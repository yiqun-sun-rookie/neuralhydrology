# Draft Directory

`draft/` is for **thesis and research writing**.

## Scope
- Thesis-oriented idea planning and narrative.
- Experiment interpretation, paper-oriented conclusions.
- Progress logs that feed thesis chapters/figures.

## Canonical Files
- Research index: `draft/RESEARCH_INDEX.md`
- Idea documents: `draft/ideas/<id>_<slug>.md`

## Writing Rule
- If content is about "how to run/maintain the project", put it in `docs/`.
- If content is about "how to write/explain research and thesis", put it in `draft/`.

# ID 05 Data Assets

Canonical basin lists for `full_531_basins` live here.

- `531_basin_list.txt`: baseline 531-basin list used by full-training configs.
- `splits/full_674_basins_{train,val,test}_basins.txt`: 674-basin splits.
- `splits/quick_full_{train,val,test}_basins.txt`: quick-test splits.
- `splits/all_basins.txt`: union list generated from 674 splits.
- `problematic_basins.txt`: manual exclusion/debug list.

These files were moved from `examples/` to remove production dependency on tutorial folders.

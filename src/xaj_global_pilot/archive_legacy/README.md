# Legacy Archive

This directory stores the archived `xaj_global_pilot` materials from the earlier Caravan-oriented pilot phase.

Archived contents include:

- basin registry and pilot-selection utilities
- the original `run_xaj_global_pilot.py` multi-subcommand CLI
- early ablation scripts and comparison scripts tied to the old pilot story
- the matching legacy tests

These files are preserved for provenance and reference only. They are no longer the active workflow for Idea 10.

Active benchmark development now lives in:

- `src/xaj_global_pilot/scripts/run_conceptual_screening.py`
- `src/xaj_global_pilot/configs/conceptual_benchmark_15_basins.csv`
- `src/xaj_global_pilot/configs/conceptual_benchmark_camels_us_531.txt`

The benchmark path is `CAMELS-US` first. `Caravan` may be added later as external validation if the screening and 531-basin benchmark justify it.

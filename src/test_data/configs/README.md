# Test Data Configs

This directory is the canonical location for lightweight test configs.

Use the generator to create/update local configs:

```bash
python src/test_data/scripts/create_test_data.py
```

Generated files:

- `quick_test.yml`
- `test_config.yml`
- `test_train_basins.txt`
- `test_val_basins.txt`
- `test_test_basins.txt`

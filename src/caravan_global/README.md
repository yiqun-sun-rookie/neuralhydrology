## 数据分析结果

基于深度学习训练需求的完整数据对齐分析（严格版：三个时期使用相同流域集）。

| **验证期** | 2006-01-01 | 2010-12-31 | 1,826 | 超参调优 |

### 筛选标准

- **三期一致**：同一流域必须在训练、验证、测试三个时期都满足要求
- 训练样本 ≥ 1,000
- 验证样本 ≥ 100
- 测试样本 ≥ 100
- 序列长度 = 365 天

| 原因 | 数量 | 百分比 |

| 验证样本不足 | 704 | 22.9% |
| 测试样本不足 | 139 | 4.5% |

## 关键发现

1. **HYSETS 有效率最低 (36.1%)** - 很多站点径流观测时间短或早期结束
2. **智利 CAMELS 较低 (59.6%)** - 部分站点数据起始较晚
3. **其他 CAMELS 数据集质量很高 (95%+)** - 数据完整性好
4. **1981-2005 是最优训练期** - 后移时间会丢失更多流域（因为很多径流数据在 2014-2015 结束）

# 深度学习水文模型训练的数据需求分析

## 核心问题

在训练 LSTM/Mamba 等序列模型进行径流预测时，需要回答以下关键问题：

1. **输入特征（气象数据）和目标变量（径流）是否对应？**
2. **它们是否有共同的时间区间？**
3. **有效训练样本数是多少？**

---

## 深度学习训练的数据结构

### 1. 输入数据 (X)

```
X = [动态输入, 静态属性]

动态输入 (时间序列):
├── total_precipitation_sum      # 降水量 [mm/day]
├── surface_net_solar_radiation_mean  # 净辐射 [J/m²]
├── temperature_2m_max           # 最高温度 [°C]
├── temperature_2m_min           # 最低温度 [°C]
└── dewpoint_temperature_2m_mean # 露点温度 [°C]

静态属性 (流域特征):
├── ele_mt_sav     # 高程 [m]
├── slp_dg_sav     # 坡度 [°]
├── area           # 面积 [km²]
├── sgr_dk_sav     # 土壤深度
├── snd_pc_sav     # 砂含量 [%]
├── cly_pc_sav     # 粘土含量 [%]
├── slt_pc_sav     # 淤泥含量 [%]
├── for_pc_sse     # 森林覆盖 [%]
├── p_mean         # 年均降水 [mm]
├── aridity        # 干旱指数
├── frac_snow      # 雪比例
└── high_prec_freq # 高降水频率
```

### 2. 目标数据 (Y)

```
Y = streamflow  # 径流 [mm/day]
```

### 3. 一个训练样本的定义

```
样本结构:
┌─────────────────────────────────────────────────┬───────┐
│     输入序列 (seq_length = 365 天)               │ 目标  │
├─────────────────────────────────────────────────┼───────┤
│ Day 1 → Day 2 → ... → Day 364 → Day 365        │ Day 365 的 Q │
│ [P, T, Rad, ...]  [P, T, Rad, ...]  ...         │ streamflow   │
└─────────────────────────────────────────────────┴───────┘

有效样本要求:
✓ 连续 365 天的气象数据都有效（非 NaN）
✓ 第 365 天的径流数据有效（非 NaN 且 ≥ 0）
```

## 数据对齐分析

### 时间区间设置

| 时期 | 起始日期 | 结束日期 | 天数 | 用途 |
|------|----------|----------|------|------|
| 训练期 | 1981-01-01 | 2005-12-31 | 9,131 | 模型学习 |
| 验证期 | 2006-01-01 | 2010-12-31 | 1,826 | 超参调优 |
| 测试期 | 2011-01-01 | 2020-12-31 | 3,653 | 最终评估 |

### 数据对齐检查逻辑

```
对于每个流域:

1. 加载气象时间序列 (ERA5-Land 驱动)
   ├── 检查所有 5 个动态输入特征
   └── 记录有效数据范围: [input_start, input_end]

2. 加载径流时间序列 (实测数据)
   ├── 检查 streamflow ≥ 0 且非 NaN
   └── 记录有效数据范围: [target_start, target_end]

3. 计算重叠区间
   ├── overlap_start = max(input_start, target_start)
   ├── overlap_end = min(input_end, target_end)
   └── 重叠天数 = overlap_end - overlap_start + 1

4. 计算各时期有效样本数
   ├── train_samples = 训练期内有效天数 - 365 + 1
   ├── val_samples = 验证期内有效天数 - 365 + 1
   └── test_samples = 测试期内有效天数 - 365 + 1

5. 检查静态属性完整性
   └── 所有 12 个静态属性都必须有效
```

### 筛选标准

| 标准 | 阈值 | 说明 |
|------|------|------|
| 最少训练样本 | 1,000 | 约 3 年有效数据 |
| 最少验证样本 | 100 | 确保验证可靠 |
| 最少测试样本 | 100 | 确保评估可靠 |
| 最大缺失率 | 30% | 数据质量控制 |
| 静态属性 | 全部有效 | 无缺失值 |

## 常见问题

### Q1: 为什么有些流域被排除？

主要原因：

1. **径流数据不足** - 观测站建站晚或停站早
   - 例：很多 HYSETS 站点 2000 年后才有数据
   
2. **气象数据缺失** - ERA5-Land 覆盖不完整
   - 极端纬度地区可能有问题
   
3. **静态属性缺失** - 某些流域特征无法计算
   - 例：小流域面积计算误差

### Q2: 输入和目标数据来源不同会有问题吗？

| 数据类型 | 来源 | 时间分辨率 | 空间分辨率 |
|----------|------|------------|------------|
| 气象数据 | ERA5-Land 再分析 | 日 | ~9km |
| 径流数据 | 各国水文站实测 | 日 | 点位 |

**潜在问题**：
- 时区差异（已在 Caravan 中处理）
- 流域边界与网格不匹配（已做面积加权）

### Q3: 训练样本数如何计算？

```python
# 简化计算
train_samples = 训练期有效天数 - seq_length + 1

# 示例
训练期: 1981-2005 (9131 天)
假设有效天数: 8000 天
seq_length: 365 天
train_samples = 8000 - 365 + 1 = 7636 个样本
```

- **七级库尾站**：43,830 行，2020-01-01 00:00 ~ 2024-12-31 23:00，步长 1h
- **七级坝前站**：42,081 行，2020-03-04 09:00 ~ 2024-12-31 23:00（2020/1-2月缺测）

3. 孟乌站存在长缺测区间，需特别处理

## 3. 实验设计（2025-11-22）

### 3.1 特征层级实验（信息阶梯）

设计 6 级层级实验，量化不同信息源的贡献：

| 编号 | 名称 | 输入特征 |
|------|------|----------|
| S1 | Rain | 仅雨量（纯模拟基准） |
| S2 | Rain_AR | 雨量 + 历史流量/水位（引入自回归） |
| S3 | Rain_Static | 雨量 + 静态属性（验证下垫面信息） |
| S4 | Rain_AR_Static | 雨量 + 自回归 + 静态（单站全要素） |
| S5 | Rain_AR_Downstream | 雨量 + 自回归 + 下游坝前水位 |
| S6 | Rain_AR_Downstream_Static | 全系统融合 |

### 3.2 统一设置

- Target: qobs
- Seq Length: 168h（7天）
- Horizon: 1h（Seq2One）/ 24h（Seq2Seq）
- Metrics: NSE, KGE, RMSE, Peak-MAPE

### 3.3 数据使用说明

**Perfect Rain 假设**：
- 目标变量（Flow/Stage）：严格遵循不可见未来原则
- 驱动变量（Rain）：使用 T~T+1 的观测降雨（水文模拟验证模式）

## 4. 实验结果（2025-11-24）

### 4.1 S1_Rain（基准）

- **验证期**: NSE ≈ 0.37
- **测试期**: NSE ≈ 0.00
- **结论**: 仅靠雨量无法准确预测流量

### 4.2 S2_Rain_AR

- **验证期**: NSE = 0.874, KGE = 0.878, RMSE = 8.53
- **测试期**: NSE = 0.488, KGE = 0.525, RMSE = 82.80
- **结论**: 自回归特征显著提升性能

### 4.3 S3_Rain_Static

- **验证期**: NSE = 0.366, KGE = 0.475
- **测试期**: NSE ≈ 0.004, KGE ≈ -0.11
- **结论**: 单流域静态属性贡献有限

### 4.4 S4_Rain_AR_Static ★

- **验证期**: NSE = 0.996, KGE = 0.994, RMSE = 1.54
- **测试期**: NSE ≈ 0.53, KGE ≈ 0.55, RMSE = 79.8
- **结论**: 最佳配置，接近自回归上限

### 4.5 汇总对比

| 实验 | 验证 NSE | 测试 NSE | 关键发现 |
|------|----------|----------|----------|
| S1 | 0.37 | 0.00 | 仅雨量不足 |
| S2 | 0.87 | 0.49 | AR 至关重要 |
| S3 | 0.37 | 0.00 | 静态属性贡献有限 |
| **S4** | **0.996** | **0.53** | 最佳组合 |

## 5. 问题排查记录

### 5.1 S2 评估 NaN 问题（2025-11-25）

**症状**：
- `nh_run evaluate` 给出 NSE ≪ 0（如 -62）
- `qobs_sim` 只有 ~24% 时间有值，其余为 NaN

**排查过程**：
1. 调试脚本确认模型在第 0 个样本就输出 NaN
2. 检查发现动态特征中的 `qobs` 在验证期全部为 NaN
3. 定位到 `datasetzoo/basedataset.py` 中 warmup 处理问题

**根因**：
在切片阶段直接将 `target_variables` 在 warmup 区间整体置为 NaN，导致 `qobs` 同时作为目标与自回归特征时，验证期前半段被清空。

**修复**：
1. 删除 `_load_or_create_xarray_dataset` 中的 NaN 替换逻辑
2. 仅针对 `y` 构造 `valid_mask`，保留原始 AR 特征

**验证**：
- 修复后验证期 NSE = 0.874（原 -62）
- `qobs_sim` 全程无 NaN

### 5.2 单流域静态属性归一化问题

**症状**：
- 训练时报错：静态属性方差为零

**原因**：
单流域场景下，静态属性只有一个值，方差必然为零。

**修复**：
在 `datautils/utils.py` 和 `basedataset.py` 中增加 `allow_constant` 逻辑，当方差为零时将归一化值置零。

## 6. 关键发现总结

### 6.1 技术发现

1. **自回归特征至关重要**：S2/S4 显著优于 S1/S3，历史流量是预测的核心特征
2. **滞后相关性**：降雨滞后 12h 与流量相关性最高
3. **累积降雨**：48h 累积降雨相关性最高（r ≈ 0.32）
4. **静态属性**：在单流域场景下贡献有限

### 6.2 数据发现

1. **2024 年数据问题**：存在录入错误，暂不使用
2. **孟乌站缺测**：覆盖率仅 80%，需特别处理
3. **PET 估算**：Hargreaves 气候态不够准确，建议替换 ERA5-Land

### 6.3 模型发现

1. **Perfect Rain 限制**：当前使用观测降雨，实际业务需替换为预报产品
2. **测试期泛化**：最佳 NSE 仅 0.53，受单站数据量和 Perfect Rain 假设限制

# 统一自动研究纵向最小版本实施计划

**目标：** 在 `src/unified_autoresearch/` 内完成四类开放候选的双开发协议、受限运行、不可覆盖登记、恢复、资源监督和独立验证。

**架构：** 新编排层以命令候选协议为稳定边界；登记、运行限制、数据准备、评分和候选实现相互分离。现有公平基准和模型代码保持只读。

**技术：** Python、SQLite、pandas、NumPy、PyTorch、pytest、Windows 进程接口。

## 里程碑零：冻结设计、流域和协议

1. 为静态属性选择器写失败测试：同一输入重复选择相同八个流域，且不接受流量或模型结果列。
2. 实现确定性最远点覆盖选择器并运行测试。
3. 生成并冻结八流域清单，写入静态输入文件的 256 位散列数字指纹。
4. 为协议校验写失败测试：两个日期协议、Maurer 气象驱动、27 项静态属性和最终评估禁区任一变化均失败。
5. 写数据、候选、资源协议并通过校验。
6. 记录测试输出和源码数字指纹，提交里程碑审核。

## 里程碑一：不可覆盖登记和原子调度

1. 写失败测试证明候选记录不能更新或删除，更正必须引用旧记录。
2. 实现追加式 SQLite 登记和散列链。
3. 写失败测试证明非法状态转换、并发调度锁和外来锁释放均失败。
4. 实现事件状态机、单调度锁和原子状态转换。
5. 写失败测试证明数字指纹缺少代码、未提交差异、配置、依赖、数据、种子或产物任一部分即无效。
6. 实现分项清单与根散列，运行登记完整性检查。
7. 记录证据并执行两个独立任务的审核和定向复验。

## 里程碑二：统一候选协议和运行限制

1. 写失败测试覆盖缺失入口、未声明依赖、越界读写、子进程、非原子检查点和错误退出状态。
2. 实现候选描述校验、隔离目录构建和命令适配器。
3. 写真实文件打开的反向测试，证明禁用文件读取被运行时拒绝且留下访问记录。
4. 实现允许文件清单、默认拒绝审核钩子、访问日志和预测阶段真值不挂载。
5. 写受控停止、两个校验检查点和恢复引用测试并实现。
6. 记录证据并执行两个独立任务的审核和定向复验。

## 里程碑三：数据准备、评分和四类候选

1. 写失败测试证明数据准备只输出两个开发协议，预测包不含观测流量，日期不触及最终评估。
2. 实现八流域 Maurer 气象、27 项静态属性和监督目标的隔离数据包。
3. 写失败测试证明缺行、额外日期、非有限预测和错误流域不能评分。
4. 实现外部 Nash–Sutcliffe 效率系数评分和双验证汇总。
5. 分别为深度学习、概念降雨—径流、融合、自定义 Python 入口写失败契约测试，再实现一个轻量参考候选。
6. 每类完成一次受控中断恢复和一次干净重跑，生成 32 个结果单元。
7. 记录证据并执行两个独立任务的审核和定向复验。

## 里程碑四：按任务需要的资源监督和连续完整运行

1. 冻结代表性资源小试验和峰值估算方法。
2. 写失败测试覆盖任务专属峰值估计、安全余量、启动时实际容量、监督启用决定及理由、进程归属和受控保存退出。
3. 实现按任务需要配置采样与汇总间隔的独立监督进程和原子资源日志；不设置统一内存门槛。
4. 连续执行两次完整纵向运行，验证退出码、产物、有限指标、禁止读取和登记校验五项门槛。
5. 生成扩展至 64 和 531 流域前的时间、存储、并行和数据准备剩余清单。
6. 记录证据并执行两个独立任务的审核和定向复验。

## 最终审核

1. 新任务只读审核数据边界、代码、32 个结果单元和证据链。
2. 第二个新任务从同一源码数字指纹建立干净目录并完整重跑。
3. 第三个新任务执行登记篡改、越界读取、检查点损坏、外来进程和比较失效的对抗测试。
4. 只在三次审核均通过且完成标准逐项有直接证据时结束目标。

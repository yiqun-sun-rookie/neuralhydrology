# 单滤波器理想合成状态更新绘图指南

文档类型：状态更新证据的绘图方法指南  
适用对象：已经完成科学计算和独立核验的理想合成状态更新结果  
不包含：重新定义样本、指标、区间或科学判断

核心原则是使用能够回答问题的最小图形集合。通常一至两张主图已经足够，但不固定图的数量、类型或配色。

## 一、硬性绘图合同

以下要求直接关系到图是否忠实：

- 图只能读取已封存并通过适用核验的数值证据；
- 绘图不得改变样本、状态定义、误差尺度、区间算法或判断规则；
- 图中的时间索引、状态名称、单位和分组必须与状态结构表一致；
- 状态选择和分组应在看图形结果前确定，不能根据结果好坏挑选；
- 主图可以只展示重点状态，但完整数值结果或补充材料必须覆盖全部传播状态；
- 理想合成图不能写成真实系统证据；
- 新图不得覆盖既有证据或原图。

若绘图数据不能追溯到封存结果，停止图形结论交付。

## 二、先按问题选择视图

### 1. 看累积同化效果

主要比较后验与完全不开启同化的开环状态。对于适合画轨迹的状态，通常同时画：

- 合成真值；
- 更新后后验；
- 开环状态。

更新前先验只在需要解释当前观测的即时作用时加入。

颜色和线型不固定。要求是语义在全部图中一致、色觉友好、灰度下可区分，并且主要对象比辅助对象更醒目。

### 2. 看状态精度方向

可以根据数据规模选择：

- 状态较少：逐状态轨迹、点图或点—区间图；
- 状态较多：状态组汇总、预先选定的代表状态和完整数值附表；
- 状态具有规则结构：在尺度可比较时使用热图；
- 存在可辩护的整体指标：展示整体、状态组和单状态的关系；
- 不存在合理整体指标：只展示状态组和单状态，并明确没有单一整体判断。

点—区间图只有在证据中确实存在配对区间时才使用。柱状图可以用于显示绝对量，但不能代替已经登记的不确定性判断。

### 3. 看滤波行为

创新、预测观测、状态投影、协方差、集合退化或似然图只在研究问题或排错需要时加入。它们不应因为可生成就全部进入主结果。

## 三、误差和尺度

单个状态的轨迹和绝对误差优先保留原始单位。

跨状态放在同一坐标轴、热图或总体汇总时，应使用验证阶段预先登记的可比尺度。标准化绝对误差差值、标准化平方误差差值只是可选方案，不是唯一方案。

若使用“后验误差减开环误差”：

- 0 表示两者相同；
- 负值表示后验误差较低；
- 正值表示后验误差较高。

热图只有在行间数值确实可比较时使用。若状态距离定义不同，应分组绘制或只显示方向性类别，不能把不可比较的原始误差放入同一色标。

相对变化只有在对照误差非零且分母稳定时绘制，并同时给出绝对误差。

## 四、图形数量和状态覆盖

主交付采用最小充分集合：

- 一个简单状态时，一张图可能足够；
- 多个低维状态可以使用共享时间轴的小图；
- 高维状态不要求每个分量都塞进主图，可用状态组汇总、代表状态和完整附表；
- 只有结构清楚且可读时才使用完整热图；
- 轨迹和精度总结可以合并，也可以分开。

完整状态覆盖是数值证据要求，不是“所有状态必须出现在主图”的要求。任何代表状态都应在看结果前选择，并说明选择依据。

## 五、视觉语义

建议遵循：

- 真值、后验、开环和先验使用稳定且可区分的视觉编码；
- 不只依赖红色和绿色表达好坏；
- 不同单位不共用同一纵轴；
- 时间相关面板使用一致的横轴；
- 差值图清楚标出 0 和正负方向；
- 标签优先使用完整名称，内部编号仅用于追溯；
- 图例、字体和线条在最终导出尺寸及灰度下可读；
- 不截断坐标轴或调整色标来夸大差异。

具体颜色、线宽、图例位置和图形库属于实现选择，不是科学合同。

## 六、阶段切换和局部放大

理想主实验使用固定真值条件时，不需要切换标记。

若另做分阶段实验，可以在相关面板标出真实切换时刻和阶段含义。切换线只表示真值条件改变，不表示状态必须同步突变，也不表示滤波器已经识别出正确候选。

局部放大只用于补充解释，不能替代完整评分时段或隐藏不利时段。

## 七、图注最低信息

图注至少说明：

- 真值、后验、开环和其他线条分别是什么；
- 误差或差值的定义及正负方向；
- 状态选择是否覆盖全部状态，若未覆盖，完整结果在哪里；
- 使用的尺度、单位和不确定性含义；
- 数据属于理想合成条件还是其他实验；
- 图中判断来自哪个封存结果。

可使用模板，但不要求固定句式。

## 八、证据管理和导出核验

绘图产物应采用非覆盖式版本管理，并保存以下信息角色：

- 输入数值证据及其身份；
- 绘图脚本或绘图环境身份；
- 图中使用的状态、样本、指标和尺度；
- 输出图及其版本或完整性校验信息。

文件名、目录结构和图像格式可以自定。

导出后核对：

- 数字、样本和判断是否与封存结果一致；
- 状态名称、单位、分组和索引是否正确；
- 时间轴、切换标记和状态投影是否对齐；
- 差值方向、0 线、区间和图注是否一致；
- 代表状态选择是否与预先登记一致；
- 图形在最终尺寸、灰度和常见色觉条件下是否可读。

禁止：

- 只画状态子集却声称已经展示完整状态；
- 用同一观测更新后对该观测的贴合程度证明隐藏状态准确；
- 用图形外观替代封存统计判断；
- 把局部时段代替完整评分时段；
- 把理想合成结果写成真实系统结论。

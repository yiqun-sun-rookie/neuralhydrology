# 单滤波器理想合成状态更新验证指南

文档类型：单滤波器验证方法指南  
适用对象：完整状态真值已知的理想合成实验  
不包含：多模型识别、状态交互、真实数据验证或预报验证

本指南的首要问题是：在公平条件下，累积使用观测得到的后验状态是否比同一滤波器不执行观测更新得到的状态更接近同一时刻的合成真值。

## 一、硬性科学合同

以下要求直接关系到结论是否成立，不应降级为可选项。

### 1. 真值不能形成循环验证

第一层是理想孪生实验：真值与估计方法使用相同的数学状态方程、量测方程、固定模型参数、外部输入、状态约束和时间步长。除运行前登记的估计初始状态误差外，真值与估计方法之间不得再加入参数差异或模型结构差异；这些差异如需研究，应另立实验。

相同数学模型不等于让滤波器自己生成答案。真值生成不得调用被验证滤波器的完整预测—更新流程。允许复用经过单独核验的纯状态转移或量测函数，但必须登记复用关系，并至少用解析结果、人工可核算算例、替代实现或不变量检查核验状态转移、量测计算和状态约束。这里要求的是对同一实验计算过程的额外核对，不是再做一套科学实验。

### 2. 后验与无观测更新对照必须公平

至少保存：

- 同一时间索引的合成真值状态；
- 由真值状态计算的无量测噪声真实输出；
- 加入量测噪声后的观测值，如适用；
- 同一滤波器不执行观测更新得到的状态和不确定性；
- 当前观测进入前的先验状态；
- 当前观测进入后的后验状态；
- 量测误差的实际数组，如适用。

本指南只有一个主要对照：**同一滤波器的无观测更新对照，以下简称开环**。后验分支和开环分支从相同的初始估计状态及初始不确定性开始，各自从上一时刻状态向前递推。两者执行相同的滤波器预测、状态约束、数值修复和不确定性传播；开环只跳过观测更新，并且从头到尾不得读取观测。对于非线性滤波器，开环仍须执行与后验分支相同的采样点、集合或协方差预测，不能改成只传播一个确定性状态。确定性物理模型轨迹如需保存，只能标为辅助结果，不能替代主要开环对照。

两条分支必须使用相同的状态转移与量测方程、模型参数、外部输入、过程噪声设定、状态约束、时间索引、传播时段和评分样本。每一层内唯一允许的实验差异是是否执行观测更新。真值初始状态不得只提供给其中一个估计分支。替换或打乱全部观测后，开环状态及其不确定性必须在登记容差内保持不变。

本指南只保留两个递进条件：

1. **无过程扰动、无量测误差。** 真值传播不加入过程扰动，滤波器使用的过程噪声协方差为零，观测值等于无量测噪声真实输出。若算法不能使用零量测误差协方差，必须在运行前登记一个具体正值、单位和用途，并明确写成“真实量测误差为零，但滤波器内部为数值稳定使用正的量测误差协方差”。不得把未定义的“最小正值”作为设置。该层用于检验滤波器能否纠正预先登记的初始状态误差。
2. **无过程扰动、加入量测误差。** 完全复用第一层的真值、输入、参数、初始误差、初始不确定性、开环和评分样本。先完整生成并固定真值状态及无量测噪声真实输出，再逐时刻加入一套运行前登记、可重放并完整保存的量测误差。后验分支必须新建滤波器实例，从与第一层相同的初始估计状态和初始不确定性重新运行，不得承接第一层末尾状态。开环若重新运行，应与第一层开环在登记容差内一致；也可以直接复用已经封存并核对一致的第一层开环。

第二层的量测误差必须登记生成方式、均值、标准差或协方差、单位、时间相关性以及加性或乘性形式。滤波器使用的量测误差协方差必须与登记设定相符，并明确区分标准差和方差。若观测还要经过非负裁剪、变换或缺失值处理，必须同时保存处理前观测、滤波器实际读取的观测，以及两者相对无量测噪声真实输出的实际误差。量测误差及其处理不得反馈到真值状态或后续真值传播。

两层的状态误差都与同一真值状态比较；若报告输出误差，应与无量测噪声真实输出比较。主要科学对比是后验对开环。后验对先验只用于解释当前观测的即时作用，不能代替累积同化效果比较。本指南只使用第二层保存的这一套量测误差，因此结论只能限定为“在这套量测误差实现下”；不能称为对一般量测噪声具有稳健性。本指南暂不加入过程噪声实验。

### 3. 完整数值证据必须覆盖全部传播状态

实验配置应提供状态结构表，记录各状态分量的名称、索引、单位、分组、边界和传播用途。

凡是被下一次状态转移、观测计算或后续预报读取的状态分量，都必须出现在封存数值证据和状态精度核验中。位于正式状态向量之外、但会影响未来结果的汇流队列、延迟缓存或其他动态记忆，也必须登记其形状、顺序、初始化和更新时间。每个状态分量必须单独报告误差；状态组汇总只能作为补充。主图可以只展示重点状态，但不能把状态子集称为完整状态。

还应保存每个状态的真值初始值、估计初始值和两者差值。初始时没有误差、没有受到有效激发或无法由现有观测约束的状态，只能称为“完成数值覆盖”，不能据此声称其恢复能力已经得到验证。

### 4. 时间和信息边界必须一致

本指南默认初始时刻只用于初始化，不执行观测更新，也不计入主要评分。对每个后续时刻，严格顺序为：

1. 使用上一时刻真值状态和当前传播区间的外部输入生成当前真值状态，再执行登记的真值状态约束；
2. 从当前真值状态计算当前无量测噪声真实输出；
3. 第一层直接把该输出作为观测，第二层在真值轨迹已经固定后加入当前量测误差，并执行登记的观测处理；
4. 后验分支和开环分支分别从各自上一时刻状态及不确定性出发，使用同一传播区间输入完成当前先验预测和预测后状态约束；
5. 后验分支使用当前观测完成更新及登记的更新后状态约束，开环分支跳过该更新；
6. 将当前后验、当前开环和当前真值按同一时刻评分；当前先验只作即时更新诊断。

实验登记必须写明传播区间使用哪个输入索引、各数组所代表的是时段开始还是时段结束、状态约束发生在预测或更新的哪个位置，以及第一个和最后一个有效评分样本。不能把当前后验与下一时刻真值比较，也不能在当前更新中使用未来观测。

评分时段、排除规则和缺失值处理必须在看结果前确定。局部时段可以作为预先登记的次要分析，但不能代替完整评分时段。

### 5. 结论边界必须明确

理想合成状态精度只能说明受控条件下的状态恢复结果。它不能自动证明参数识别、噪声识别、状态交互、未来预报或真实系统隐藏状态有效。

## 二、最小实验登记

开始前至少登记以下信息：

- 唯一实验身份和非覆盖式输出位置；
- 状态转移模型、量测模型、固定参数、状态约束及真值与估计代码的复用关系；
- 外部输入、真值初始状态、逐状态估计初始误差、初始不确定性和评分时段；
- 完整时间递推顺序、输入索引、观测处理和有效评分索引；
- 真值过程扰动、滤波器过程噪声协方差、实际量测误差数组和滤波器量测误差协方差这四个对象的各自设定；
- 量测误差生成器、随机种子、数组形状及实际数组散列，如适用；
- 状态结构表；
- 主要对比、逐状态误差、主要判断对象、数值容差和进入第二层的判定规则；
- 每项检查属于必需、条件触发还是不适用，以及不适用理由；
- 代码、配置、输入、真值证据和精确运行命令的可追溯身份及散列；
- 解释器和主要依赖版本；
- 运行前工作树状态。

不要求固定目录结构或文件格式，但不得覆盖既有证据，也不得清理、还原、暂存或提交用户已有改动。

## 三、科学判断前的必要门槛

### 1. 真值门槛

应确认：

- 真值、输入、模型输出和观测使用一致的时间索引；
- 第一层除估计初始状态误差外，真值与估计方法没有参数或模型结构差异；
- 状态及模型输出有限，并满足登记的状态域约束；
- 具有记忆、滞后、队列、空间或层级结构时，更新方向和索引顺序正确；
- 状态投影或裁剪的时刻、前后数值和调整量可追溯；
- 真值可以重放，或能够通过另一种计算检查得到一致结果；
- 第二层逐元素满足“滤波器实际读取的观测减去无量测噪声真实输出等于保存的实际量测误差”，观测处理造成的变化已单独记录；
- 量测误差没有改变任何真值状态、后续真值输出或外部输入。

### 2. 实现门槛

状态转移、量测计算和观测更新至少应各有一种额外检查方式，例如解析结果、人工算例、替代实现、差分对照或不变量检查。检查方式由算法决定，不要求所有方法使用同一组测试。

应证明后验与开环确实使用同一套预测路径，且开环只跳过观测更新。相同输入应得到可解释的重复结果；使用保存的量测误差数组时应能够逐次重放。第二层必须从登记的初始状态和初始不确定性重新开始。

### 3. 封存结果只读复核门槛

只读复核不是第二套实验。它是在不改写封存结果的前提下，用单独的小程序或人工公式直接读取原始轨迹，重新计算主要误差，并核对时间索引、状态顺序、有效评分样本和最终文字判断。复核不得直接调用正式运行中生成同一汇总结果的函数。

运行前登记为必需或被条件触发的门槛、证据散列或只读复核只要有一项失败，就暂停科学判断。必须区分“不适用”“未执行”和“执行失败”；看到结果后不得更改适用性。

## 四、指标和整体判断

### 1. 指标必须适合状态类型

指标在看结果前确定。连续状态可以使用均方根误差或平均绝对误差；周期状态、类别状态、比例状态或其他特殊状态应使用与其定义相符的距离或损失。

各单状态应报告具有可解释尺度的绝对误差。跨单位比较或聚合时，才需要使用预先登记的标准化方法。

### 2. 不强制生成单一整体标量

完整状态的含义是数值证据覆盖全部传播状态，不等于必须把所有状态压成一个数。

若存在科学上可辩护的整体指标，应在看结果前规定标准化、权重和聚合方式。等分量权重、等状态组权重或任务相关权重都可以使用，但必须说明含义。

若不存在合理的整体指标，应分别报告各状态组和单状态方向，并明确写“未定义单一整体优劣判断”。

### 3. 第一层判定和停止条件

证据是否有效与状态是否改善必须分开判断：

- 任一必要门槛失败，记为“证据无效”，停止实验，不给状态改善结论；
- 必要门槛全部通过后，再按运行前登记的主要判断对象、差值方向和数值容差，判为“改善”“恶化”或“证据不足”；
- 若没有定义单一整体指标，必须在运行前列出必须改善的状态或状态组、不得恶化的状态以及组合逻辑；否则只能给逐状态结论，不能把整层称为通过或失败；
- 只有必要门槛全部通过且第一层满足预先登记的进入条件，才进入第二层；第一层得到“恶化”或“证据不足”时停止，但不能把它写成实现检查失败。

### 4. 不确定性分析按研究问题选择

只有需要从有限时段、事件、重复试验或随机种子推断更一般结论时，才需要配对区间。重采样或重复试验方法应保留时间依赖和配对关系。

本指南第二层只使用一套固定量测误差，可以报告该实现下的点估计，但不能外推为其他量测误差实现下也会得到相同结果。只有另立研究并预先登记多个量测误差实现及汇总方法后，才能判断跨量测误差实现的一般结果。

### 5. 相对变化是辅助量

相对变化应与绝对误差同时报告。只有对照误差非零且分母具有稳定含义时才使用相对变化；否则报告绝对差值。

## 五、按方法触发的检查

以下检查仅在方法具有相应对象时适用：

- 显式协方差滤波器：检查协方差有限、对称和半正定；只有提出概率可靠性结论时才检查覆盖与校准；
- 集合或粒子方法：检查成员有限、权重归一化以及退化或有效样本问题；
- 受约束滤波器：区分原始更新与状态投影的影响；
- 使用观测似然的方法：检查创新、预测观测和似然计算；
- 使用随机数组的方法：检查随机种子、实际数组、数组散列和逐次重放；本指南的一套固定量测误差不强制重复试验。

各项适用性必须在运行前登记。不适用的检查可以省略，但应记录理由。

## 六、最小结果交付

主结果应至少让读者知道：

- 比较对象和有效样本；
- 每个传播状态的误差尺度、单位、开环绝对误差和后验绝对误差；
- 状态组或整体指标，如已预先定义；
- 预先登记的差值方向；
- 不确定性结果，如适用；
- 改善、恶化或证据不足的判断；
- 哪些传播状态完成了数值覆盖，哪些状态的恢复能力实际得到检验。

表格、分组表、补充材料或机器可读文件均可承载完整结果，不规定固定列数。

证据链至少应包含以下角色，文件名和格式可以自定：

- 配置、精确运行命令和运行环境；
- 代码、未提交内容、输入和外部输入的身份及散列；
- 合成真值状态和无量测噪声真实输出；
- 含噪观测、滤波器实际读取的观测和实际量测误差数组，如适用；
- 开环状态与不确定性、先验状态、后验状态及其他方法必需的原始轨迹；
- 有效评分索引及所有排除原因；
- 指标与判断汇总；
- 封存结果只读复核记录；
- 运行完成或失败状态、日志和全部产物散列清单。

每项结论都应能够从汇总结果追溯到原始状态轨迹、配置、输入和代码身份。

## 七、允许使用的结论

可以写：

> 在完整状态真值已知、真值传播不加入过程扰动、后验与同一滤波器的无观测更新对照公平匹配的理想合成条件下，累积使用观测得到的后验状态相对无观测更新对照，在【无量测误差／这一套已保存量测误差】条件下，对【明确列出的状态、状态组或预先定义的整体指标】表现为改善、恶化或证据不足。

不能由本实验单独声称：

- 找到了正确模型参数或噪声设定；
- 能够识别真实参数切换；
- 状态交互或多模型方法有效；
- 未来预报已经改善；
- 真实系统中的隐藏状态已经恢复；
- 有限检查通过已经证明实现普遍正确；
- 同化后输出更贴近参与更新的观测就等于隐藏状态恢复正确；
- 一套量测误差实现的结果已经证明对一般量测噪声稳健。

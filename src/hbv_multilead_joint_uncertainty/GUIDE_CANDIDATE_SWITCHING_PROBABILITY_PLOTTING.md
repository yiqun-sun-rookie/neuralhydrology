# 候选切换概率绘图指南

文档类型：候选后验概率图形规范
适用对象：参数候选、过程噪声候选、参数与噪声联合候选的概率曲线、热图与多事件汇总图
前置条件：判断已按《交互式多模型方法验证与候选切换判断指南》完成并封存；本指南只负责把封存判断画清楚
适用范围：不绑定具体动力模型、状态个数或候选个数
不包含：切换成功规则与判断用语（归验证与判断指南）、状态轨迹与交互诊断图、预报图（以后另立指南）

绘图程序只能读取封存判断，不得在画图时重新定义成功规则、门槛或样本范围。

## 本指南的地位

验证与判断指南中的"本指南的地位"同样适用于这里：以下图形约定不是唯一正确的画法，鼓励提出更清楚的替代方案，反驳成立时应修改本指南并记录原因。唯一不可协商的是另一件事——成功规则、样本范围和判定数字只能来自封存判断，不得在绘图阶段重新定义。

## 一、最小充分绘图

图的数量由问题决定，不设置固定张数。主结果通常只需一张阶段对齐概率图；候选较多或联合候选难以阅读时，再增加热图或摘要图。

## 二、阶段对齐概率图

主图应让读者不查内部编号也能看懂：

- 横轴为时间或相对切换时间（切换时刻为第 0 步）；
- 每个真实切换点有明确竖线；
- 背景色带或顶部条带写出每一阶段的真实候选；
- 当前真实候选曲线加粗，其他曲线减弱；
- 候选使用完整、通俗的名称；
- 纵轴明确为后验概率，范围固定为 0 到 1；
- 面板内写出样本数、判断规则、成功数和响应时间摘要。

候选数量较少时可以画全部候选；较多时优先画真实候选、最强竞争候选和其余候选总概率，完整候选分布改用热图。

不得只靠"绿色代表正确"传递真值。颜色、线宽、背景标注和文字应共同表达信息，灰度查看时也应能区分主要曲线。

面板内直接报告的字段从封存统计表读取，例如：

```text
成功事件：k / N
响应规则：W 步内连续 K 步最高
响应起始时刻中位数：d 步
精确区间：[下限, 上限]
判断：通过 / 未通过
```

## 三、候选概率热图

候选较多时，热图通常比大量折线更清楚：

- 横轴为时间；
- 纵轴为固定顺序的候选；
- 色标固定为零到一；
- 每个阶段直接标记真实候选所在行；
- 参数、噪声或其他候选属性按预先登记的顺序分组；
- 切换线与主图使用相同时间位置。

热图不能只显示获胜候选，因为这会丢失近似并列和概率扩散信息。

## 四、多次重复的汇总图

有多个区块或随机种子时，主图可画真实候选概率的中位数和预先指定的分位区间，并在补充图保留单次事件细线与失败事件；关键切换方向可另做放大图。

图注必须明确阴影表示分位区间、重采样区间还是参数估计区间。不要用平均曲线掩盖两类相反结果。

## 五、参数与噪声联合候选图

联合候选实验优先使用对齐的三个读出面板：

1. 参数边缘概率；
2. 过程噪声边缘概率；
3. 唯一参数—噪声联合候选概率。

边缘概率由所有具有同一参数或同一噪声属性的联合候选概率求和得到。标题和图注不得统一写成模糊的"正确概率"。

联合候选很多时，不应把全部联合曲线挤在一张折线图中；可使用两个边缘概率面板，加一个联合概率热图或真实联合候选概率轨迹。

## 六、条件诊断图

以下图只在主图不能解释结果时加入，不是每次都必须生成；对应的诊断逻辑见验证与判断指南第八节：

- 观测似然优势图：真实候选与最强错误候选的逐时刻对数似然差和累计对数似然差；
- 转移先验与观测更新分解图：观测前候选预测概率与观测后候选后验概率的对比。

诊断图用于解释失败，不得把失败样本静默排除出主图。

## 七、绘图证据

绘图数据与图形生成记录必须可追溯：绘图脚本读取的封存判断文件、绘图数据快照、图形文件及其散列应一并保存。图上出现的每个数字都应能追溯到封存统计表，不得在绘图脚本内重新计算判定。

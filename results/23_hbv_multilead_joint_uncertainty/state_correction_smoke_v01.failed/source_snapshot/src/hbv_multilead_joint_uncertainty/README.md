# 日尺度一、三、七天联合参数与过程噪声试验

交互式多模型方法（在多个候选模型之间按观测证据更新权重并交换状态）管理多个改进无迹卡尔曼滤波器
（用一组确定性样本点传播非线性状态及其不确定性）。过程模型是 Hydrologiska Byråns
Vattenbalansavdelning 简化模型（一个包含积雪、土壤、快流、慢流和汇流记忆的日尺度概念水文模型）。

本目录实现一个回顾性诊断回报试验。日期 `t` 的气象先推进模型，再用日期 `t` 的实测流量更新状态；随后
复制后验筛选器组，只使用 `t+1` 至 `t+7` 的实测气象。输出的一天、三天和七天预测不读取起报日之后的
流量。由于未来气象是事后实测值，且中心参数由1999年至2008年资料率定，本结果不是实时或业务预报。

五种方法为：不更新状态的中心模型、固定参数与固定噪声的单一状态更新、仅三个完整参数向量变化、仅三个
过程噪声协方差变化、三个参数向量与三个过程噪声协方差组成的九候选联合方法。相同过程噪声编号在全部
参数向量中使用逐元素完全相同的十五乘十五绝对协方差；十个汇流记忆状态的过程方差严格为零。
参数与过程噪声分别使用单因素每日保持概率0.98；联合九候选的转移矩阵是两个单因素矩阵的克罗内克积，
因此参数和过程噪声的边际每日切换概率都为0.02，单个联合候选的每日自保持概率为0.9604。

## 预测时间和评价资料

- 状态预热：1988年10月1日至1989年9月30日，只用气象，不读取流量。
- 冻结评价：1989年10月1日至1990年9月30日，共365天。
- 每个方法使用相同的358个起报日；目标索引严格等于起报索引加1、3或7。
- 日期 `t` 的流量可以更新日期 `t` 的后验状态；所有日期 `t+1` 及以后的流量都不可用于该次起报。
- 中心参数由1999年10月1日至2008年9月30日的资料率定，晚于评价窗口。因此本试验只能检验回顾性状态更新，不能解释为按时间向未来的业务检验。

## 实际进入模型的输入

| 输入 | 数值与单位 | 来源和处理 | 起报后是否使用 |
|---|---|---|---|
| 降水 | 毫米每天 | Maurer 流域平均文件的 `PRCP(mm/day)`，不变换 | 使用未来实测值 |
| 平均温度 | 摄氏度 | Maurer 文件的最高温度与最低温度的算术平均 | 使用未来实测值 |
| 潜在蒸散发 | 毫米每天 | 由短波辐射、日长、平均温度和水汽压按 Priestley–Taylor 公式逐日计算，负值截为零 | 使用未来实测值 |
| 流量 | 毫米每天 | 美国地质调查局日流量乘 `2.4466/流域面积（平方千米）`；负原值视为缺测 | 只允许使用到起报日 |

Daymet 温度只用于发现 Maurer 温度文件损坏，不进入模型。每个合同的 `input_variables.csv` 记录逐流域文件、
完整文件校验和、单位、日期范围、推导方式和未来可用性。正式合同冻结前不打开评价期原始流量文件。

## 十三个参数如何给定

每个流域的中心向量来自冻结的531流域训练参数投影；投影只含流域编号、运行状态、十三个参数和五个训练末
状态，不含任何评价指标。参数值及其率定协议分别见
`configs/trained_parameter_projection_531_v01.csv` 和
`configs/trained_parameter_projection_531_v01.metadata.json`。

另两个完整参数向量只用2006年10月1日至2008年9月30日的开发资料确定。在中心向每个参数物理边界的
10%、5%、2.5%和1.25%四个范围内，每个范围生成256个完整候选向量，合计1,024个。每个范围都使用
固定随机种子1，并重新启动同一条加扰索博尔低差异序列（在参数空间中比普通随机抽样更均匀的一组采样点）；
候选编号按上述范围从大到小排列，每个范围内再按采样顺序排列。保留开发期纳什—萨特克利夫效率系数下降
不超过0.03的候选。先将每个参数差值除以该参数的冻结物理边界跨度，再穷举所有范围中的全部合格候选对；
对每一对计算“候选一到中心、候选二到中心、两个候选之间”三个欧氏距离，并选择三个距离中最小值最大的
候选对。完全并列时按候选编号升序确定。模拟平均流量只保存为诊断量，不参与选择。合格且不同于中心的候选
少于两个时，合同直接失败，不按流域放宽标准，也不进入评价。

效率下降0.03是六个开发流域共同使用的操作标准，不是统计显著性阈值或普适水文常数；每个范围的256个
候选和四个范围合计1,024个候选都是冻结的计算预算，不表示完整覆盖十三维参数后验分布。当前规则、归一化
距离、全部候选的开发期指标和最终编号写入逐流域合同；三个向量的十三个数值、单位、边界、开发期效率和
来源校验和写入
`parameter_vectors.csv` 与 `parameter_dictionary.csv`。旧版“平均流量一低一高”合同仍可复核，但不会用于
新的六流域和十六流域计算。

新版合同验证器不信任合同中保存的开发期指标。它会从合同自己的冻结输入副本重新读取中心参数、暖机气象、
开发期气象和开发期流量，重新模拟中心及全部1,024个候选；保存的效率或平均流量与重算值相差超过
`1e-12`即拒绝，再只用重算值重建最终候选对。生成方法、随机种子1、归一化方式、距离、目标函数、并列规则
和“平均流量仅作诊断”也逐项核对。

## 过程噪声和观测噪声如何给定

过程噪声先在方差比例 `10^-8、10^-7、10^-6、10^-5、10^-4、10^-3、10^-2` 上搜索。每个比例乘以下列五个
状态尺度的平方：土壤田间持水量、积雪持水比例乘土壤田间持水量、土壤田间持水量、快流阈值与渗漏率及1的
最大值、渗漏率除慢流退水系数与1的最大值。十个汇流记忆状态的过程方差固定为零。搜索所得最佳比例及其相邻
三个比例进入正式合同；同一编号的绝对协方差在全部参数向量中完全相同。

观测噪声表示测量误差和过程模型未表达误差的合并效果。先计算中心模型开发期残差的
`1.4826 × 残差中位绝对偏差`，下限为0.05毫米每天，再乘0.25、0.5和1.0。七个过程方差比例与三个观测
标准差组成21个单滤波器组合，按开发期逐日高斯对数似然平均值选择一组。观测噪声随后对五种正式方法保持
相同。每个流域的完整十五乘十五过程噪声协方差、观测噪声标准差和方差写入
`process_noise_covariances.csv` 与 `observation_noise.csv`。

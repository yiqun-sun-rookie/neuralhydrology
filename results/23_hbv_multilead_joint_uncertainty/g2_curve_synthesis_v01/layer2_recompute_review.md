## 复算方法（独立实现声明）

- 输入只用 4 个格各自 `evidence.npz` 里的原始数组：`candidate_daily_log_likelihoods` (12 块×3 真值×总天数×3 候选)、`stage_start_days`、`stage_end_days`、`adaptation_days`、`truth_candidate_indices`，以及 `config_snapshot.json` 的 bootstrap 段（replicates=20000，种子=3150000+格序号，已逐格核对：格2→3150002、格9→3150009、格13→3150013、格17→3150017）与判定阈值。
- 评分窗、阶段内累计、严格排名（rank = 含真候选自身的 `cum ≥ true_cum` 计数，rank==1 即严格第一，平手算输）、首稳日（尾部后缀全 rank1 的最早 1-based 日，否则 −1）、稳定判定（首稳日 ≤ 评分日数−5+1 且末日 margin>0）、T=5+首稳日、删失、分位数（numpy 线性插值）、区块 bootstrap（12 个块内稳定比例，`default_rng(seed+stage_index)`，`integers(0,12,(20000,12))`，重采样均值取 [0.025,0.975] 分位）全部为自写 NumPy 代码，未调用 `score_candidate_log_likelihoods` / `g2_curve_summary.py` / `run_g2_curve_summary.py` 的任何函数。
- 附加交叉核验：从原始逐日似然独立推导出的 `first_stable`、`stable`、逐日 margin 三个中间数组，与 evidence.npz 内密封的对应派生数组逐元素完全一致（margin 最大绝对差 = 0.0）——密封派生数组与原始数组内部自洽，汇总不是只在派生层上自我一致。
- 对照精度：所有字段先按 ≤1e-9 容差比对，随后又做了一轮逐位（==）比对，全部通过（含 bootstrap 下界）。

## 定义理解歧义记录（最终数字虽一致，仍如实报告）

1. **bootstrap 阶段种子偏移**：阶段 i 的种子 = seed + stage_index（0 计），即阶段 2→+1、阶段 3→+2，与运行器 `int(bootstrap_seed) + stage_index` 一致；按 +1/+2 实现后 bootstrap 下界逐位吻合，反向证实了这一解读。
2. **真候选取值日**：定义为"该阶段首评分日（start+5）的 truth_candidate_indices 值"；复算中额外断言了每阶段整个评分窗内真候选索引恒定（4 格×3 阶段全部通过），本数据上无实质歧义。
3. **rank 含自身**：`rank = sum(cum >= true_cum)` 把真候选自身计入（恒 ≥ 自己），rank 最小为 1；错候选与真候选打平（==）时 rank≥2，平手判负。若写成 ">" 会放松判定。
4. **稳定门槛边界**：`first_stable ≤ 评分日数 − 5 + 1` 用 min(5, 评分日数)=5（4 格评分日 10~175 均满足），末日 margin 用严格大于 0；margin 只查末评分日，不查稳定窗内每日。
5. **分位数与删失**：删失（−1→NaN）不进分位数，但进 n_total 与删失比例分母；分位数用 numpy 默认线性插值。pooled = 阶段2 展平 36 + 阶段3 展平 36 拼接（拼接顺序不影响分位数）。

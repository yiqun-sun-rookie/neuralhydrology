# Results Directory Policy

`results/` is the canonical long-term output storage.

Use structure:
- `results/01_caravan_global/`
- `results/02_mamba_camels_us/`
- `results/03_mamba_camelsh/`
- `results/04_namou_kuwei/`
- `results/05_full_531_basins/`
- `results/06_haihe_river/`
- `results/07_hydroagent/`
- `results/mts_mamba_global_transfer/`

Completed runs are archived under each idea, typically at `results/<ID>_<idea>/runs/`.

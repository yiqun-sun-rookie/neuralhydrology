# 最近三十天平均后验概率预报读出设计

状态：结果前设计；正式结果产生后不得改窗口、规则或门槛。

## 1. 唯一目标

在不修改完整状态交互、候选滤波器、似然、同化期模型概率递推和预报期单位转移的前提下，检验能否避免同化末日单日噪声造成的候选误识别，并把参数识别转化为更低的三日和七日预报误差。

## 2. 结果前固定规则

- 一日预报：保持当前完整状态交互后验加权，逐位不变。
- 三日和七日预报：对同化最后三十天的候选后验概率逐候选取算术平均，选择平均概率最高的候选预报。
- 三十天包含同化末日；若历史不足三十天则拒绝运行，不缩短窗口。
- 平票选择候选顺序中最靠前者，与 NumPy `argmax` 契约一致。
- 预报期候选概率不递推，模型转移为单位矩阵，不混合候选状态。
- 不使用未来流量、未来真值或正式区块结果选择规则。

## 3. 开发依据，不作为正式证据

旧八个开发区块中，三十天平均概率保持 `24/24` 次正确识别。对上一轮正式确认中发生末日误识别的六个唯一区块进行只读历史重建后，三十天平均概率纠正 `6/8` 次误识别，并未把同一区块内原本正确的 `10` 次改错。

只把这六个可修复索引替换为三十天平均概率选择时，一日保持当前方法不变，三日和七日均方根误差点估计分别降低 `1.0582%` 和 `3.5594%`。这些数字只用于提出本设计；正式判断只使用全新随机区块。

## 4. 独立确认

- 九十六个全新匹配区块，每个区块三个真值试验，共二百八十八个试验。
- 区块编号从 `g3_temporal_confirmation_block_001` 到 `g3_temporal_confirmation_block_096`。
- 降雨、过程噪声和观测噪声种子分别从 `7411001`、`7412001`、`7413001` 连续取九十六个整数。
- 共享区块自助抽样二万次，种子 `7414001`。
- 候选、三阶段切换、五百四十日同化、噪声、参数间距和一日、三日、七日预见期保持不变。

## 5. 保留门槛

平方误差差定义为“新读出减对照”，负值有利于新读出。百分之一均方根误差改善对应平方误差边界 `-0.0199 × 对照均方误差`；百分之一均方根误差损害对应 `+0.0201 × 对照均方误差`。

只有以下条件全部满足才保留：

1. 一日预报与当前完整状态交互后验加权最大绝对差不超过 `1e-12`。
2. 三十天平均概率最高候选识别正确率不低于 `95%`，即至少 `274/288`。
3. 三日相对当前完整状态交互后验加权的平方误差差百分之九十五区间上界低于百分之一损害边界。
4. 七日相对当前完整状态交互后验加权的区间上界低于百分之一改善边界。
5. 三日相对无状态交互后验加权的区间上界低于百分之一损害边界。
6. 七日相对无状态交互后验加权的区间上界低于百分之一改善边界。
7. 正式包完整、所有数值有限、候选与真值顺序一致、独立复算逐项通过。

任一条件失败即不保留；不在正式结果上改成十四天、六十天或其他窗口，也不新增置信阈值。

## 6. 解释边界

本方法只是在预报输出端用三十天平均后验概率选择候选，不改变交互式多模型同化结构。即使通过，也只能说明在当前理想参数切换条件下，时间稳健的参数读出改善了三日和七日预报；不能外推到真实流域、其他候选间距、其他噪声或其他切换周期。

## 结论

正式候选是“一日保持后验加权，三日和七日使用最近三十天平均后验概率最高候选”。它直接针对末日瞬时误识别，且不改变完整状态交互模型结构。

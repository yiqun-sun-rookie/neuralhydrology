## 二、主判据（配对提升，跑前冻结）

对每个任务（流域 × 种子 × 臂），对每个非中档档位 L ∈ {低 m=0.1, 高 m=10}：

```
D_L = mean(该档候选后验 | 切换情景, L 的真值段)
    - mean(同一候选后验 | 空对照,   同一批日子)
```

L 的真值段：低档 = 第 2、6 段（第 180–359、900–1079 天）；
高档 = 第 3、5 段（第 360–539、720–899 天）。两情景取**同一批日历日**，
故气象强迫、观测噪声实现、季节全部对齐，差值只反映真值档不同。

**通过条件（每臂、每档位分别判，全部满足才算该臂通过）**：

1. 中位提升 `median(D_L) > 0.10`；
2. 提升为正的任务比例 `≥ 0.90`；
3. **安慰剂门**：中档段同样构造的 `D_中`（两情景真值相同，理论应为 0）
   满足 `|median(D_中)| ≤ 0.05`。任一臂违反即判"对比构造有系统偏置"，
   本轮结论作废、只报数字。

三条阈值均在看到种子 2/3 任何数字之前冻结；发现集上对应值为
+0.266 / +0.433（中位）、88/88（比例）、−0.029（安慰剂），故 0.10 与 0.90 是
真实的门槛而非事后贴合。

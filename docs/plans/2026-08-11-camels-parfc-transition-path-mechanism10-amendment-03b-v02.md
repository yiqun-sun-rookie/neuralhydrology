## 2. 实际权重合同

九条来源到目标路径记为 `b=(i,j)`。对数空间只执行一次全局归一，得到普通浮点路径权重 `w_ij`。定义 `N_n(z)` 为生产混合函数的实际非负权重归一：`math.fsum` 求总量后逐项相除。

```text
d_ij         = N_9(w)_ij
mu_raw_j     = math.fsum_i(w_ij)
beta_j       = N_3(mu_raw)_j
alpha_raw_ij = w_ij / mu_raw_j
a_ij         = N_3(alpha_raw[:,j])_i
v_ij         = beta_j * a_ij
Delta_ij     = d_ij - v_ij
```

`mu_raw_j=0` 的目标保持非活动。目标内状态和协方差只使用 `a`；嵌套全局矩只使用 `beta`；直接全局矩只使用 `d`。保存和下一日递归的候选普通概率仍为 `mu_raw`。稳定对数概率只保存和评分，不参与状态混合或递归。

## 3. 平移不变混合均值

每次混合选第一个正权重分量状态 `r` 为参考。混合函数对归一后实际权重 `z` 计算：

```text
m[k] = r[k] + math.fsum_c(z_c * (x_c[k] - r[k]))
```

协方差仍为：

```text
C[p,q] = math.fsum_c(
    z_c * (P_c[p,q] + (x_c[p]-m[p])*(x_c[q]-m[q]))
)
```

最后执行 `0.5*(C+C.T)`。同一状态的所有分量必须精确返回该状态；大共同偏移不得放大协方差允许界。该更正同时用于 P 的直接九路径、目标内层和目标外层混合，不进入基线 C 的标准交互路径。

## 5. 独立权重门

```text
rho_w = 2*gamma_512/(1-gamma_512)
Ew_ij = rho_w*max(|d_ij|,|v_ij|) + 64*eta
```

逐路径要求 `|Delta_ij| <= Ew_ij`。总权重要求：

```text
math.fsum_ij(|Delta_ij|) <= math.fsum_ij(Ew_ij)
```

权重门不能由状态或协方差尺度替代。从一个活动路径向另一个活动路径转移 `1e-9` 且保持总和为一，必须被拒绝。

## 6. 状态逐元素门

路径状态为 `x_b[r]`；直接与嵌套状态为 `mD[r]、mN[r]`。

```text
ADm[r] = sum_b |d_b*x_b[r]|
ANm[r] = sum_b |v_b*x_b[r]|
Bm[r]  = max(1e-12, gamma_1024*(ADm[r]+ANm[r]) + 2048*eta)
```

逐元素要求：

```text
|mD[r]-mN[r]| <= Bm[r]
```

## 7. 协方差逐元素门

使用生产算法实际得到的直接均值 `mD`、目标均值和协方差 `g_j、G_j`、嵌套均值 `mN`。先计算未对称化的中心条件尺度：

```text
ADC_raw[p,q] = sum_b |d_b| * (
    |P_b[p,q]| + |(x_b[p]-mD[p])*(x_b[q]-mD[q])|
)

AIN_raw[p,q] = sum_j |beta_j| * sum_i |a_ij| * (
    |P_ij[p,q]| + |(x_ij[p]-g_j[p])*(x_ij[q]-g_j[q])|
)

AOUT_raw[p,q] = sum_j |beta_j| * (
    |G_j[p,q]| + |(g_j[p]-mN[p])*(g_j[q]-mN[q])|
)
```

不要求输入协方差逐位对称。对每个元素使用两条对称分支中较大的尺度：

```text
ADC[p,q]  = max(ADC_raw[p,q],  ADC_raw[q,p])
AIN[p,q]  = max(AIN_raw[p,q],  AIN_raw[q,p])
AOUT[p,q] = max(AOUT_raw[p,q], AOUT_raw[q,p])

BC[p,q] = max(
    1e-11,
    gamma_4096*(ADC[p,q]+AIN[p,q]+AOUT[p,q]) + 8192*eta
)
```

逐元素要求：

```text
|CD[p,q]-CN[p,q]| <= BC[p,q]
```

由于均值采用平移不变公式，完全相同的大状态偏移产生零中心离差；该界不会因共同偏移本身变大。权重路线、均值路线、两层协方差路线及归一残差已经通过 `k_C=4096` 的总运算图上界合并，不再另加未经证明的原始二阶矩项。

# 按预见期使用识别结果的预报读出设计 — 2026-07-27

状态：**设计冻结；在独立新随机种子确认通过前，不进入核心方法。**

## 1. 唯一目标

完整状态交互更新已经能把真实参数候选识别得更集中。本轮不再修改候选滤波器、状态交互公式、似然、模型转移矩阵或同化阶段概率递推，只解决一个问题：

> 怎样把同化末日已经获得的正确参数识别，稳定转化为更低的确定性多日预报误差。

当前预报合同保持不变：预报期模型转移为单位矩阵，候选概率不再递推，候选之间不混合状态。

## 2. 现有证据给出的约束

封存理想流域结果共有八个匹配区块、三个真值试验和一日、三日、七日三个预见期。

1. 完整状态交互更新在二十四次同化末日选择中全部找到真实参数候选。
2. 只使用最高后验候选并不能统一改善所有预见期：均方根误差为 `1.6534、2.7420、6.5645`；当前后验概率加权为 `1.4814、2.7462、6.6979`。
3. 真实参数候选并非每次都是误差最低的候选；一日、三日、七日分别只有 `13/24、17/24、11/24` 次误差最低。因此，仅凭“识别正确”无法在每一个样本上数学保证预报更好。
4. 把完整状态交互形成的三个候选预报等权平均，一日均方根误差降到 `1.2320`，但三日和七日恶化到 `2.9099、7.4109`。
5. 把候选混合状态直接交给最高后验参数预报，一日均方根误差恶化到 `1.8957`。因此，不采用状态强制合并。

这些事实说明：一日主要受状态与噪声误差影响，多候选平均有利；三日和七日参数差异逐渐重要，应该使用已识别出的参数候选。

## 3. 比较过的三种方案

### 方案一：所有预见期都选择最高后验候选

优点是改动最小、解释直接。缺点是封存诊断已经显示一日误差从 `1.4814` 增加到 `1.6534`，不能保留。

### 方案二：识别后强制合并或重置状态

可把最高后验参数与混合状态组合，或者在识别后关闭状态交互。前者的封存开发诊断已经恶化一日误差；后者会改变同化路径和切换后的重新识别行为，超过本轮“尽量不改交互结构”的边界。

### 方案三：按预见期改变最终组合规则

同化和交互全部不动，只在已经生成逐候选预报后采用以下确定规则：

- 一日：三个候选等权平均；
- 三日和七日：使用同化末日最高后验候选；
- 三日和七日使用同一个候选索引，不读取未来流量、未来真值或未来观测。

封存开发数据上的均方根误差为 `1.2320、2.7420、6.5645`，相对当前完整状态交互预报的三个点估计均降低；相对无状态交互预报 `1.6499、2.7523、6.5957` 也均降低。

**选择方案三。** 它只增加一个纯预报读出函数，不改变交互式多模型主体。

## 4. 软件设计

新增独立模块 `src/hbv_multilead_joint_uncertainty/lead_adaptive_readout.py`，不修改 `forecast_from_posterior()` 的默认返回值或历史结果。

纯函数接收：

- 同化末日候选概率，一维；
- 逐预见期、逐候选预报，二维；
- 预见期整数向量；
- 显式的预见期到组合规则映射。

函数返回：

- 新的逐预见期组合预报；
- 每个预见期实际使用的候选权重；
- 最高后验候选索引。

输入必须有限、维度一致、概率非负且和为一；规则只允许“等权平均”和“最高后验候选”。后验并列时固定选择候选顺序中最靠前者。函数不得修改输入。

当前正式规则映射固定为：

```text
一日 -> 等权平均
三日 -> 最高后验候选
七日 -> 最高后验候选
```

## 5. 独立确认实验

### 5.1 开发与确认严格分离

上述八个旧区块只用于提出规则，不再用于正式保留判定。正式确认使用三十二个全新匹配区块、三个真值试验及不重复的强迫、过程噪声、观测噪声和自助抽样种子。

候选参数、噪声水平、阶段长度、观测强度和一日、三日、七日预见期保持不变。这样只检验新读出能否在同一理想科学问题上复现。

### 5.2 正式比较

主要方法：

1. 完整状态交互更新加原后验概率加权；
2. 完整状态交互更新加按预见期读出；
3. 无状态交互更新加原后验概率加权。

参照方法：

4. 已知真实候选；
5. 固定等权平均。

### 5.3 预注册保留门槛

以匹配区块为自助抽样单位，三十二个区块共享同一套两万次重采样索引。平方误差差值均写为“新读出减对照”，负值有利于新读出。

新读出只有同时满足以下条件才进入核心方法：

1. 相对无状态交互更新，至少一个预见期的百分之九十五区间完全低于“均方根误差改善百分之一”对应的平方误差边界；
2. 三个预见期相对无状态交互更新的区间上界都不超过“均方根误差恶化百分之一”对应的平方误差边界；
3. 三日和七日的归一化平方误差平均差的百分之九十五区间上界低于零，证明使用最高后验候选在多日预报上形成可检测的联合改善；
4. 三日和七日使用的最高后验候选正确率不低于百分之九十五；
5. 新读出相对当前完整状态交互更新至少一个预见期达到实质改善，且其余预见期没有实质损害。

任何一项不满足，都把本方案记为负结果，不继续调阈值、改预见期规则或在正式结果上重新选择超参数。

## 6. 完整性与范围

- 一项实验编号对应一份配置、一个输出目录和一行登记表。
- 设计、实现、测试、配置和运行器在正式运行前提交。
- 正式输出保存配置快照、环境、逐候选预报、原后验概率、新读出权重、候选索引、真值、逐样本平方误差、共享自助抽样索引和全部校验值。
- 旧封存实验只读，不覆盖、不重跑。
- 本轮仍是理想流域确认；通过后只能说明该读出在同一理想参数切换问题上有效，不能直接外推到实际流域。

## 结论

本轮不再修改交互式多模型本身。唯一新增内容是按预见期使用现有候选预报：一日用等权平均抵消状态与噪声误差，三日和七日使用已经识别出的最高后验参数候选。只有全新随机种子确认同时证明“至少一项实质改善、所有预见期无实质损害、三日和七日联合改善”，才认为正确参数识别真正转化成了更好的预报。

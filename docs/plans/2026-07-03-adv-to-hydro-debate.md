# ID05 对抗鲁棒性 → 真水文重构：思考与辩论 loop（2026-07-03）

供 /goal 迭代使用。**这是一个"想清楚 + 辩论"的 loop，不是写正文的 loop。判定标准和硬护栏是硬约束；其余自由探索。**

## 背景（为什么开这个 loop）
多轮辩论后三个质疑成立：
1. "攻击→模型下降"是同义反复；"雪区下降更多"≈半同义反复（输出越依赖输入 → 梯度越大 → 越好打）。
2. "准≠稳 / 过程依赖 / 长记忆"是把**一条**真发现（雪区攻击换打气温、毁融雪峰）撑成的大框——飘、硬凑。
3. "对抗/安全"威胁模型在水文里**没有对手**，是从图像领域借来的、虚的。真正有意义、且不靠对手的核是：**保矩绕过质检、敏感度诊断、真实输入误差传播**。

## 目标
不写论文正文。**用迭代辩论收敛出一个"不飘、不是同义反复、真水文"的论文框架**——或诚实结论"守方法论文 + 一节干净水文"。每一步靠证据或判定实验，不靠叙述。

## 判定：一个候选框架/主张"成立"当且仅当同时满足
1. **不是同义反复**——不是"攻击造成损伤"或"依赖多→好打"的换皮。
2. **不飘**——每句能溯到实测证据或明确标注的假设；不叙述打不开的模型内部机制。
3. **可证**——现有证据能支撑，或有一个明确、可判定的实验能证/证伪它。
4. **真水文**——水文学家会 care，不是 ML 套壳。
5. **超 Yang 2026**——相对已有工作有增量。
任一不满足 → 砍掉或降级为假设。

## 两个已识别的判定实验
- **A 混淆检验（零 GPU，起手做）**：控住"输出对输入的依赖度 / 流量方差 / 序列信号量"后，雪区脆弱是否仍显著？→ 判"拟合最好处最脆"是真发现还是同义反复。这是整个框架的地基。
- **B 季节窗口归因（需 GPU）**：把攻击限制/归因到积雪累积-融雪窗 vs 其他时段，破坏力是否集中？→ 判"融雪时机机制"是真的还是脑补。现有 delta 因 L∞ 饱和证不了，必须重跑。

## 候选框架池（辩论对象，可增删）
- **F1（缩）**：只讲"雪区命门在气温/融雪峰"这一条干净小发现，不拔高。
- **F2（质检失效）**：以"矩质检拦不住的输入误差结构"为主线——**不需要对手**，操作性强。
- **F3（真实误差传播）**：重心挪到"真实结构 forcing 误差怎么传播、在哪最放大、质检能不能拦"——有几十年文献（Kavetski/Renard/McMillan）的正经水文方向。
- **F4（诊断仪）**：攻击当探针，读出模型学到的敏感度结构（通道/流域/特征）。
- 组合或全新框架自由提。

## 硬护栏
- 一切表述停在**输入-输出层**，不碰模型内部表征。
- 每个结论都要过一遍**"没有对手，它还成立/有意义吗"**——过不了的，说明依赖了虚的安全叙事。
- **不靠还没跑的实验支撑主张**：要么先跑，要么明标为假设。

## 每轮纪律
①提出/精化一个候选框架，或跑一个判定它的分析/实验 →②独立审查（是不是同义反复 / 飘 / 证不了 / over-claim / 没水文味 / 没超 Yang）→③独立验证这些审查（对抗性复核，审查本身对不对，必要时派子代理/盲评 panel）→成立的下轮修或砍，不成立的丢、不纠缠 →④回看目标别漂 →⑤按判定决定收敛还是带清单进下轮。同一问题卡 5 次停下重估方法。

## 收敛
当某框架连续约 2 轮独立对抗审查不倒，或判定实验 A/B 出结果 settle 掉，或诚实结论 = 没有超出"一条小发现"的非飘水文故事（则守方法论文 + 一节干净水文）。收敛即停，输出：**定下的框架 + 支撑证据 + 还需的实验 + 投稿含义**。

## 进度记录

### Round 1（2026-07-03）— 判定实验 A：雪区脆弱是真发现还是同义反复
脚本 `src/adversarial/scripts/analyze_tautology_confound.py`（零 GPU）；4-agent 独立复核（数字复算 + 检察官/辩护/方法学盲辩），全部 `mixed`、实质一致，数字全复现。
- **数字**：D_APGD~雪 控 skill +0.61 → 控 D_rs100 +0.44 → 控 D_FGSM +0.21；D_FGSM~雪 +0.59；rank(D_APGD,D_FGSM)=0.984（单步 FGSM 已达 81% 伤害）；amp(协同溢价)~雪 +0.16；temp_share~雪 +0.69（控 skill +0.68），temp_share~伤害仅 +0.12。
- **判定结果**：
  - ❌ **"fits-best-most-fragile / 脆弱性分布" 的幅度主张 = substantially 同义反复**（伤害幅度≈模型梯度，梯度在雪区最大是任务要求；D_rs100 是 strawman 弱控制，"存活+0.44"只否掉没人主张的各向同性版本）→ **砍掉当 headline**。
  - ✅ **唯一干净存活 = 通道身份（雪→攻击打气温，与伤害幅度正交：temp_share~雪+0.69 但 ~伤害+0.12）**。但现仅 107 流域 + 用攻击导出的归因（skeptic 可诟病 attack-dependent）。
- **框架收窄**：从 "how much（脆弱性分布）" 转向 "**where（气温/融雪通道）**"。
- **→ Round 2（三方一致的决定性检验）**：无优化器的**遮挡/置换通道重要性**（zero/shuffle 每通道测 NSE 掉多少，纯前向）在**全 531 流域**算"气温 vs 降水依赖份额"，控住总输入依赖度后气温份额是否仍随雪上升。同时破 circularity + 补 107→531 + 用有界份额替掉重尾 amp。

### Round 2（2026-07）— 无优化器遮挡（zero）+ 独立复核
脚本 `run_occlusion_importance.py`（zero 模式）+ `analyze_occlusion_channel.py`；3-agent 复核（数字/方法/triviality/框架收敛）。
- **数字全复现**：temp_share~雪 | nse+total_dep = +0.531（p=4.8e-40），与 total_dep 正交(+0.17)，雪 temp_share 0.48 vs 非雪 0.10-0.17，温度>降水 雪62%/非雪5%，遮挡 vs 攻击归因 +0.38。
- **真问题（材料级，已修）**：zero 遮挡用**全局标准化均值**（非每流域气候均值）→ 对冷雪流域=暖阶跃冲击、随雪增长、total_dep 控不掉。
- **真 triviality**：裸"LSTM 在雪区用气温"是度日模型常识（Lees2022/Kratzert2019 已展示 LSTM 用雪信号），非发现；非平凡只在"skill↔vulnerability 同通道 + 可靠性后果"。

### Round 3（2026-07）— shuffle 遮挡修混淆，结果反转增强
`run_occlusion_importance.py --mode shuffle --k 3`（时间置换、保流域分布、无阶跃）。
- **temp_share~雪 | nse+total_dep = +0.841（p=6e-143）**，比 zero(+0.53) **更强**；与 total_dep 更正交(+0.086)；雪 temp_share 0.54；温度>降水 雪62%/非雪3%；zero-vs-shuffle 一致 +0.735。
- **判定**：混淆是真的但作用是稀释非虚高——**通道身份非阶跃 artifact**，无优化器/in-distribution/全531/扣依赖度后 +0.84。**通过判定①（非同义反复，与幅度正交）+③（可证、非 attack-derived）。**
- **仍开**：判定④/⑤ 的 triviality/novelty——非平凡 payload = 可靠性/误差传播（需真实温度误差实验：雪区预测对真实幅度温度误差是否不成比例敏感）+ 相对 Lees2022/Kratzert2019 的增量。
- **框架收敛到 F3（可靠性/误差传播）**：skill 和 error-sensitivity 都落温度→雪区预测对温度误差不成比例敏感（温度恰是山区最不可信+升温情景最关键强迫）。empirical 核已锁，framing 待 R4 的 novelty 核查 + 真实误差实验坐实。

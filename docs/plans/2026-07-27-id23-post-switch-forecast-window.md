# 参数切换后早期预报窗口实施计划

## 目标

在旧八个封存区块上，比较完整状态交互与无状态交互在两次参数切换
后前七天发出的多步预报，并以固定门槛决定是否进入新正式确认。

### 任务一：固定起点预报收集

- 实现显式预报起点收集器。
- 先写失败测试，覆盖起点索引、与全起点运行逐位一致、输入候选库
  不变和未来观测隔离。

### 任务二：开发运行器

- 直接读取封存强迫、观测、初始状态和最终预报证据。
- 只重放主参数候选族的完整状态交互与无状态交互。
- 保存两个切换窗口的逐起点预报、概率、候选预报、真值和误差。
- 用第 `539` 日逐位核对历史封存结果。

### 任务三：条件式继续

- 三日和七日均至少改善 `1%` 且一日损害不超过 `1%`：冻结全新
  随机区块正式设计。
- 任一失败：记录负结果并停止，不调整切换窗口。

## 结论

先回答识别优势是否只存在于参数切换后的适应期，再决定是否投入
新正式实验。

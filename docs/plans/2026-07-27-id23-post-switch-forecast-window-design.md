# 参数切换后早期预报窗口开发设计

> **2026-08-01 范围更正：** 这里的“参数切换”仅指合成真实系统按预先设定的阶段改变固定参数，不是后验概率或加权参数摘要每天更新。本文档的逐候选轨迹加权结果只保留为局部多轨迹集合对照，不能定义标准完全交互多模型方法的最终状态，也不能替代全 540 天、15 个状态的同日全局后验误差比较。

状态：结果前开发设计；旧八个区块只作筛查。

## 1. 问题

现有一日、三日和七日预报只从第 `539` 日发出，即最后一次参数
切换后第 `180` 天。无状态交互候选已经得到完整阶段长度来调整
状态，因此这个时点不能回答“完整状态交互更快认对参数是否在刚
切换时改善预报”。

## 2. 固定评估

- 同化、候选、完整状态交互、无状态交互、模型概率递推和预报期
  单位转移全部不变。
- 参数切换发生在活动日索引 `180` 和 `360`。
- 在每次切换后的第 `0` 至第 `6` 天发出预报，即起点
  `180..186` 和 `360..366`。
- 每个起点都评价一日、三日和七日预报。
- 只使用该起点及以前的观测；预报不读取未来流量。
- 额外重算第 `539` 日，仅用于与封存最终预报逐位交叉核对，不进入
  切换窗口指标。
- 不加残差校正，不改概率读出，不选择候选，不调整窗口。

选择七天窗口的依据是已有独立结果：切换后正确参数的中位后验概率
约在第 `2` 天达到 `0.94`，第 `5` 天达到 `0.995`。窗口覆盖这一
完整快速识别过程，并在看本轮预报结果前固定。

## 3. 对照

开发筛查只比较：

1. 完整状态交互后验加权预报；
2. 无状态交互后验加权预报。

若开发筛查通过，正式确认再加入不使用状态交互且不使用后验概率的
等权独立候选对照。开环预报不进入本轮机制筛查。

## 4. 开发门槛

必须同时满足：

1. 第 `539` 日完整状态交互和无状态交互候选预报、最终概率及组合
   预报与封存证据最大绝对差不超过 `1e-12`；
2. 所有切换窗口目标索引合法，全部数值有限，且未来观测隔离测试
   通过；
3. 一日完整状态交互相对无状态交互的均方根误差损害不超过 `1%`；
4. 三日完整状态交互相对无状态交互的均方根误差至少降低 `1%`；
5. 七日完整状态交互相对无状态交互的均方根误差至少降低 `1%`。

任一门槛失败即停止该评估时点路线；不在结果后缩短窗口、删除某次
切换或只报告有利预见期。

## 5. 证据边界

开发结果只说明旧八个理想合成区块是否存在值得独立确认的信号。
通过不等于方法成立；必须使用全新随机区块和配对区块自助区间。

## 结论

本轮不改方法，只把预报放到参数识别真正有用的切换适应期。若完整
状态交互仍不能在三日和七日同时改善至少 `1%`，则“更快认对参数”
在当前理想实验中也没有可检测的点预报价值。

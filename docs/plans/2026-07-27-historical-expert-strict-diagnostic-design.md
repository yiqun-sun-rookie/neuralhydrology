# 历史分段专家严格屏蔽、嵌套复现与五轮迭代设计

**日期：** 2026-07-27

## 1. 目标

最终目标是得到一个只使用 Maurer 五项逐日气象驱动和 27 项流域静态属性的历史分段专家模型。最低要求是内部验证效果与经典长短期记忆网络相当；更高目标是超过经典模型，且逐流域中位提升越大越好。

在候选训练前必须先证明：

1. 已训练的分层高信息量历史模型可以被完整、可审计地执行七种非空分支屏蔽；
2. 一个包含但完全停用中期和远期模块的近期单分支嵌套控制，可以逐元素复现经典模型训练；
3. 三个同构专家的参数量、输入边界和训练协议已冻结。

分支屏蔽和严格复现属于前置诊断，不计入最多五次候选迭代。

## 2. 数据与封存边界

- 仅允许模型读取 Maurer 五项气象驱动和 27 项静态属性。
- 训练目标来自冻结的内部目标包，目标期为 1999-10-01 至 2006-09-30。
- 内部验证期为 2006-10-01 至 2008-09-30，共 60 个流域、43,860 条逐日预测。
- 正式评估期 1989-10-01 至 1999-09-30 始终封存。
- 禁止读取 `usgs_streamflow`、`camels_hydro`、`*_obs_eval.parquet` 和正式评分答案。
- 不修改版本 03、04、05 的代码、配置、结果或任何公平基准冻结文件。

## 3. 稳定实验编号

| 编号 | 类型 | 含义 | 是否占用五轮候选额度 |
|---|---|---|---|
| `D06-MASK` | 只读诊断 | 版本 05 检查点七种分支屏蔽 | 否 |
| `R06-NEST` | 严格复现 | 经典近期模型与嵌套近期控制锁步训练 | 否 |
| `E06-I01` | 候选迭代 1 | 三个同构专家的冻结首轮 | 是 |
| `E06-I02` 至 `E06-I05` | 条件候选迭代 | 每轮只依据上一轮证据改变一个主要因素 | 是 |

每个编号必须有独立配置快照、输出根目录、清单和登记行。不得覆盖既有结果。

## 4. 七种分支屏蔽

屏蔽发生在三个编码器输出已经形成、但尚未进入输出层的位置。模型处于评估模式，随机丢弃关闭；被屏蔽分支的表示置零，输出层偏置保留一次。

七种非空组合是：

1. 仅近期；
2. 仅中期；
3. 仅远期；
4. 近期加中期；
5. 近期加远期；
6. 中期加远期；
7. 近期加中期加远期。

完整组合必须逐元素复现版本 05 已保存预测。每个组合报告中位纳什－萨特克利夫效率系数、相对完整候选和经典 256 单元模型的逐流域中位差、流域胜率及预测变化幅度。

屏蔽结果只能说明当前共同训练检查点依赖哪些分支，不能作为分支因果收益或损害的证据。

## 5. 严格近期单分支嵌套控制

嵌套控制包含近期、中期和远期模块，但整个训练中只执行近期路径：

- 活跃参数与经典 256 单元模型完全相同，共 297,217 个；
- 中期和远期参数 `requires_grad=False`，不进入优化器；
- 前向只读取 270 天近期气象驱动和静态属性；
- 随机丢弃只作用于 256 维近期表示；
- 参数顺序、批次顺序、学习率、损失、梯度裁剪和最终检查点规则与经典模型完全相同。

经典模型和嵌套控制使用成对锁步训练。每个批次在两个前向之间保存并恢复中央处理器和图形处理器随机数状态。前十次更新逐项比较预测、损失、梯度、裁剪后梯度、Adam 状态和更新后参数；以后每轮比较完整活跃状态，最终比较全部验证预测。

严格通过容差为零：

- 输入键、批次索引、随机数状态、随机丢弃掩码完全相同；
- 初始参数、预测、损失、梯度、优化器状态和最终参数逐元素相同；
- 43,860 条预测和 60 个逐流域指标逐元素相同。

任何不相等都停止候选训练并进入根因诊断。同一根因连续三次修复仍失败时停止补丁式修改，重新审核架构。

## 6. 候选迭代 1

三个专家使用完全相同的单层长短期记忆网络结构和隐藏宽度：

- 近期：滞后 0 至 269 天，270 个逐日时间步；
- 中期：滞后 270 至 1824 天，沿用版本 03 的 60 个均值时间块；
- 远期：滞后 1825 至 3649 天，沿用版本 03 的 60 个均值时间块；
- 每个时间步输入均为五项气象驱动加重复的 27 项静态属性，共 32 维；
- 每个专家隐藏宽度均为 256；
- 三个 256 维状态组成一个 768 维线性输出，只产生一个流量。

精确参数量：

- 三专家候选：891,649；
- 最近的经典容量控制使用隐藏宽度 455：890,436；
- 差异 1,213，即候选参数量的 0.136%。

候选和新鲜经典对照使用按随机种子、训练轮次、批次和分支固定的独立随机丢弃流，保证近期分支的随机丢弃不受其他分支形状影响。

## 7. 候选迭代门槛

候选迭代 1 先运行随机种子 100，必须同时满足：

- 相对经典 256 单元模型的逐流域中位差不低于 +0.01；
- 相对参数量控制的逐流域中位差大于 0；
- 相对简单历史后期拼接模型的逐流域中位差大于 0；
- 相对经典 256 单元模型的流域胜率不低于 0.55。

全部通过才运行随机种子 200 和 300。未全部通过时，允许依据证据进入下一候选迭代，但每轮只能改变一个主要因素，并必须使用新的实验编号、配置和结果目录。

最多运行 `E06-I01` 至 `E06-I05` 五轮候选。任何内部结果都不能表述为 531 流域正式基准结论。

## 8. 候选迭代原则

后续迭代因素必须由上一轮证据决定，优先顺序是：

1. 优化稳定性和共同适应；
2. 融合方式；
3. 历史时间块分辨率；
4. 容量分配；
5. 正则化。

不得在同一轮同时改变多个无法分离的因素。达到经典模型相当水平并不自动停止；只要仍有候选额度且证据支持，继续追求更大的稳定提升。

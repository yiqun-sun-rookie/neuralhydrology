# HBV 合成真实参数切换的状态响应因果对照：封存结论

## 结论

**不通过作为一般“状态更新精度”实验的干净真值条件；通过作为已明确标注的突变参数压力测试。**

当前三阶段水文局水量平衡模型（Hydrologiska Byråns Vattenbalansavdelning，HBV）的合成真值生成器，在“等效参数组1切换到训练中心参数”时，不仅改变后续模型参数，还会在当天气象强迫进入前按新参数的物理取值范围直接裁剪旧状态。48个匹配事件中有16个事件发生这种初始状态域投影，违反了“干净状态精度真值应有零个初始新参数域投影事件”的冻结判断门。

因此，下一项状态更新精度实验应另建为：**固定真实参数，仅注入预先定义且物理可解释的真实状态突变，再测试状态恢复**。现有三阶段结果只能回答当前HBV合成真值生成器在参数和参数域同时突变时的状态响应，不能作为低地水文模型或真实流域证据，也不包含同化方法或预报比较。

## 因果对照是否保持唯一变化因素

- 事件数：8个强迫块 × 3个真值试验 × 2个边界 = 48。
- 边界：第180—181天之间和第360—361天之间。
- 每个事件两条分支均从完全相同的切换前15维真实状态出发。
- 两条分支逐日使用完全相同的未来30天气象强迫和已保存过程扰动。
- 唯一变化：继续使用旧真实参数，或切换到新真实参数。
- 未读取观测流量或真值流量，未执行观测更新、状态同化、状态手工重置或预报。
- 新参数分支对封存30天真值的生产重建最大绝对误差为0；独立方程路径重建最大绝对误差为 `2.274e-13`。

## 隐藏的参数域投影机制

只有“等效参数组1 → 训练中心参数”发生初始投影，共16/16个该转换事件：

- 土壤含水量：田间持水容量从 `565.943809` 变为 `115.411441`。16/16个事件在当日强迫前直接减少 `277.356702–450.532369` 个模型原状态单位，相当于冻结状态标准差的 `1.502874–2.441237` 倍。
- 融水：积雪持水比例从 `0.128639390` 变为 `4.790858e-09`。3/16个事件在当日强迫前直接减少 `0.038013–0.095283` 个模型原状态单位，相当于冻结状态标准差的 `0.009233–0.023143` 倍。
- 投影函数只裁剪对应状态，没有把被裁剪的水量转入上层蓄水、下层蓄水或汇流记忆状态。
- “训练中心参数 → 等效参数组2”和“等效参数组2 → 等效参数组1”均为0/16个初始投影事件。

这解释了为何参数边界和所有状态的最大变化不同步：土壤含水量可在边界当天被投影；新的原始径流先进入最新汇流记忆状态，然后按每日移位依次传到更老的10个汇流记忆位置。后者的峰值日严格依次为第1至第10天，不应期待与参数边界同时出现。

## 验证结果

- 聚焦测试：12项通过；没有失败测试。
- 生产物理门：全部状态有限且非负；土壤含水量、融水和汇流移位满足约束；汇流记忆过程扰动严格为0。
- 独立核验：通过；使用 `hbv_joint_uncertainty.hbv_adapter.advance_state` 与 `hbv_joint_uncertainty.preflight.project_hbv_state`，未导入生产因果模块、生产运行器或任何预报模块。
- 全部证据数组的独立重算最大绝对差异：`4.547474e-13`，小于冻结容差 `1e-12`。
- 三张表、三幅正式图、结果文件散列和冻结配置均通过独立核验。
- 正式曲线图在视觉复查时发现顶部图例与标题重叠。没有覆盖或改变已核验文件；另建视觉只读目录重新渲染，并通过原分辨率人工复查。视觉只读清单绑定正式证据散列，明确 `scientific_evidence_modified=false`。

## 证据边界与下一实验

事实：上述结论只适用于当前三阶段HBV合成真值生成器及其48个匹配切换事件。

推断：参数边界后出现的延迟汇流记忆峰值来自最新原始径流差异的逐日移位，不是额外的异步参数切换。

下一实验：固定一组真实参数和状态物理域，预注册一个不依赖参数域裁剪的状态突变；最好分别设置水文蓄水扰动和汇流记忆扰动，并保证水量如何转移或注入有明确账目。先评价同日和逐日真实状态恢复，再决定是否进入预报评价。

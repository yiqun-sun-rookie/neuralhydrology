# 状态交互与候选权重二乘二预报诊断设计修正一 — 2026-07-26

状态：**在实现前冻结；本文件优先于原设计中冲突的表述。**

## 1. 解释边界

四种组合中的两个非对角组合是“末日权重重组诊断”。候选权重与候选条件状态原本在同化期间共同生成，因此非对角组合通常不对应任何自洽的滤波后验。本轮：

- 不把非对角组合称为可部署方法；
- 不把比较称为严格因果效应；
- 只回答：在已经形成的候选预报库上，替换同化末日的最终候选权重会怎样。

`C_full` 与 `C_none` 的差异同时包含同化末日候选状态均值、完整协方差以及整个同化期的交互历史。原设计中的“状态作用”统一改称：

> 同化交互路径产生的候选预报分布作用

该作用不是纯状态均值作用，也不能进一步归因给单一状态、协方差或某一天的交互。

## 2. 每项实用等效的基准

每个平方误差差都以右侧被减方法作为基准，并保存逐预见期的基准均方误差及实用等效上下界：

| 比较 | 平方误差差 | 基准 |
|---|---|---|
| 主要权重作用 | `E_none_full - E_none_none` | `none_states_none_weights` |
| 权重作用复核 | `E_full_full - E_full_none` | `full_states_none_weights` |
| 主要候选预报分布作用 | `E_full_none - E_none_none` | `none_states_none_weights` |
| 候选预报分布作用复核 | `E_full_full - E_none_full` | `none_states_full_weights` |
| 完整差异 | `E_full_full - E_none_none` | `none_states_none_weights` |
| 错误候选比较 | `E_wrong - E_true_candidate` | 真实候选预报 |

实用等效上下界仍为基准均方误差的 `-0.0199` 倍和 `0.0201` 倍。

错误候选预报距离比必须在每次匹配区块重采样后分别重算分子均方根、分母均方根及两者之比，禁止先计算区块比值再平均。分母为零时结果不得静默替换为有限数，正式统计必须明确失败或报告无法确定。

## 3. 两份封存证据的职责

理想参数切换封存证据只提供：

- 强迫、观测；
- 初始状态和初始协方差；
- 噪声自由真值和真值预报；
- 候选顺序及候选标识。

最高后验候选预报封存证据只提供交叉核对参照：

- 完整状态交互与无状态交互的每日候选概率；
- 无状态交互逐候选预报；
- 两个既有对角组合预报；
- 已保存的真值预报。

主参数候选方法必须按完整方法名称查找，禁止使用固定数组下标。新证据必须保存候选标识和同化末日真实候选标识。

直接读取理想参数切换证据不称为“重放验证”。直接数组交叉核对必须逐位相同；通过逐候选预报乘最终权重重建组合预报时使用 `rtol=0`、`atol=1e-12`。每项交叉核对都保存最大绝对误差。

## 4. 源码和资源合同

新运行器必须定义自己的源码快照清单，至少包含：

- 新诊断模块；
- 新运行器；
- 新测试；
- 候选方法构建、预报、交互多模型滤波、单模型滤波和水文状态转移的全部直接依赖。

禁止复用旧运行器的硬编码源码清单。

新配置必须冻结资源试运行证据。资源预检返回 `safe_to_run=False` 时，新运行器必须在科学计算前停止，不能只把结果写入记录。

## 5. 保存的原始证据

正式证据至少保存：

- 候选标识、同化末日真实候选；
- 两种每日概率及末日权重；
- 两种同化路径的候选末日状态均值和完整协方差；
- 两种逐候选预报；
- 四种组合预报及逐样本平方误差；
- 预报值尺度和平方误差尺度的二乘二非加性项；
- 五项区块级误差比较；
- 错误候选距离与误差的原始分子、分母和差值；
- 真值预报及全部交叉核对最大绝对误差；
- 每项比较自己的基准均方误差和实用等效上下界。

平方误差尺度的非加性项只作描述，不用于把完整差异按比例分配给两个作用；平方误差作用仍不满足可加归因。

## 6. 历史兼容

实现只新增独立诊断模块、独立测试、独立运行器、独立配置和独立结果包：

- 不给既有比较函数增加开关；
- 不调用三阶段运行器重新生成真值；
- 不运行无关方法；
- 不修改任何既有配置、结果或结论。

## 结论

本轮能严格分开的只有“最终权重替换”与“同化交互路径形成的整套候选预报分布替换”。它是末日重组诊断，不是纯状态效应、纯参数效应、严格因果效应或可部署的新方法。

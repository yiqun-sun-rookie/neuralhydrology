## 2. 共同普通路径权重合同

九条来源到目标路径记为 `b=(i,j)`。每一天观测更新后，在对数空间完成一次全局归一，得到并保存普通浮点路径权重 `w_ij`。定义 `N_n(z)` 为生产混合函数对长度为 `n` 的非负权重执行的实际规则：先用 `math.fsum` 求总量，再逐项除以该总量。

直接九路径混合和三个目标候选必须只从同一组 `w` 构造，并保存混合函数实际消费的归一后权重：

```text
d_ij       = N_9(w)_ij
mu_raw_j   = math.fsum_i(w_ij)
beta_j     = N_3(mu_raw)_j
alpha_raw_ij = w_ij / mu_raw_j
a_ij       = N_3(alpha_raw[:,j])_i
v_ij       = beta_j * a_ij
Delta_ij   = d_ij - v_ij
```

`mu_raw_j=0` 的目标候选保持非活动；不得从稳定对数概率再次独立生成条件权重。保存和下一日递归的三个目标普通概率为 `mu_raw`；嵌套全局矩实际使用 `beta`。稳定对数概率只用于保存和评分，不参与候选状态混合或下一日递归。

## 3. 固定浮点常数与运算次数

固定双精度单位舍入误差：

```text
u   = 2^-53 = 1.1102230246251565e-16
eta = 2^-1074
gamma_k = k*u / (1-k*u)
```

对 `math.fsum(n)`，保守计每次部分合并和最终合并最多四次舍入；最多 `n(n-1)/2+(n-1)` 次合并，因此：

```text
F(n) = 2*(n-1)*(n+2)+4
F(9) = 180
F(3) = 24
```

运算图上界固定为：

| 对象 | 运算图计数 | 登记 k |
|---|---:|---:|
| 九路径直接状态 | `9` 次乘法加 `F(9)=180` | `k_Dm=192` |
| 三目标嵌套状态 | 三个内层各 `3+F(3)=27`，外层再 `27`，合计 `108` | `k_Nm=128` |
| 九路径直接协方差单元素 | 两个状态均值 `2*189`；九项各五次基本运算；`F(9)`；两次对称化，合计 `605` | `k_DC=640` |
| 三目标嵌套协方差单元素 | 六个内层均值 `6*27`；三个内层协方差各 `41`；两个外层均值 `2*27`；外层协方差 `41`，合计 `380` | `k_NC=384` |
| 从共同 `w` 到实际 `d` | `F(9)+1=181` | 路线计数 `181` |
| 从共同 `w` 到实际 `v` | `mu_raw` 最多 `24`；`beta` 路线最多 `3*24+24+1=97`；`a` 路线最多 `24+3+24+1=52`；最终乘法一次，合计不超过 `150` | 路线计数 `150` |
| 两条权重路线合并比较 | `181+150=331` | `k_w=512` |

这些整数由固定的三来源、三目标运算图向上取整，未使用 CAMELS 运行差值选择。

## 4. 权重一致性门

定义保守双路线相对误差系数：

```text
rho_w = 2*gamma_512 / (1-gamma_512)
```

每条路径必须满足：

```text
Ew_ij = rho_w * max(|d_ij|, |v_ij|) + 64*eta
|Delta_ij| <= Ew_ij
```

全部九条路径还必须满足：

```text
sum_ij |Delta_ij| <= math.fsum_ij(Ew_ij)
```

权重门独立于状态和协方差门；不得用更大的矩尺度掩盖错误路径权重。

## 5. 状态逐元素门

路径状态为 `x_b[r]`；九路径直接状态和三目标嵌套状态分别为 `mD[r]`、`mN[r]`。

```text
Wm[r]  = sum_b |Delta_b| * |x_b[r]|
ADm[r] = sum_b |d_b * x_b[r]|
ANm[r] = sum_b |v_b * x_b[r]|

Bm[r] = max(
    1e-12,
    Wm[r] + gamma_192*ADm[r] + gamma_128*ANm[r] + 320*eta
)
```

逐元素要求：

```text
|mD[r]-mN[r]| <= Bm[r]
```

## 6. 协方差逐元素门

路径协方差为 `P_b[p,q]`，目标均值和协方差为 `g_j、G_j`，全局直接和嵌套协方差为 `CD、CN`。

```text
R_b[p,q] = P_b[p,q] + x_b[p]*x_b[q]
mw = sum_b w_b*x_b
mv = sum_b v_b*x_b

WC[p,q] =
    sum_b |Delta_b|*|R_b[p,q]|
    + |mw[p]*mw[q] - mv[p]*mv[q]|

ADC[p,q] =
    sum_b |w_b| * (
        |P_b[p,q]|
        + (|x_b[p]|+|mD[p]|) * (|x_b[q]|+|mD[q]|)
    )

AIN[p,q] =
    sum_j |mu_j| * sum_i |alpha_ij| * (
        |P_ij[p,q]|
        + (|x_ij[p]|+|g_j[p]|) * (|x_ij[q]|+|g_j[q]|)
    )

AOUT[p,q] =
    sum_j |mu_j| * (
        |G_j[p,q]|
        + (|g_j[p]|+|mN[p]|) * (|g_j[q]|+|mN[q]|)
    )

BC[p,q] = max(
    1e-11,
    WC[p,q]
    + gamma_640*ADC[p,q]
    + gamma_384*(AIN[p,q]+AOUT[p,q])
    + 1024*eta
)
```

逐元素要求：

```text
|CD[p,q]-CN[p,q]| <= BC[p,q]
```

## 7. 保存和独立核验合同

每个 P 任务逐日额外保存：

- `w、mu、alpha、v、Delta`；
- 权重逐项允许界、逐项比值、权重绝对差总和、总允许界和总比值；
- 状态 `mD、mN、|mD-mN|、Wm、ADm、ANm、Bm、ratio`，共 15 个元素；
- 协方差 `CD、CN、|CD-CN|、WC、ADC、AIN、AOUT、BC、ratio`，共 `15×15` 个元素；
- 活动路径掩码；`u、eta、k_Dm、k_Nm、k_DC、k_NC、k_w` 及相应 `gamma`。

每任务和全实验报告权重、状态、协方差最大比值及其日期、元素索引。任一非有限值、界比值大于一、概率不归一或路径合同不一致立即停止。

独立核验器必须从原始路径数组重新构造全部对象。非负尺度与允许界使用 `Decimal.from_float`、至少 80 位精度计算，并向上转换为双精度；不得调用生产私有混合矩或相信保存的允许界。

## 8. 测试先行合同

在运行任何 CAMELS 任务前，必须先固定以下独立测试：

1. 接受均匀权重、单一路径占优、强消减、零质量路径，以及状态和协方差从 `1e-6` 到 `1e12` 的合成案例；
2. 版本 03 和 03A 的失败点只能作为回归案例，不得改变任何常数；
3. 从一条活动路径向另一条活动路径转移 `1e-9` 且保持权重和为一，权重门必须拒绝；
4. 给一个嵌套状态分量增加 `1e-8*max(1,ADm,ANm)`，必须拒绝且比值至少 `1e4`；
5. 对称地给一个嵌套协方差元素增加 `1e-8*max(1,ADC,AIN+AOUT)`，必须拒绝且比值至少 `1e4`；
6. 交换来源和目标轴必须拒绝；
7. 生产、任务审计和独立核验器三套实现不得互相调用私有界计算函数。

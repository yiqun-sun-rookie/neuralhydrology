## 2. 唯一主结果

改进方法每天展开九条“昨日来源候选→今日目标候选”路径。每条路径独立完成状态映射、推进和观测更新；随后先在每个目标候选内部合成，再由三个目标候选合成唯一的十五状态全局后验。

三目标逐级合成结果是唯一主状态和主协方差，并用于状态评价和主预测。九路径直接合成只是在实数精确算术下等价的诊断读数：它不参与下一日递归、评分、主预测或继续判定，也不再承担浮点相等停止门。

## 3. 普通概率与递归合同

来源、目标均按候选索引 0、1、2 排序。来源优先展平顺序固定为：

```text
(0,0),(0,1),(0,2),(1,0),(1,1),(1,2),(2,0),(2,1),(2,2)
```

从上一日普通候选概率、固定转移矩阵和九路径观测对数似然，在对数空间只执行一次全局归一，得到普通九路径后验概率 `w_ij`。稳定对数概率只保存和评分，不参与状态混合或下一日递归。

全局对数归一逐操作固定为当前登记实现：来源优先展平；对有限值用 `numpy.max` 取最大值；按索引顺序计算 `numpy.exp(value-maximum)`；用 `numpy.sum(..., dtype=float64)` 求和；计算对数归一常数并逐项相减；再次 `numpy.exp` 得普通概率；用同一 `numpy.sum` 求普通概率总量并逐项相除；稳定对数概率再减去该普通总量的自然对数。非活动路径保持普通零和稳定对数负无穷。候选稳定对数概率按目标列分别用相同的最大值—指数—求和顺序做对数求和，再用上述过程归一。独立核验必须逐位重建这一完整运算图。

生产实际使用的普通权重定义为：

```text
mu_raw_j     = math.fsum_i(w_ij)
beta_j       = N_3(mu_raw)_j
alpha_raw_ij = w_ij / mu_raw_j              if mu_raw_j > 0
a_ij         = N_3(alpha_raw[:,j])_i         if mu_raw_j > 0
```

其中 `N_n(z)` 是生产函数的实际非负归一：先用 `math.fsum` 求总量，再逐项相除。零质量目标不参与混合。即使输入总量是次正规数，除法后的活动权重至少有一个不小于 `1/3`；状态混合不得直接用未归一的极小总质量做乘法后再除法。

+ 每个目标候选的状态和协方差只使用其 `a_ij`。
+ 唯一全局状态和协方差只使用 `beta_j`。
+ 保存的候选普通概率和下一日递归概率均为同一个 `beta`；不得使用未归一的 `mu_raw`，不得从稳定对数概率复活已经下溢为零的普通路径。
+ 每日必须保存 `w、mu_raw、beta、alpha_raw、a` 和活动掩码。独立核验器不得相信这些派生数组，必须从上一日普通概率、转移矩阵和九路径似然重新构造并逐值核对。

## 4. 登记的浮点混合算法

每次权威混合最多三个活动分量。删除零权重分量后，保持原索引顺序。对已经按第 3 节归一的实际权重 `z`，先令 `s=math.fsum(z)`，并硬性要求 `0.5 <= s <= 2`；参考状态 `r` 取最大 `z` 对应的分量，并列时取原索引最小者：

```text
m[k] = r[k] + math.fsum_c(z_c * (x_c[k] - r[k])) / s

C_raw[p,q] = math.fsum_c(
    z_c * (P_c[p,q] + (x_c[p]-m[p])*(x_c[q]-m[q]))
) / s

C[p,q] = 0.5 * (C_raw[p,q] + C_raw[q,p])
```

目标内层使用 `a`，目标外层使用 `beta`，且均使用以上算法。再次除以 `s` 是为了避免假定归一后的双精度权重在精确实数域仍严格和为一。输入、权重、所有中间状态和协方差必须有限；权重必须非负且 `s>0`。协方差不要求输入时逐位对称，但输出必须由上述两支显式对称化。

基线方法不调用该路径专用混合函数；其旧输出必须按既有绝对容差和事件判定逐项复现。

## 5. 第一层硬门：独立浮点逐级重建

独立核验器不得导入生产私有混合或权重函数。它必须按第 3、4 节固定顺序独立重建：

1. 九路径普通后验概率、三个目标普通概率、目标条件权重和稳定对数候选概率；
2. 三个目标的状态和协方差；
3. 唯一全局状态和协方差；
4. 当日目标普通概率、状态、协方差到下一日来源数组的递归身份。

第 0 日来源普通概率、三个候选初始状态和初始协方差必须与独立初始矩清单逐位一致；不能只验证第 1 日以后的自洽递推。该清单必须同时登记 `basin_id`、`seed`、10×3 初始概率、10×3×15 初始状态、10×3×15×15 初始协方差、三类轴顺序及文件 SHA-256，并在创建输出目录前核验身份、形状、有限性、概率非负归一和协方差对称性。

比较前统一把 `-0.0` 规范为 `+0.0`。在登记运行环境中，所有重建值与保存值必须逐位相同。任一非有限值、轴身份错误、活动掩码错误、漏路、重复路径、权重不归一、逐位不一致或跨日递归断裂均立即失败。

这道门回答“生产程序是否精确执行了已登记算法”，不使用九路径直接合成与三目标逐级合成之间的差异。

## 6. 第二层硬门：每一级高精度参考

第一层通过后，独立核验器对每个实际目标内层和全局外层分别检查数值稳定性。每次最多三个分量，权重 `z` 必须是第一层独立重建的生产实际权重。

### 6.1 机器常数

```text
u   = 2^-53
eta = 2^-1074
```

定义 `gamma_k=k*u/(1-k*u)`。三分量权威混合先对已归一权重再次用 `math.fsum(3)` 求 `s`。均值还包含三次减法、三次乘法、一个三项 `math.fsum`、一次除法和一次最终加法，按包含分母路线的联合图向上登记为 64 次舍入，使用 `gamma_64`。协方差每个对称元素包含同一分母、两个未对称分支、各三组“两减、一乘、一加、一乘”、两个三项 `math.fsum`、两次除法和最终对称化，联合图向上登记为 128 次舍入，使用 `gamma_128`。不得把 `gamma_k` 简写成 `k*u`。

### 6.2 均值参考和允许界

以生产选择的同一参考状态 `r`，令 `Z` 为实际浮点权重 `z` 在精确实数域的和，对每个状态分量计算精确参考区间：

```text
m* = r + sum_c z_c * (x_c - r) / Z
A  = sum_c |z_c| * |x_c - r| / Z

B_m = max(
    1e-12,
    gamma_64*A + 4*ULP_envelope(m*) + 128*eta
)
```

生产浮点均值到参考区间的最坏距离必须不超过 `B_m`。

### 6.3 协方差参考和允许界

协方差参考有意固定使用已经通过本层均值门的生产浮点均值 `m`，以审计生产实际协方差运算。分别计算未对称的 `p,q` 和 `q,p` 精确参考区间，再精确执行对称化。条件尺度为：

```text
C_raw*[p,q] = sum_c z_c * (
    P_c[p,q] + (x_c[p]-m[p])*(x_c[q]-m[q])
) / Z

C*[p,q] = 0.5 * (C_raw*[p,q] + C_raw*[q,p])

S_raw[p,q] = sum_c |z_c| * (
    |P_c[p,q]| + |(x_c[p]-m[p])*(x_c[q]-m[q])|
) / Z

S[p,q] = max(S_raw[p,q], S_raw[q,p])

B_C[p,q] = max(
    1e-11,
    gamma_128*S[p,q] + 4*ULP_envelope(C*[p,q]) + 256*eta
)
```

生产浮点协方差到对称参考区间的最坏距离必须不超过 `B_C`。

### 6.4 区间和浮点最小间隔

+ 参考和尺度使用成对向外舍入的 `Decimal` 区间，精度至少 100 位；所有浮点输入用 `Decimal.from_float` 精确转换。
+ 下界运算使用 `ROUND_FLOOR`，上界运算使用 `ROUND_CEILING`；含符号运算保留上下界。生产值到参考区间的距离取对区间两端距离的较大值。
+ `ULP_envelope(q)` 定义为：把参考区间两个端点分别正确舍入到双精度，考察该浮点数及其上下相邻浮点数，取所有相邻间距的最大值。若普通转换未向外包住端点，使用 `math.nextafter` 向外扩一格。该定义覆盖负数、正负零、次正规数和二进制指数边界。
+ 任一参考、尺度、界或比值非有限即失败。均值或协方差任一元素超过允许界即失败；不得在运行后调整 `64、128、4、128、256` 或两个绝对下限。

## 7. 九路径直接合成诊断

九路径直接状态和协方差完整保存，但永不参与停止或科学继续门。独立核验器固定报告：

+ 与唯一逐级全局后验的逐元素绝对差；
+ `绝对差 / max(1, |直接值|, |逐级值|)`；
+ 有限双精度值之间的整数浮点间隔距离。先规范正负零，再把二进制表示映射为保持数值顺序的无符号整数，取整数差。

这些诊断不得事后转成门槛、用于调算法或替代主结果。

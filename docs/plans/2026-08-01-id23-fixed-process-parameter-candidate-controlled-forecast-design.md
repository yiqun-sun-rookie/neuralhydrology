# 单滤波器与标准完全交互三模型方法的固定读出预报设计

> 2026年8月1日解释修正：该实验控制了预报读出，但同化端比较的是
> 两套完整方法，不能将差异只归因于参数模型数量或状态交互。

## 唯一问题

在过程噪声方案和预报参数完全相同的条件下，标准完全交互三参数模型
方法的每日唯一全局后验状态，是否比单个固定参数滤波器的后验状态
产生更准确的第1至第7天确定性流量预报。

## 两种方法

| 固定内容 | 一个固定参数滤波器 | 标准完全交互三参数模型方法 |
|---|---|---|
| 参数候选 | 中心率定参数1套 | 两套等效参数与中心率定参数，共3套 |
| 过程噪声 | 固定方案`process_2` | 三个候选全部使用同一`process_2` |
| 内部模型条件状态 | 一个 | 三个 |
| 同化后最终状态 | 单滤波器15维后验状态 | 方法迭代结束时的唯一15维全局后验状态 |
| 预报参数 | 中心率定参数 | 同一个中心率定参数 |
| 预报形式 | 一条确定性轨迹 | 一条确定性轨迹 |

参数向量和过程噪声协方差均不更新。三模型方法每天执行完全交互，
更新三个模型条件状态和模型概率，并输出一个全局后验状态。预报阶段
不使用模型条件状态、模型概率、协方差、采样点或未来流量观测。

## 固定总体

- 封存三阶段合成实验的8个匹配气象区块和3个真实参数试验；
- 全部540个同化后逐日起报点；
- 第1至第7天全部七个预见期；
- 主评价只保留目标日与起报日处于同一真实参数阶段的样本；
- 8个匹配区块为配对重抽样单位，20,000次重抽样，随机种子
  `20260801`。

## 评价量与判断

每个预见期报告两种方法的均方根误差，以及“完全交互三模型方法减去
单滤波器方法”的配对均方误差差值、百分之九十五区间和相对均方根
误差变化。

只有同时满足以下两项时，才写成完全交互三模型方法在该预见期明确改善：

1. 均方根误差至少降低1%；
2. 配对均方误差差值区间上界小于0。

另按三个真实参数阶段报告描述性结果，用来检查总体平均是否由中心
参数阶段或两个非中心参数阶段单独驱动；阶段结果不另设筛选门槛。

## 正确性门槛

- 封存源文件散列必须为
  `77f84d793f18a72972e5af5f2ac4ed767645471e37da31c612ab995ecf4bbf67`；
- 单滤波器必须只有`trained_center__process_2`一个候选；
- 三模型方法必须只有三项，三项过程噪声标识均为`process_2`，并使用
  完全交互；
- 两种预报都必须使用同一`trained_center`参数向量；
- 起报日为`t`时，第一行未来强迫和第一天目标必须为`t+1`；
- 生产实现与独立参考实现最大绝对差不超过`1e-10`；
- 独立核验器不得导入生产确定性预报模块；
- 新结果目录禁止覆盖，历史封存结果禁止重跑或改写。

## 上下文边界

三个参数候选与九个参数—过程噪声组合候选的比较回答的是另一问题，
不能作为本控制变量实验的证据。2026年8月1日完成的逐项状态替换只
用于解释状态误差敏感度，也不能代替本实验。

本实验仍是使用既有封存合成数据的开发性方法比较，不能外推到真实
流域；结果只说明当前固定过程噪声和固定预报读出下两套完整同化方法
的差异，不能说明单独的参数模型数量作用或状态交互作用。

# 15维状态误差对预报的逐项归因设计

## 结论问题

本实验只回答：当未来预报使用同一真实阶段参数时，参数不确定性更新
状态和联合不确定性更新状态中的哪一个状态分量误差会改变未来1至7天
流量误差。

它不比较多个候选分别起报，不使用协方差传播，也不评价真实业务中
无法获得的真实参数。

## 固定总体

- 封存三阶段合成实验的8个匹配区块和3个真实参数试验；
- 全部540个同化后逐日起报状态；
- 第1至第7天预见期；
- 主评价只使用目标日与起报日仍处于同一真实参数阶段的样本；
- 配对统计以8个匹配区块为单位，固定20,000次重抽样和随机种子
  `20260801`。

## 状态干预

分别从参数不确定性更新状态和联合不确定性更新状态出发，构造19种
唯一完整状态：

1. 原始估计状态；
2. 依次只把15个状态中的一个替换成同日起报真实值；
3. 一次替换全部5个蓄水状态；
4. 一次替换全部10个汇流记忆状态；
5. 全部15个状态替换为真实值。

每一种干预仍只发出一条确定性开环轨迹。除被指定替换的状态外，
其他状态、参数、强迫、起报日和目标日全部保持不变。

## 评价量

每个更新方法、状态干预和预见期报告：

- 流量均方根误差；
- 相对原始估计状态的均方根误差变化；
- 8个匹配区块上的均方误差差值及点对点百分之九十五区间；
- 是否达到“至少降低1%且区间上界小于0”的探索性筛选标准。

若替换某一状态后误差增大，不能解释为真实状态有害；它表示该估计
状态中的误差与其他状态误差发生补偿。逐项替换效应允许非线性，不能
相加成完整状态效应。

## 正确性门槛

- 封存源文件散列必须为
  `77f84d793f18a72972e5af5f2ac4ed767645471e37da31c612ab995ecf4bbf67`；
- 起报日为`t`，第一行未来强迫和第一天目标必须为`t+1`；
- 生产实现和独立参考实现最大绝对差不超过`1e-10`；
- 两个更新方法的全真实状态干预必须产生完全相同的预报；
- 独立程序必须重算全部轨迹、统计量和判断，不导入生产状态干预或
  确定性预报模块。

## 结论边界

这是合成实验中的机制筛查，不是多重比较校正后的正式变量选择，不能
外推到真实流域，也不能把逐项效应解释为可加的因果贡献。

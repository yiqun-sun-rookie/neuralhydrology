## 1. 阶段二回答的可独立检验问题

在**与 G3 门逐位相同的理想条件真值**上，完整 IMM 的交互机制（状态混合 + 马氏权重递归）相对更简单的混合策略，在**识别**与**预报技巧**上各加多少价值，且离"已知真值"的 oracle 上界还差多少？

## 2. 四臂（在同一候选集、同一真值上对照）

| 臂 | 定义 | 代码路径 | 需新代码 |

复用 `g3_ideal_gate_param_switch_v01` 的**全部真值输入**：间距 m=8（`g2_spacing_inputs_v01/parameter_vectors_m80.csv`）、L=180、低噪声（`g3_ideal_inputs_v01/observation_noise_low.csv`）、process_2、warmup 45、`factor_transition_stay_probability=0.98`、`initial_covariance_fraction=0.001`、lead_days [1,3,7]、8 区块 × 3 真值试验、forcing/process/obs 种子 3301/3302/3303 段。**不生成任何新真值**，因此无新 forcing/process/obs 种子。配对单元 = （区块 × 真值试验）。这既做方差缩减的配对比较，又让 full 臂能复用门轮封存结果并逐位交叉核对。

## 4. 度量（看结果前冻结）

- **识别**（对产出概率的臂 full/none）：逐阶段 median 真候选后验概率 + 逐日 argmax 准确率（与门同口径，排除每阶段首 5 日）。static 概率恒均匀、oracle 恒 1，识别对照仅作参照不参与假设检验。
- **预报技巧**（全部四臂）：组合流量预报对**无噪真值流量**的 RMSE，于 lead 1/3/7、逐阶段、跨区块×试验聚合。逐（区块×试验）配对差。

## 5. 价值判据（方向性假设，看结果前冻结）

- **H1 交互加识别**：逐阶段 full 的 median 真概率 ≥ none 的 median 真概率。
- **H2 交互加预报**：每 lead 上配对 RMSE 满足 full ≤ none ≤ static（配对，区块 block-bootstrap 95% CI 于差值）。
- **H3 离 oracle 的差距**：每 lead 报 full RMSE / oracle RMSE 比值，且 full 比 static 更接近 oracle。
- 报效应量 + 配对 block-bootstrap 95% CI（单元 = 匹配区块，replicates 20000，**新 bootstrap 种子 3306757**）。方向未被 CI 排除零之前不宣称"有价值"。
- **无后验改判据**：本节冻结后不改。若 full 未优于 none/static，如实报"交互在理想条件下不加价值"（负结果同样是交付）。

## 6. oracle 精确定义（上界的公平性）

oracle = 单一 MUKF，在每阶段使用**该阶段真候选的真参数**（parameter_switch 在阶段边界切换参数、状态按 project 延续），同化同一观测、预报同一 future forcing。即"任何时刻都精确知道模型"，是"完美识别但状态/观测仍有误差"下可达的预报上界。它不是零误差——它把"识别误差"归零、保留其余误差，从而量化识别最多能买到多少技巧。

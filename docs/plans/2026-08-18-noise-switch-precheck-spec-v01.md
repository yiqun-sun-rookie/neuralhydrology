# 噪声切换实验 跑前可辨识预检查规范（NOISE-G1，2026-08-18，计算前冻结）

授权：用户 2026-08-18 "go"。上游：立项书把"噪声候选辨认"列为 not_tested 的四项之一
（`2026-08-17-online-noise-estimation-charter-v01.md` 第七节）；本预检查是该实验的第一步，
**零次滤波运行**。方法由用户提出（往开环状态注扰动、量流量集合离散度），
已在单流域验证与似然法一致（m=1 vs m=10：26.7 天 vs 似然法 27–47 天）。

## 〇、披露

- 单流域（01144000）的雏形数字在写本规范前已看到：m=0.1/1/10 的流量集合方差分别为
  观测噪声方差的 0.018 / 0.174 / 1.739 倍；m=1 vs m=10 = 26.7 天、vs m=0.1 = 281 天。
  **90 流域全量结果未算过。** 准入门 90 天沿用 parFC 实验的段长逻辑（180 天段长的一半），
  非按结果挑选。
- 本预检查只判"理论上分不分得开"，不判方法好坏；它的预测力本身要等切换实验跑完
  才能验证（parFC 那套的 AUC 0.69 是事后验证得到的，不可直接套用到噪声上）。

## 一、被检验的候选设计（冻结）

- **只切下层地下水过程噪声乘子 m**，三候选 **{0.1, 1.0, 10.0}**（×10 间隔）。
  理由：雏形显示 ×3 间隔需 88–210 天，超过 90 天窗，放入候选必然白跑。
- 土壤水降雨系数 c 全程固定 **0**（阶段2 已证 c=0 是合成真值结构）。
- HBV 参数全程固定为率定值（parFC 用率定值，**不引入参数候选**）——按用户裁定，
  参数辨认与噪声辨认分开考。
- 真值噪声档按 7 段轮换 `(1, 0.1, 10, 1, 10, 0.1, 1)`（索引 0,1,2,0,2,1,0），
  每段 180 天、共 1260 天，覆盖全部 6 种有向切换；与 parFC 实验同构。

## 二、噪声注入与集合（冻结）

- 档 m 对应的真值注入：SLZ 每日乘以 `exp(N(-s²/2, s))`，
  **s = SLZ_LOGNORMAL_SIGMA × sqrt(m) = 0.02 × sqrt(m)**（与滤波器 Q 的矩匹配一致：
  Q[SLZ,SLZ] = m·expm1(σ²)·SLZ²）。均值保持、严格正、零截断按构造不发生。
- 集合规模 **N = 40**；随机种子 `SeedSequence((20260818, int(basin_id), cell_index))`，
  逐流域逐档确定；集合成员逐日推进，状态从率定表存档末态起跑。
- 每档输出逐日流量集合方差 `v_cand[t]`（1260 天）。

## 三、可辨识判据（冻结）

- 每日总预测方差：`v[t] = v_cand[t] + sigma_obs²`，σ_obs 取自冻结的
  `g1_precheck_v01/g1_precheck.csv`（真实观测中位流量的 10%，下限 0.02）。
- 候选对 (A=真, B=对手) 的每日证据率（零均值正态方差辨别的 KL）：
  `KL[t] = 0.5·( ln(v_B[t]/v_A[t]) − 1 + v_A[t]/v_B[t] )`，取全窗口均值 `KL_mean`。
- 可辨识时间：`t_lik = ln(19) / KL_mean`（与 parFC 预检查同族公式）。
- 对 6 种有向切换各自算 t_lik（真档→对手档共 6 个有序对），取**最大值** t_lik_max
  作为该流域的控制量。
- **准入：t_lik_max ≤ 90 天。** 另报每个有向对的 t_lik，以便按升档/降档分别报告
  （雏形已预示强不对称，分方向报是必须的，不是事后分层）。

## 四、停止条件

- 若准入流域数 **< 10**，则噪声切换实验在 ×10 间隔下无可行样本 → 如实报告
  "合成域噪声切换在本设计下不可辨识" 并停；**不得**放宽 90 天门、不得改间隔到 ×30
  以上凑数（任何变体＝新预登记）。
- 预检查数字本身不构成任何方法有效性声称。

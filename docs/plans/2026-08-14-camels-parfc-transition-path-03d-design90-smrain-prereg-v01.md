# 03D Design90 预登记：降雨比例土壤水过程噪声（2026-08-14，执行前登记）

## 动机与方案选择

03C（比例SLZ过程噪声）后残余8个受灾任务（P端6+C端2）经诊断全部为同一病灶：SM 过程噪声
为零的通道仍积累正向误差并伴随方差坍缩（z=+32~+587000）；03049800·s1 上只替换 SM 均值
即解除末段灾难（0.017→0.70）。

两轮10任务扫描（8受灾+2健康对照，结果根 camels_parfc_sm_noise_scan_{01,02_rain}_20260814_local）：

- 固定/SM比例噪声存在真实权衡：治愈越彻底、健康对照退化越重（sm_prop_0p02 治愈8/8 但
  对照 NLL 0.40→3.50/1.37、掉事件）。
- **降雨比例噪声 sd=0.2×日降雨 (sm_rain_0p2) 为权衡最优**：受灾零日 517→9、严重日
  812→121，5/8完全治愈；对照 NLL 0.403→0.414 / 0.404→0.445，事件完全不变。
- 已知例外：02193340·s1 对降雨噪声反应为负（严重日 40→113），预期03D不能治愈该任务。

**选择偏差警告（登记在先）**：sm_rain_0p2 是在含全部8个受灾任务的扫描上选出的；其对受灾
任务的效果估计有乐观偏差。90流域整体（尤其176个未参与选择的任务）才是诚实检验。

## 唯一改变因素（相对03C）

滤波器过程协方差在03C基础上增加一项：Q[SM,SM]=(0.2×当日降雨)²（毫米单位；旱天为0）。
SLZ 项、候选、初始矩、强迫、观测、高斯证据、转移矩阵、守恒parFC映射、任务表全部与03C相同；
输入直接读取03C冻结任务文件（强迫/观测/候选逐位继承）。

## 判据（与03C逐字相同，执行前登记）

- 主档30天窗、副档90天窗（5天/0.5/边距0.1规则），按六转移类型与增/减容方向拆分报告；
  每类型通过率≥0.5 为门。
- 概率质量门（每方法）：零概率日=0；严重日(负对数概率>100)=0；平均NLL≤log3；Brier≤2/3。
- 配对报告项：每任务与03C同任务的事件/Brier/NLL方向比较。
- 预期（登记在先）：尾部零日/严重日大幅下降但02193340·s1不愈；健康任务指标近似不变；
  90天窗每类≥0.5保持。若健康任务整体退化超过扫描对照所示量级，判定方案不外推、如实报告。

## 范围与边界

90流域×种子0,1×两方法=360任务；种子2/3禁用；531流域未授权。仅参数候选辨认；
完整状态精度、预报价值、噪声辨认、真实同化不作声称。降雨比例系数0.2与SLZ的σ=0.02同属
"已知合成设定内的噪声建模选择"，真实观测场景需在线估计。本03D采用运行+内置重算汇总一体
模块（run_parameter_path_design90_smrain.py），未设独立第三方verifier，汇总数字可由保存的
逐任务概率文件随时重算复核。

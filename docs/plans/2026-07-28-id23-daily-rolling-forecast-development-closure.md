## 4. 预定门槛与决定

开发进入正式确认必须满足：

1. 完整状态交互相对无状态交互的一日至七日全部至少改善 `1%`；
2. 完整状态交互相对独立候选等权平均的一日至七日全部至少改善
   `1%`；
3. 完整性检查全部通过。

实际结果为：

- 相对无状态交互：`0/7` 项通过；
- 相对独立候选等权平均：`7/7` 项通过；
- 完整性检查：通过。

最终决定：

`NO-GO 正式确认`。

不得创建或运行 `96` 个全新匹配区块的正式确认，也不得删除不利
预见期、缩回切换后七天窗口或放宽 `1%` 门槛。

## 6. 结论边界

本次开发筛查使用八个既有理想合成匹配区块。它足以执行结果前
停止门槛，但不是新的独立正式确认。

它支持的最严格结论是：

- 完整状态交互在参数切换后前七天具有局部快速适应优势；
- 该优势从第七天之后消失；
- 在两个完整参数阶段的逐日滚动平均中，完整状态交互没有优于
  无状态交互；
- 当前一般全阶段预报优势主张不成立，不进入正式确认。

不能外推到实际流域、参数每天连续变化、其他候选间距、其他噪声、
未知气象强迫或其他切换频率。

`NO-GO 正式确认`：局部快速适应价值没有转化为全阶段总体预报优势。

## 二、臂定义（全部严格因果：第 t 日标量只用 ≤t−1 日信息；估计器全确定性，无新随机源）

**两个在线标量**：m = SLZ 状态比例方差乘子（真值锚=1，矩匹配已知σ=0.02）；
c = SM 降雨比例系数（**无真值锚**——真值过程无 SM 噪声项，c 是吸收未建模误差的建模
选择，03D 调出 0.2）。第 t 日 Q 构造与 03D 完全同式，仅以 (m_t, c_t) 替换 (1, 0.2)。

### A1 自适应协方差匹配（在环，C/P 各跑）

- 初值 (m_0, c_0) = (0.03, 0.02)：不诚实小噪声起点（考验能否爬到诚实水平）。
- 每日组合归一化创新平方 z²_t：C = Σ_i prior_i·ν_i²/S_i；P = Σ_active w_branch·ν²/S；
  winsorize 到 ≤100。
- 干日（雨量<0.1mm）：EWMA_dry ← λ·EWMA_dry + (1−λ)·z²_t，更新
  m_{t+1} = clip(m_t · clip(EWMA_dry^γ, 0.8, 1.25), 1e-3, 100)。
- 雨日：同式经 EWMA_rain 更新 c_{t+1}，clip 到 [1e-3, 2]。
- 超参（冻结）：λ=0.98，γ=0.1，EWMA 初值=1。更新后的标量自次日生效。

### A2 噪声网格贝叶斯模型平均（离线因果重加权，C/P 各跑）

- 网格：m ∈ {0.1, 0.3, 1, 3, 10} × c ∈ {0, 0.2, 0.4}，共15配置；每配置=固定标量完整
  运行（03D 同式），逐日保存该配置的边际观测 log 似然 ℓ_g,t
  （C: logsumexp(log prior + candidate_log_evidences)；P: logsumexp over active
  branches of (branch_prior_log_prob + branch_log_evidence)）。
- 权重 w_g,t ∝ 网格均匀先验 × 似然累积：**A2-cum** 用 Σ_{τ≤t} ℓ_g,τ；**A2-f99** 用
  折扣和 Σ λ_f^{t−τ} ℓ_g,τ，λ_f=0.99。
- 组合参数后验 p_t = Σ_g w_g,t · p_g,t（各量只依赖 ≤t 日观测）。

### 锚（不重跑）

03B 与 03D 的冻结 `verification/task_metrics.csv` 提供对应任务锚值。

## 三、判据与容差（冻结）

1. **G1 复现门（硬门，先于一切臂）**：网格点 (m=1, c=0.2) 重放 16 任务，与 03D 保存
   npz 的 probabilities 逐位相等（最大绝对差=0）。不过 → 停，修复前不跑任何臂。
2. **G2 无害门（对照）**：07184000 的 4 个对照任务上，臂平均真候选 NLL ≤ 对应03D值
   +0.05，且零概率日 ≤ 03D 对应值。
3. **排序 R（选型）**：全16任务 mean(NLL_arm − NLL_03D) 最小者胜；差距 <0.02 视为
   平手，取实现更简单者（简单序：A1 > A2-cum > A2-f99）。
4. **生存底线**：臂在 ≥8/16 任务上 NLL 高于 03B 锚 → 该臂淘汰；全部臂淘汰 → 如实
   报告"在线估计试点失败"，调参重试需新预登记。
5. **SQ3（描述性）**：报告 m_t 轨迹（A2 报后验加权 m）；软目标=末30%时段中位
   m ∈ [0.5, 2]。c 只报轨迹，不设门（无真值锚）。
6. **SQ2（描述性，进阶段2的设计输入）**：切换日±15天内标量最大相对变化 vs 全期日变化
   分布；记录"标量跳变（>×2）与真候选概率响应延迟共现"签名的有无。不设门。

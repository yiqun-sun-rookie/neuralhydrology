# G3 追加轮：预报期权重漂移的净影响 — 设计冻结 2026-07-24

**本文件在看到任何结果之前冻结，并在运行前入 git。**

前序：`docs/plans/2026-07-23-g3-phase2-closure.md`（四方法价值对照，负结果）。
本轮回答阶段二遗留的一个具体质疑：**预报期每天按转移矩阵漂动权重，对多天预报误差到底有多大净影响？**

## 1. 背景与动机

阶段二四种方法（完整交互 / 无交互 / 均匀加权 / 已知真值）用同一个转移矩阵，
预报期每天都把权重乘一次转移矩阵（三候选、停留概率 0.98 → 对角 0.98、两个非对角各 0.01）。

- 这在贝叶斯意义上是自洽的：同化期假设"真模型每天有 2% 概率切换"，预报期就该把这个信念往前推。
- 但本实验的真值 180 天才切换一次参数，等于每天 0.56%，**假设的切换率比真相快约 3.6 倍**。
- 7 天累计 1 − 0.98⁷ = 13.2% 的权重被漏给已知为错的候选。
- 阶段二只能给出一个**上限**：无交互 7 天误差 6.6235 vs 已知真值 6.5646，差 0.9%，
  而这 0.9% 同时含"漂移"和"加权合成"两项开销，**没有单独测量过漂移**。

## 2. 冻结的问题（一个，可独立验证）

**在同化过程完全不变的前提下，把预报期的权重固定在同化最后一天的后验权重（不再漂），
多天预报误差会变好还是变坏，幅度多少？**

## 3. 设计

### 3.1 真值与同化：逐位复用，绝不改动

- 复用 G3 理想门 / 阶段二**完全相同**的输入源（参数 / 过程噪声 / 观测噪声三个 csv 的 sha 与阶段二配置一致）、
  相同的 8 个匹配区块种子（3301001-8 / 3302001-8 / 3303001-8）、相同预热 45 天、
  相同阶段长度 [180,180,180]、相同预报天数 [1,3,7]、相同初始协方差比例 0.001、相同停留概率 0.98。
- 因此重跑得到的真值、观测、同化轨迹与已封存证据**逐位相同**；运行器执行与阶段二相同的
  交叉核对（对照已封门证据 `evidence.npz` sha `77f84d79…`：主方法预报、无噪真值预报、含噪观测三者
  `np.array_equal`），不通过则拒绝落盘。
- **门轮与阶段二的证据一律不动**（列入受保护路径，执行前后哈希比对）。
- 说明：本轮**故意不换**强迫/过程噪声/观测噪声种子——复用同一批真值正是本设计的前提。
  唯一新种子是自助重采样种子（见 3.5）。

### 3.2 "去掉漂移"的定义

预报期把用于**合成最终预报值**的权重固定为同化最后一天（第 540 天）的后验权重 `w_post`，
即 `frozen_forecast[lead] = w_post · candidate_predictions[lead, :]`，
其中 `candidate_predictions` 是各候选在该 lead 日各自的预报流量。

对照组（漂移版）就是现有做法：`drift_forecast[lead] = w_drift[lead] · candidate_predictions[lead, :]`，
其中 `w_drift[lead]` 是权重每天乘一次转移矩阵后的结果。

### 3.3 两组对比及其干净程度

| 对比 | 干净吗 | 说明 |
|---|---|---|
| **主对比**：无交互（冻结）vs 无交互（漂移） | **干净，单因子** | 无交互方法预报期不混状态，各候选的预报轨迹与权重完全无关，所以换权重只改合成一步，**精确等价于去掉漂移** |
| **次对比**：完整交互（冻结）vs 完整交互（漂移） | **不干净，明确标注** | 完整交互预报期用权重混状态，本设计只冻结合成权重、混状态仍用漂移权重，因此这只测"合成那一步的漂移"，不是全部 |

次对比只作报告，不作主判据。

### 3.4 待检假设（看结果前冻结）

- **H1（主）**：无交互方法冻结权重后，逐 lead 的配对平方误差差（冻结 − 漂移）
  在 8 区块配对自助 95% 区间内**整段 < 0** → 判"漂移有害且显著"；
  **整段 > 0** → 判"漂移有益且显著"；**跨 0** → 判"不显著"。
- **H2（次，标注不干净）**：完整交互方法同样比较，同样判据，仅报告。
- **H3（辅助报告，不作判据）**：冻结权重后的无交互方法与已知真值方法的 7 天误差差距，
  对照阶段二的 0.9%，看漂移在其中占多少。
- **漂移幅度直接报告（不作判据）**：真候选权重在同化末日与 lead 1/3/7 各自的中位数。
- **负结果照报**：若漂移无害或有益，如实写入结论，不事后改判据。

### 3.5 统计

配对区块自助：单位 = 匹配区块（8 个），每次重采样区块行、同一行三个 lead 一起带走；
重复 20000 次；**新种子 3307001**（前序最高已用到 3306757）。

### 3.6 正确性锚点（先写测试，看到失败，再写实现）

1. 新的"带候选轨迹的同化+预报"函数在完整交互模式下，其合成预报与阶段二
   `assimilate_family_arm` **逐位相等**。
2. 无交互模式下，各候选的预报轨迹与"单候选独立跑"（冻结单候选路径 `_assimilate_record_then_forecast`）
   **逐位相等** —— 这正是"换权重不改候选轨迹"的证明，也是主对比干净性的依据。
3. 用均匀权重做冻结合成，结果与阶段二 `static_mixing_arm` 的合成预报**逐位相等**。
4. 冻结合成函数本身：给定候选轨迹与权重，输出等于加权和；权重不合法（不归一 / 负值 / 形状不符）报错。

单一理想点（候选间距倍率 8、阶段长度 180、观测噪声约为平均流量的 2.6%、三套候选参数、
停留概率 0.98、真实切换周期 180 天）。结论只覆盖"在这一点上，预报期权重漂移对 1/3/7 天预报的净影响"，

# 唯一组合状态确定性预报归因设计（2026-07-31）

## 结论门

现有“唯一状态预报”不是确定性单轨迹：它仍通过无迹变换传播协方差和
采样点。现有状态误差核查也只比较五个蓄水状态，遗漏十个汇流记忆
状态。本实验先修正这两点，再判断预报退化来自参数读出还是状态。

## 固定设计

- 输入：封存的三阶段合成实验，不重跑同化；
- 起点：全部540个同化日；
- 预见期：第1至第7天；
- 主评价：不跨越第180天和第360天参数变化的预报；
- 状态：完整15维，包括5个蓄水状态和10个汇流记忆状态；
- 预报：一个状态、一套参数、一条确定性水文模型轨迹；
- 统计单位：8个匹配区块，区块内合并3组真实参数和全部有效起点；
- 重采样：固定20,000次匹配区块重采样；
- 真值参数：只用于原因核查，不是实际可运行方法。

## 十二个交叉组合

四种状态来源：完整更新状态、完整真实状态、更新蓄水状态加真实汇流
记忆、真实蓄水状态加更新汇流记忆。

三种参数来源：当日真实阶段参数、后验概率加权参数、后验概率最大候选
参数。

## 必须先通过的检查

1. 13,104个封存真值转移全部逐元素精确复现；
2. 第`t`日同化后状态只能使用第`t+1`日起的气象输入；
3. 第`h`天预报只能与第`t+h`日流量比较；
4. 确定性预报接口不得包含协方差、采样点、候选概率或未来流量观测；
5. 主结果不得混入跨参数变化的预报；
6. 独立参考实现与生产实现最大绝对差不得超过`1e-10`。

任何一项失败都停止科学解释，只修代码。

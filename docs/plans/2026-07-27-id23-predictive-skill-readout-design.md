# 滚动多步预报技能读出设计

状态：结果前开发设计；旧八个区块仅用于筛查，不能作为正式性能证据。

## 1. 问题

九十六个新匹配区块证明，最近三十天平均后验概率能以 `97.92%` 的正确率识别生成真值的参数候选，但真实参数候选成为预报误差最小候选的比例在一日、三日、七日仅为 `53.13%`、`51.39%`、`50.00%`。因此参数真实性和预报技能不是同一个目标。

## 2. 固定方法

- 完整状态交互、候选滤波器、似然、同化期模型概率递推和预报期单位转移全部不变。
- 一日预报保持当前完整状态交互后验加权，逐位不变。
- 三日预报：在预报起点之前，取最近三十次已经获得对应观测的三日候选预报，逐候选计算均方误差，选择均方误差最小的候选。
- 七日预报同理，只使用最近三十次已经完成验证的七日候选预报。
- 平票选择候选顺序最靠前者。
- 历史不足三十次时拒绝运行。
- 不使用预报起点之后的观测、噪声自由真值或当前试验的未来误差。
- 不用结果调整窗口、损失、权重形式或一日规则。

## 3. 时间索引

若最终同化日索引为 `t`，预见期为 `L`，可用于评分的最近一个预报起点是 `t-L`，其目标日是 `t`。最近三十个评分起点为 `t-L-29` 至 `t-L`。最终业务预报仍从 `t` 发出，目标为 `t+L`。

## 4. 开发筛查

只使用此前的八个开发区块。候选预报技能读出必须同时满足：

1. 一日预报与完整状态交互后验加权最大绝对差不超过 `1e-12`。
2. 三日相对完整状态交互和无状态交互的均方根误差损害均不超过 `1%`。
3. 七日相对完整状态交互和无状态交互的均方根误差均至少降低 `1%`。
4. 所有索引、有限值、历史数量和无未来观测检查通过。

任一条件失败即停止，不进入新的正式随机确认。

## 5. 正式边界

开发筛查通过后，才另行冻结全新随机区块、种子、样本量和配对区块自助区间。正式保留仍要求一日逐位相同、三日无实质损害、七日相对两个对照均有实质改善，并通过独立复算。

## 结论

本方法不再把“真实参数”当作预报最优代理，而是只用已经发生的同预见期预报误差估计候选技能；它改变读出目标，但不改变完整状态交互模型结构。

# 历史专家初始化冻结近期状态：候选迭代 3

## 结论与单一改动

候选迭代 3 保持近期专家冻结，但把历史信息的注入位置从“输出端相加”改为“初始化近期专家的
隐藏状态和记忆状态”。不再训练两个历史输出残差。

数据、历史分段、三个专家的输入维度、长短期记忆网络层数、隐藏宽度、近期模型检查点、损失、
批大小、学习率计划、验证期和四项筛选门槛均不改变。

## 证据

候选迭代 2 的输出残差使 36/60 个流域改善，但相对近期经典模型的逐流域效率差中位数仅为
+0.000627956001。把残差乘以 0 至 2 的验证期诊断上限也只有 +0.000787502868，说明简单
输出缩放不能达到 +0.01 门槛。

旧版较窄历史编码器初始化近期状态的单训练随机数结果曾相对经典近期模型达到
+0.006626，但未超过参数量匹配模型。该结果受到共同训练轨迹和结构宽度差异影响，不能直接
作为当前候选结论，但支持在严格冻结近期参数后重新检验状态初始化。

## 模型

1. 近期、中期和久远专家均为 32 维输入、单层、隐藏宽度 256 的长短期记忆网络。
2. 近期编码器和唯一流量输出层从已训练经典模型加载并完全冻结。
3. 中期和久远专家分别产生最终隐藏状态与记忆状态。
4. 四个长度为 256 的逐维门控向量分别作用于中期隐藏状态、久远隐藏状态、中期记忆状态和
   久远记忆状态；门控使用双曲正切函数并从全零开始。
5. 两个历史隐藏状态之和构成近期编码器的初始隐藏状态，两个历史记忆状态之和构成初始记忆
   状态。
6. 训练时只对历史状态使用按训练随机数、轮次、批次和分支固定的 0.4 随机失活；近期最终
   输出不使用随机失活。
7. 唯一流量输出来自近期专家的最终状态。

候选总参数量为 892,161，其中 594,944 个历史编码器和门控参数可训练。门控全零时，候选
输出必须与冻结近期模型逐位相同。训练后近期编码器和输出层参数必须与训练前逐位相同。

## 训练与筛选

训练随机数 100 的历史参数训练 30 轮、18,000 次更新。四项门槛保持不变：

- 相对近期经典模型的逐流域效率差中位数至少为 0.01；
- 相对参数量匹配经典模型的逐流域效率差中位数大于 0；
- 相对冻结旧版历史拼接模型的逐流域效率差中位数大于 0；
- 优于近期经典模型的流域比例至少为 0.55。

任一门槛失败即停止本轮，不运行训练随机数 200 和 300。全部通过时，才生成另外两个训练
随机数的经典近期检查点和条件运行配置。

# 修正后多日预报对照设计 — 2026-07-25

## 目标

在完全相同的已知真值、观测和更新过程上，取消预报阶段的模型切换与候选状态混合后，重新判断完整交互更新是否改善未来 1、3、7 天流量预报。

## 唯一改变

- 更新阶段保持原定义：完整交互更新仍使用模型转移、候选状态交互和观测似然更新；无交互更新仍让候选独立更新并递推候选概率。
- 预报阶段统一使用最终更新后概率；模型转移矩阵设为单位阵，候选概率不漂移，候选状态不跨模型混合。
- 真值、强迫、观测、候选集合、初始状态、更新天数和预报起点全部不变。

## 方法

比较四种方法：

1. 完整交互更新后预报。
2. 无交互更新后预报。
3. 独立更新候选的均匀平均预报。
4. 始终使用已知真实候选的预报。

前两种方法是主要比较；后两种只用于解释性能位置。

## 主问题与判据

对每个预报时长，计算完整交互更新减去无交互更新的配对平方误差。

- 95% 区间上界小于 0：完整交互更新改善预报。
- 95% 区间下界大于 0：完整交互更新损害预报。
- 区间包含 0：当前证据检测不到差异。

同时报告四种方法的总体均方根误差。结论按 1、3、7 天分别给出，不要求三个时长同向。

## 完整性要求

新运行必须与旧封存证据逐位一致地复现以下内容，否则立即停止且不发布结果：

- 强迫、随机扰动、无噪真值、含噪观测；

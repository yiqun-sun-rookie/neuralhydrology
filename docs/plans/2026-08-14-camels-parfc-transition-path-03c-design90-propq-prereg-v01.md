# 03C Design90 预登记：状态比例 SLZ 过程噪声修复（2026-08-14）

## 动机（已完成的单流域证据，全部冻结）

1. 第540天十五状态与子集反事实（流域07184000、种子0）：土壤水 SM 是灾难性概率锁定的
   充分且必要单状态（sm_only 恢复 0.6655 ≈ 全15状态 0.6613；slz_only、routing_only、
   all_but_sm 均不恢复，156个零概率日不变）。
2. 根因：冻结03B合同的滤波器过程协方差为固定值（仅 SLZ 项非零，标准差≈3.9 mm），而
   真值每日注入的 SLZ 对数正态噪声标准差≈70 mm（方差低估约320倍）；其余14个状态过程
   噪声为零。创新被系统性误分配进 SM 并伴随方差坍缩。
3. 单流域修复验证（07184000、种子0和1、两方法）：改用
   `lower_groundwater_state_proportional`（multiplier=1，矩匹配真值噪声）后，零概率日
   全部归零、平均真候选负对数概率≈0.40（登记上限 log 3≈1.0986）、SM 误差从 58σ 回到
   1.3σ、两方法事件模式完全一致（减容切换30天内全过，增容切换57–84天检出）。

## 唯一改变因素

滤波器过程协方差模式：`fixed`(q_scale=3e-8) → `lower_groundwater_state_proportional`
(q_state_multiplier=1.0, q_structure=lower_groundwater_state_only)。每日按候选0转移
预测的参考 SLZ 重建 Q[4,4]=expm1(σ²)·SLZ²，三个候选共用同一 Q（03B 公平性修正不变）。
候选、初始矩、强迫、观测、高斯证据、转移矩阵、守恒 parFC 映射、任务表全部与03B相同。

## 判据（执行前登记）

用户2026-08-14批准双报制：

- **主档（30天窗，与03B判据逐字相同）**：切换后30天内出现连续5天真候选后验>0.5（严格）
  且边距≥0.1。按六种转移类型（每类型每方法180事件）分别报告通过率；03B科学门
  （每方向通过率≥0.5）照实评估并报告，不因结果修改。
- **副档（90天窗，本文件首次登记）**：同一5天/0.5/边距规则，窗宽90天。同样按转移类型
  与容量增/减方向拆分报告。
- **概率质量门（每方法，194400评分日）**：真候选零概率日=0；负对数概率>100的严重日=0；
  平均真候选负对数概率≤log(3)=1.0986122886681098；多类别布赖尔分数≤2/3。
- **配对对照（报告项，非门）**：每任务与冻结03B同任务（fixed-Q）的事件数、布赖尔、
  NLL 方向比较。

预期（登记在先）：基于单流域证据，预期减容方向30天通过率高、增容方向30天通过率低而
90天通过率显著提高；概率质量门预期两方法均通过。若增容方向90天仍<0.5，判定为该噪声
水平下参数可辨识性不足，而非估计器缺陷；不得据此在执行后另立新门。

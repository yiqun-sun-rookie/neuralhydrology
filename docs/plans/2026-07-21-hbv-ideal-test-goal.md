# 总目标：ID23 理想测试框架与候选可辨识边界（2026-07-21 设定）

## 背景

论文稿 draft-4（另仓 `paper-imm-variable-params`，WALRUS + 交互式多模型）的合成试验证明力不足：单次实现无重复、判定事后化、看不到切换后瞬态、缺静态混合对照。本仓 ID23 冻结证据已确认：在 15 状态 HBV、紧候选间距、15 日阶段、10 评分日下，观测似然认不出真候选；似然分解显示优势来源无跨场景统一答案。两者之间的"可辨识边界"没人量过。

## 总目标（长期，边界清晰）

在本仓 ID23 线上建成一个完整的"理想测试"框架，并用它回答三个问题：

- **G1 再识别刻画**：真值切换后，观测似然累计排名多快让真候选登顶、多快稳定登顶；认不出的试验里，主导失败模式是"从未登顶"、"登顶后被反超"还是"登顶太晚"。
- **G2 认出时间曲线与可辨识边界**（2026-07-22 修订，依 MATLAB 锚点对齐与用户指示"时间长一点认出也是认出"）：主交付物 = 认出时间 T（切换后稳定登顶所需**同化循环数**）作为 候选间距倍率 × 每阶段循环预算 的函数曲线，两轴并列第一优先；循环预算用拉长日步阶段实现（如 15/45/90/180 天，不移植小时模型）。"可辨识边界"降级为该曲线的等高线（T ≤ 阶段长即预算内认出）；三件套判据仍用于逐格"预算内稳定认出"的判定。开发种子出曲线、确认种子按预选边界格一次验证；观测噪声轴留第二波。MATLAB 锚点（小时步 WALRUS，见 `docs/technical/2026-07-22-matlab-imm-reconciliation.md`）：稳定认出实测 82 / 560 / 724 / 1203 循环，占真值停留时间的 7%–99%。
- **G3 对照闭环**：同一真值上对比 静态等权混合 / 无交互似然加权 / 完整交互式多模型（带状态交互与权重递归）/ 含真值 oracle 单滤波器 的状态估计质量，回答 (a) 交互式多模型是否只是加权平均 (b) 长窗权重递归能否救回短窗似然认不出的候选 (c) 候选滤波器是否因同化同一观测过快收敛（承接上一轮遗留问题）(d)（2026-07-22 增）**未认出过渡期的代价**：认出前的过渡窗内状态/预报质量相对 oracle 损失多少——若软加权在过渡期已接近 oracle，认出慢即无害；若过渡期恰是预报损失集中处，认出时间/停留时间比值就是关键指标。

## 完成标准

三个 G 各有密封证据目录 + 两层独立审查通过；最终一份综合报告给出边界图、对照表和明确的"在什么条件下交互式多模型前提成立"的结论。证据不足处写"目前无法确定"。

## 明确不做（边界）

WALRUS/真实流域实验、论文写作、权重机制改进设计、修复 pip freeze 环境问题（已记录）、修改任何冻结证据。

## 硬约束（沿用 ID23 协议；2026-07-21 经独立可行性审查修订）

- 冻结实验不重跑不修改；新实验新编号、新目录、全新种子（种子须避开已用的 990001–998012 段，新实验从 1001001 起分配并记录）。
- 只读分析可用冻结区块；新实验的设置不得靠反复窥视同一批区块调出来——网格与判据一次冻结，确认种子只跑一次。
- **G2 确认协议三条硬规则**（读任何开发结果前生效）：① 确认的"关键边界单元"用确定性规则选取（每场景取"最小通过间距"与"最大失败间距"两格）；② 确认结果与开发矛盾时，报告"边界目前无法确定/只给区间"，禁止换种子重跑；③ 确认结果无论方向均为最终。
- **G2 判据整体继承冻结三件套**：稳定比例 ≥ 2/3、区块自助法 95% 下界 > 0.5、第十日累计差中位数 > 0，三者同时满足才算该格"可辨识"；预登记单调性假设（间距增大可辨识性不降），边界报区间并附逐格自助法区间。
- **G1 分类阈值预冻结**："登顶太晚" = 首次稳定登顶日 > 6（最晚合格日 = 10 − 5 + 1）。
- **G3 每轮开跑前预冻结**：状态误差口径（全 15 态还是 5 储量态、是否归一、统计窗）与 (a)(b)(c) 各自的量化判据；G3 拆成三轮，每轮一个子问题；(c) 先用冻结 `candidate_innovation_variances` 数组做只读预检，信号明显则省一轮新实验。
- **倍率生成器**：对照 `hbv_adapter.py` 参数界硬校验，越界倍率拒绝而非截断；文档明写"间距倍率同时改变真值轨迹"的解释边界。
- 数值发散冒烟用一次性声明的废弃种子做，不烧正式种子。噪声轴留第二波，另行冻结网格。
- 行为改动先聚焦失败测试；配置在读结果前冻结；输出经 `.incomplete` 暂存密封 + 全目录散列。
- 每轮：一个可独立检验的问题 → 实现/实验 → 一层独立上下文审方法结果 → 另一层从原始证据复算。
- 资源按实际数组形状与并行度估算，无统一固定门槛。
- 每轮结束对照本文件检查是否偏离总目标。

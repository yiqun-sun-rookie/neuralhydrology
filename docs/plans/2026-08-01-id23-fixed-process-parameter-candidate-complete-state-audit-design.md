# 单滤波器与标准完全交互三模型方法的完整状态比较设计

> 2026年8月1日解释修正：历史实验标识和配置保持不变。本实验比较
> 两套完整同化方法，不能把差异只归因于参数模型数量或状态交互。

## 问题

在过程噪声方案、观测、气象强迫、同化日期和误差计算全部相同时，
标准完全交互三参数模型方法每次更新后的唯一全局后验状态，是否比
单个固定参数滤波器的后验状态更接近当天真实15维状态？

本实验到状态更新为止，不执行任何向后预报。

## 两种状态更新方法

| 内容 | 单个固定参数滤波器 | 标准完全交互三参数模型方法 |
|---|---|---|
| 固定参数向量 | 中心率定参数1套 | 两套等效参数和中心率定参数，共3套 |
| 过程噪声 | `process_2` | 三个模型全部使用`process_2` |
| 内部状态 | 一个滤波器后验状态 | 三个模型条件后验状态 |
| 交互 | 单模型下退化为恒等操作 | 更新前进行完全状态与协方差交互 |
| 模型概率 | 恒为1 | 每天进行概率预测和后验更新 |
| 每日最终输出 | 一个后验状态 | 一个后验概率加权的全局后验状态 |

三套参数向量和过程噪声协方差在运行前固定，运行中不修改数值。三个
模型条件状态是内部量，不是三项最终状态输出。

## 归因边界

该比较同时包含以下结构差异：三个固定参数模型、非平凡的完全交互、
三个模型概率的更新以及全局后验合成。因此它只能比较两套完整同化
方法，不能单独识别任何一个机制的贡献。

## 评价总体

- 复用封存的八个匹配气象区块和三个真实参数试验；
- 使用全部540个同化日；
- 每天的最终后验状态只与同一天真实状态比较；
- 不按距真实参数改变多少天分组；
- 不使用任何未来气象、未来流量或预报结果。

## 完整状态与判断规则

评价全部15个状态：五个蓄水状态和十个汇流记忆状态。每个状态分别
报告均方根误差、相对变化以及按八个匹配区块重抽样得到的配对均方
误差差值区间。

另计算完整状态标准化误差：先把每个状态误差除以该真实状态在全部
有效样本中的标准差，再对15个状态等权计算均方根。五个蓄水状态和
十个汇流记忆状态分别报告组内原始误差与标准化误差。

对“标准完全交互三模型方法减去单滤波器”的均方误差差值：区间上界
小于零为三模型方法更准，区间下界大于零为三模型方法更差，其余为
证据不足。

## 正确性门槛

- 封存源证据散列必须为
  `77f84d793f18a72972e5af5f2ac4ed767645471e37da31c612ab995ecf4bbf67`；
- 单滤波器必须是`trained_center__process_2`；
- 标准三模型方法必须使用三套固定参数并全部共享`process_2`；
- 三模型源必须明确使用完全交互模式；
- 保存的每日方法状态必须是每次更新后的唯一全局后验状态；
- 保存状态形状必须为`8×3×5×540×15`；
- 独立核验器直接从封存源重算全部误差和统计量；
- 最大数值差不得超过`1e-12`；
- 结果目录、封存源和历史配置快照不得改写。

## 证据边界

这是合成数据上的两套完整同化方法比较。它不评价预报，不分离状态
交互作用，也不能外推到真实流域。纠错侧车配置为
`g3_fixed_process_parameter_candidate_complete_state_audit_v01.scope_correction_20260801.json`。

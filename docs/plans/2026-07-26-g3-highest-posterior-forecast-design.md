# 最高后验候选预报诊断设计冻结 — 2026-07-26

状态：**经用户批准，在任何实现和新结果生成之前冻结。**

## 1. 科学问题

理想参数切换实验已经确认：完整交互更新使真实候选的后验概率更集中，但这种集中没有转化为可检测的一日、三日或七日预报优势。

本轮只回答一个问题：

> 无状态交互更新已经识别出最高后验概率候选后，直接使用该候选预报，能否优于按完整后验概率加权平均？

若能，说明概率平均可能稀释了识别结果，可以把“识别后选择候选”作为后续方法候选；若不能，说明当前条件下识别集中度不是限制预报效果的主要瓶颈。

## 2. 冻结范围

- 继续使用已封存理想参数切换实验的八个匹配区块、真值、观测、候选、初始状态、协方差、同化时长和一日、三日、七日预见期。
- 真值与全部同化期数组必须与封存理想实验逐位一致。
- 预报阶段不使用模型切换矩阵，不改变候选概率，不进行跨候选状态混合。
- 不修改任何既有配置、结果、结论或封存文件。
- 本轮不涉及过程噪声切换、参数与过程噪声联合切换、实际流域或五百三十一个流域。

## 3. 五种方法

1. **完整交互更新**：同化期进行跨候选状态交互，并按观测似然更新候选后验概率；预报期固定同化末日后验概率。
2. **无状态交互、后验加权预报**：候选在同化期保持独立，按观测似然更新候选后验概率；预报按同化末日后验概率加权。
3. **无状态交互、最高后验候选预报**：与第2种方法共享完全相同的同化结果和候选预报，只选择同化末日后验概率最高的候选预报。
4. **独立候选固定等权平均**：候选独立同化，不更新组合权重，预报固定等权平均。
5. **已知真实候选**：每个阶段直接使用生成真值的候选，作为可达到上限的参照。

开环方法不进入本轮理想条件下的核心机制比较；回到实际流域时仍必须保留开环作为绝对效果参照。

## 4. 最高后验候选的精确定义

- 候选选择只使用同化末日的后验概率，不读取未来流量或未来真值。
- 选择规则为 `argmax`；完全并列时选择冻结候选顺序中索引最小者。
- 一次起报的一日、三日和七日全部使用同一个已选候选。
- 第2种和第3种方法必须由同一次无状态交互同化及同一次候选预报产生；两者唯一差别是最终组合规则。
- 保存每个区块、每个真值试验的已选候选索引、同化末日后验概率、逐候选预报和最终预报。

## 5. 判断规则

主要比较为“最高后验候选预报减去后验加权预报”的配对平方误差，以匹配区块为重采样单位，分别报告一日、三日和七日的均值及百分之九十五区间：

- 区间上界小于零：最高后验候选预报改善该预见期；
- 区间下界大于零：最高后验候选预报损害该预见期；
- 区间包含零：未检测到差异。

同时报告相对固定等权平均和已知真实候选的均方根误差，但不据此更改主要判断规则。

只有新方法相对后验加权预报出现可检测改善，且其他预见期未出现可检测损害，才把“识别后选择候选”保留为后续方法候选；否则只记录为机制诊断，不扩展为方法。

## 结论

本轮不是再次提高识别概率，而是检验已经得到的后验识别结果是否被概率平均稀释。它保持同化和候选预报完全相同，只改变最终预报选择规则，因此能够直接判断“识别后选择候选”是否值得成为方法的一部分。

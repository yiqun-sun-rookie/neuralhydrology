# 单滤波器与标准完全交互三模型方法的完整状态比较结论

## 结论

同化过程噪声固定为同一`process_2`后，标准完全交互三参数模型方法
每次更新后的唯一全局后验状态呈现明确的混合结果：

- 五个蓄水状态全部比单个固定参数滤波器更准确；
- 十个汇流记忆状态全部更不准确；
- 15个状态按各自真实波动尺度标准化并等权汇总后，总体误差降低
  `45.028%`。

本实验没有执行任何向后预报。它比较的是一套单滤波器方法和一套
标准完全交互三模型方法，不能把`45.028%`只归因于增加参数模型，
也不能只归因于状态交互。

## 方法输出的准确含义

标准完全交互方法内部保留三个模型条件后验状态，但每天主要输出是
按模型后验概率合成的一个15维全局后验状态。实验评价的正是这个
全局后验状态，而不是三个子滤波器状态，也不是额外创建的状态平均
发布方案。

单滤波器使用固定中心率定参数和`process_2`。三模型方法分别使用
两套等效参数及中心率定参数，三者都使用相同`process_2`，并执行
完全状态与协方差交互、模型概率更新和全局后验合成。两者使用相同
八个气象区块、三个真实参数试验、全部540个同化日、观测和同日
真实状态；没有按距真实参数改变多少天分组。

## 五个蓄水状态

| 状态 | 单滤波器误差 | 完全交互三模型全局后验误差 | 相对变化 |
|---|---:|---:|---:|
| 积雪 | 64.6695 | 54.4465 | 改善15.808% |
| 融雪水 | 4.1656 | 2.6249 | 改善36.987% |
| 土壤水 | 258.8722 | 121.5294 | 改善53.054% |
| 上层地下水 | 6.4444 | 4.7460 | 改善26.355% |
| 下层地下水 | 323.8934 | 101.1171 | 改善68.781% |

五项配对均方误差差值的百分之九十五区间都完全小于零。五个蓄水
状态的组内原始均方根误差从`187.7034`降至`74.8170`；标准化组
误差降低`45.859%`。

## 十个汇流记忆状态

十个汇流记忆状态的单项均方根误差在单滤波器中为`0.4794`至
`0.5356`，在完全交互三模型全局后验中为`0.5304`至`0.6431`。
十项误差分别增加`10.633%`、`10.958%`、`16.215%`、`18.089%`、
`19.614%`、`20.223%`、`20.181%`、`20.462%`、`20.798%`和
`20.828%`，相应区间全部高于零。组内原始均方根误差从`0.52852`
升至`0.62364`；标准化组误差增加`17.993%`。

## 完整15维汇总

- 单个固定参数滤波器：`0.677799`；
- 标准完全交互三模型全局后验：`0.372601`；
- 相对降低：`45.028%`；
- 三模型减去单滤波器的标准化均方误差差值区间：
  `[-0.357686, -0.286891]`。

因此，15个状态分别标准化并等权时，标准完全交互三模型方法的全局
后验更准确；但不能说15项全部更准，因为十个汇流记忆状态明确更差。

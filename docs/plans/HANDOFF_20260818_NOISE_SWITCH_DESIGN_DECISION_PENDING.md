## 二、当前阶段的实验对象、唯一变量与方法合同

### 噪声切换实验（当前活跃线）

- **被辨认的对象**：下层地下水状态（SLZ）的每日过程噪声量级本身，而非模型参数。
  以往全部实验切的都是土壤最大蓄水容量参数（parFC）；本实验**参数全程固定为率定值**，
  唯一变化的是噪声档。
- **三候选（预检查规范已冻结）**：噪声乘子 m ∈ {1.0（率定参照）, 0.1, 10.0}；
  土壤水降雨系数 c 全程固定 0（阶段2 已证 c=0 是合成真值结构）。
- **真值注入**：SLZ 每日乘以 `exp(N(-s²/2, s))`，`s = 0.02 × sqrt(m)`
  （与滤波器 Q 的矩匹配一致：`Q[SLZ,SLZ] = m·expm1(0.02²)·SLZ²`）。均值保持、严格正。
- **真值轮换**：七段各 180 天共 1260 天，档位索引顺序 `(0,1,2,0,2,1,0)`
  即 中→低→高→中→高→低→中，覆盖全部六种有向切换；与既往参数切换实验同构。
- **答题方**：三个滤波器并行，各假设一档固定噪声，用同一套交互多模型机制
  （C 臂 `full` 与 P 臂 `pairwise_path_postcollapse`），每日输出"当前真值用哪一档"的概率。
- **判据（沿用参数实验模板，实验本体预登记时再最终冻结）**：每次真值切换后 90 天内
  把概率押到正确档；六种有向切换分别报告（预检查已预示强不对称，分方向报是必须的）。

### 2. 阶段3 真实观测（负结果，判定完成）

- 准入：九十流域经两级冻结规则筛至 **52** 个（跑前可辨识为真 + 中心候选窗口效率系数
  ≥0.3 + 候选未在参数上界重合）。真实观测在同一 1260 天窗口零缺测零负值（实测）。
- **稳健运行门未过，触发预登记点名的网格饱和停止条款**：边界格（m=10 或 c=0.4）
  时间平均权重中位 0.993（C 臂）/0.999（P 臂）；"边界权重<0.5"这一条 C 臂 0/52 通过、
  P 臂 1/52 通过；两臂通过率均 0.0%。
- 核心机制（描述性，非声称）：真实数据上模型结构误差约为观测噪声的十倍（中心候选平均
  绝对偏差 ÷ 观测噪声中位 10.72，候选足迹比中位 4.05，两者之比中位 2.30）；
  预测似然偏爱"永不被惊讶"的大噪声档，而该档点预报是灾难（个别流域效率系数达 −101.7）。
- 一步预报效率系数（52 流域中位）：单模型固定 m1_c0 格 **0.705**；开环 **0.640**；
  三候选交互固定同格 −0.012（C）/−0.073（P）；完整系统（三候选+似然投票）−0.15/−0.24；
  单模型+似然投票 −1.260。**即真实域两层各自都在扣分，候选层扣约 0.7 是大头。**
- 一个确定性数值崩溃：流域 03384450 / P 臂 / m10_c0，协方差最小特征值 −3.58e-08 触发
  半正定检查。按修正案 01a 记为稳健运行门数值坍缩并退出配对；**决定不修滤波栈**。

### 3. 阶段4 第一步 换加权尺子（负结果，判定完成，零次新滤波）

- 唯一变量：跨格加权尺子从折扣似然改为**折扣逆平方预报误差**（λ=0.99 继承，无拟合参数，
  严格因果）。仅单模型，不含参数候选层。
- **双门均未过**：非劣门中位 −0.2289（5 赢/47 输，容差 −0.01）；修复门中位 vs 开环 −0.1472。
- 52 流域中位效率系数：换币加权混合 0.4551；赢者通吃变体 0.6522；似然混合 −1.2597；
  固定 m1_c0 **0.7055**；开环 0.6405。
- 结论（可引用）：换币确实修复了旧灾难（vs 似然混合中位 +1.4326，49/52 赢），但
  **真实域"过程噪声尺度自适应"本身无价值**——最好表现只是从下方逼近手工固定一档。
  机制：坏档预报灾难性差，加权平均给它几个百分点权重即中毒；硬选择只能逼近不能超越。

### 5. 噪声切换实验跑前预检查（NOISE-G1，已完成，零次滤波）

方法由用户提出：往开环模型状态注入各档扰动、跑集合（规模 40）、量流量集合方差，
再用零均值正态方差辨别的相对熵换算可辨识时间 `t = ln(19)/平均相对熵`
（与参数实验的 `ln(19)/(r²/2)` 同族）。

- **准入 44/90 流域**，停止条件（<10）未触发。
- 各档流量集合方差占观测噪声方差的倍数（中位）：m=0.1 → **0.0439**；m=1 → 0.451；
  m=10 → 4.571。**低档信号只有观测噪声的约 4.4%，被观测噪声盖住。**
- 六种有向切换的可辨识天数（中位）：低→高 1.7；中→高 5.3；高→低 9.8；高→中 15.7；
  低→中 51.7；**中→低 94.9（瓶颈，84/90 流域的控制约束）**。
- 规律（更正雏形期说法）：难度由**目的地档是否可见**决定，不是切换方向大小——
  以 m=0.1 为终点的两个切换最慢，从 m=0.1 出发向上切最快。
- 一个流域 09510200 三档流量方差均在 1e-17~1e-19 量级（该流域几乎不产流，观测噪声顶在
  下限 0.02），任何档不可分，算得无穷，已按规则自动排除。

# 连续多尺度历史气象编码实验设计

**日期：** 2026-07-28  
**实验家族：** `continuous_multiscale_history_v08`  
**严格复现实验：** `R08-NEST`  
**候选实验：** `E08-C01`

## 1. 结论性目标

本实验只回答一个问题：在只使用 Maurer 五项气象驱动和 27 项流域静态属性时，取消原有
`1825` 天硬分界、把滞后 `270–3649` 天表示为一个连续且逐渐变粗的时间序列，能否在新的
内部确认期稳定优于经典近期长短期记忆网络及参数量控制。

这是一次性确认实验。结构、时间块、数据切分、训练预算和判断门槛在查看新确认期结果前
全部冻结。训练随机数 100 失败后不修改设计重试；成功时才运行训练随机数 200 和 300。

## 2. 已有诊断作为前置事实

- 版本 05 已训练模型的七种非空分支屏蔽已经完成并可复算。仅近期分支的中位
  纳什－萨特克利夫效率系数为 `0.444846`，完整模型为 `0.607831`，经典近期模型为
  `0.663391`。这说明共同训练后近期路径发生了明显漂移，不能把屏蔽差异解释为历史信息的
  因果收益。
- 严格停用历史模块时，经典 256 单元模型和嵌套控制在 30 轮、18,000 次更新及 43,860 条
  验证预测上逐元素相同。代码框架具备严格嵌套能力。
- 版本 07 的远期→中期→近期状态传递在旧确认期相对经典模型的逐流域配对差中位数只有
  `+0.001398`，且弱于参数量控制和简单历史拼接。该结果只否定固定硬分段方案的净优势，
  不否定更早气象历史可能含有信息。

## 3. 数据边界和新确认期

- 流域：冻结的 60 个内部流域，列表 SHA-256 为
  `3160dad3b22200fdb596164c9f69e4fbe19cc156cfad768beb193efea7b26b65`。
- 目标包：`pilot_targets_1999_2008_v02.csv`，SHA-256 为
  `d4c93675eefd433515d6f7e10943caea31c6eb7e30533d4c387cf9325886e05c`。
- 新训练目标期：`1999-10-01` 至 `2004-09-30`，每个流域 1,827 天，共 109,620 个目标。
- 新确认期：`2004-10-01` 至 `2006-09-30`，每个流域 730 天，共 43,800 条预测。
- 原有 `2006-10-01` 至 `2008-09-30` 内部验证期不用于本实验的训练、选择或报告。
- 正式评估目标期 `1989-10-01` 至 `1999-09-30` 的观测、预测和答案始终不读取。
- 最早训练目标的 3,649 天 Maurer 气象历史追溯到 `1989-10-04`。这是允许的气象驱动，
  不是正式评估观测流量或答案；报告和审计必须明确记录这一点。
- 标准化统计量、流量损失权重只用新训练目标期计算，不得包含新确认期。

## 4. 连续多尺度表示

近期路径固定为滞后 `0–269` 天的 270 个逐日时间步，与经典模型完全相同。

更早历史固定为滞后 `270–3649` 天，共 3,380 天和 120 个互不重叠、无空缺的时间块。
时间块边界由以下唯一公式生成：

```python
edges = round(exp(linspace(log(270), log(3650), 121)))
edges[0] = 270
edges[-1] = 3650
```

按紧凑 JSON 编码后的边界 SHA-256 固定为
`bae1f744feca9160181365545a07b445eab269d6afa8817a2e7c99e19f200d73`。
实际块宽为 6–78 天；由于整数取整，局部可能相差一天，但总体随滞后增大而变粗。模型按
最老到最近的顺序读取 120 个时间块，不存在原有 1,825 天分界。

每个历史时间块包含：

1. 五项已按新训练期标准化的 Maurer 气象驱动均值；
2. 时间块宽度的对数归一化值；
3. 时间块中心滞后的对数归一化值；
4. 重复的 27 项静态属性。

前两项时间坐标完全由滞后索引确定，不引入外部预测信息。历史编码器输入宽度为
`5 + 2 + 27 = 34`。近期编码器仍为 `5 + 27 = 32`。

## 5. 模型结构

### 连续历史候选

- 一个 34 输入、256 隐藏单元、单层的历史长短期记忆网络；
- 一个 32 输入、256 隐藏单元、单层的近期长短期记忆网络；
- 历史最终隐藏状态和记忆状态分别乘以两个 256 维可学习门，再初始化近期网络；
- 两个门的原始参数初始化为零，并经双曲正切限制；
- 一个 `256 → 1` 线性输出层，只预测一个流量；
- 随机丢弃只作用于近期最终状态，并使用按训练随机数、轮次、批次和分支固定的独立随机流；
- 近期网络和输出层与同训练随机数的经典 256 单元模型逐元素同初始化。

零门使候选在训练开始前逐元素等于经典近期模型。第一步先更新门；历史编码器从门非零后
获得梯度。这避免随机历史状态在训练开始时立即扰动近期路径。

候选精确参数量为 `596,737`。

### 经典近期对照

- 只读取 270 天逐日近期输入；
- 输入宽度 32、隐藏宽度 256、单层长短期记忆网络；
- 参数量 `297,217`。

### 参数量控制

- 只读取 270 天逐日近期输入；
- 输入宽度 32、隐藏宽度 369、单层长短期记忆网络；
- 参数量 `595,198`；
- 与候选相差 `1,539`，即候选参数量的 `0.258%`，低于 1%。

## 6. 新结构的严格嵌套复现

`R08-NEST` 使用与候选相同的类和全部历史模块，但历史前向完全停用，历史参数和门冻结且
不进入优化器。活跃参数只包含近期网络和输出层，共 `297,217` 个，名称、顺序、形状和初值
与经典模型相同。

经典模型和停用历史的嵌套控制在新训练切分上锁步运行 30 轮。每个批次比较：

- 样本索引；
- 前向前后的中央处理器和图形处理器随机数状态；
- 预测、损失、未裁剪梯度、裁剪后梯度；
- Adam 优化器状态；
- 更新后活跃参数。

通过容差为零，即全部使用逐元素相等判断。最终 43,800 条确认期预测及逐流域指标也必须
逐元素相同。任何一处不相等都停止候选训练；同一根因连续三次修复仍失败则停止实验并转入
架构审核。

## 7. 训练协议

- 第一阶段训练随机数：100；
- 条件训练随机数：200、300；
- 30 轮；
- 每批 256 个目标；
- Adam 优化器；
- 学习率：第 1 轮 `0.001`，第 12 轮 `0.0005`，第 22 轮 `0.0001`；
- 梯度范数裁剪：1.0；
- 近期输出随机丢弃比例：0.4；
- 初始遗忘门偏置：5.0；
- 固定使用最后一轮，不读取确认期选择检查点；
- 候选、经典对照和容量对照使用完全相同的样本、批次顺序、损失和训练预算。

## 8. 判断门槛和停止条件

训练随机数 100 必须同时满足：

1. 相对经典 256 单元模型的逐流域效率系数差值中位数不低于 `+0.01`；
2. 相对参数量控制的逐流域差值中位数大于 `0`；
3. 相对经典模型获胜的流域比例不低于 `0.55`；
4. 对 60 个流域进行 100,000 次有放回自助抽样后，配对差中位数 95% 区间下界大于 `0`，
   自助抽样随机数固定为 `20260728`。

任何一项失败即记录 `NO-GO`，不运行训练随机数 200 和 300，也不在该确认期修改时间块、
门、宽度、损失或训练预算。

全部通过时运行训练随机数 200 和 300。多训练随机数结论还必须同时满足：

- 三个训练随机数至少两个相对各自经典对照的配对差中位数为正；
- 三训练随机数等权预测集成相对经典集成的配对差中位数不低于 `+0.01`；
- 集成相对容量对照为正；
- 集成相对经典的流域胜率不低于 `0.55`；
- 集成配对差中位数的 95% 自助区间下界大于 `0`。

另外，以下情况立即停止并判为审计失败：

- 读取禁止的观测流量、正式评估答案或正式评估预测；
- 新切分的样本键或观测值在比较臂间不一致；
- 历史时间块未精确覆盖滞后 `270–3649` 天，存在重叠、空缺或未来索引；
- 参数量差超过 1%；
- 冒烟运行出现非有限损失、错误状态形状，或第三次优化更新后历史编码器仍无非零梯度；
- 落盘预测不能精确复算落盘逐流域指标。

## 9. 固定诊断和独立审核

候选训练完成后只执行预注册诊断：

- 正常历史状态初始化；
- 把两个历史门在推理时置零，仅使用共同训练后的近期路径；
- 记录两个门、历史隐藏状态、历史记忆状态的范数；
- 记录近期参数相对初始经典参数的漂移；
- 指标只从重新读取的落盘预测计算。

屏蔽只描述共同训练后的依赖，不作历史信息因果归因。

无论结果成功或失败，独立审查者都必须从配置、代码、检查点和逐日预测重新审核：

1. 模型结构、参数量和零门嵌套；
2. 时间索引、120 个时间块和新数据切分；
3. 仅使用 Maurer 气象驱动和 27 项静态属性；
4. 正式评估目标和答案未读取；
5. 训练随机数、样本顺序、检查点规则和停止条件；
6. 全部产物 SHA-256；
7. 从落盘预测独立复算指标、门槛和最终结论；
8. 主动寻找足以推翻结论的泄漏、错位、容量不公平或统计错误。

独立审核单独给出 `PASS`、`HOLD` 或 `REJECT`，并明确区分“实现有效”与“预测有效”。

# 历史连续多尺度气象模型版本09训练目标封存边界诊断

## 结论

原输入计划中的训练目标导出路径不够严格，必须修正后才能实施。

原因是核心函数
`neuralhydrology.datasetzoo.camelsus.load_camels_us_discharge`会用pandas一次解析整份原始流量文件，
建立全部日期索引，并对全部`QObs`执行单位转换。之后再截取1999-10-01至2008-09-30训练期，
只能证明“没有输出正式评估期流量”，不能证明“正式评估期流量没有被解析”。

版本09现改为训练日期先行的可信流式解析：

1. 每行只先分离流域、年、月、日和未解析尾部；
2. 日期不在训练期时立即丢弃尾部，不分离、不数值转换、不哈希、不记录流量字段；
3. 只有训练期行才解析流量和质量标记；
4. 候选训练和预测代码只读取封存后的`targets.npy`，永远不导入可信解析模块；
5. 正式评估期流量字段解析数必须为0。

本次只读源码，没有打开或读取任何原始流量文件。

## 修正后的信息边界

### 可信输入阶段

可信导出器是唯一允许定位原始流量文件的版本09模块。它必须：

- 在一次性正式输入授权已经原子消费后才打开原始流量文件；
- 流式逐行处理，不能调用pandas读取原始流量；
- 使用`split(maxsplit=4)`只得到日期前缀和可选的未解析尾部；
- 对非训练日期立即删除未解析尾部，且不要求尾字段存在或具有固定数量；
- 对训练日期才把尾部分为流量和质量标记；
- 验证每个流域恰有3,288个连续训练日期；
- 不打印流量值、原始流量路径、流域流量统计或非训练期派生量。

原始流量文件和正式评估期值仍由可信模块所在的隔离输入阶段接触；候选路径只得到训练期监督数组。
这里的“未解析”指不把非训练期流量字段分离为数值、不转换、不汇总、不哈希和不输出。
由于训练期和其他日期位于同一文本文件，操作系统仍会读取整行字节；不能把这一事实描述为
“文件字节从未进入内存”。

### 候选训练与预测阶段

候选运行代码只允许读取：

- Maurer气象内存映射；
- 27项静态属性；
- 训练期`targets.npy`；
- 训练期归一化统计；
- 已审核检查点。

候选代码不得：

- 定位或打开`usgs_streamflow`；
- 导入可信目标导出模块；
- 接收原始流量路径；
- 接收正式评估期观测；
- 计算观测派生的水文签名。

### 正式评分阶段

评分命令的`--experiment-dir`必须显式指向候选运行源码包。可信输入工具不属于候选运行时传递依赖，
不进入该包。独立审核必须同时证明：

- 候选运行时没有导入可信目标模块；
- 候选源码包完整覆盖实际训练和预测代码；
- 禁止访问扫描命中数为0。

## 训练目标来源指纹

不再对整份原始流量文件计算并公布摘要，因为整文件摘要包含正式评估期字节的旁路指纹。

每个流域只对允许解析的训练期规范记录计算SHA-256。规范记录为：

```text
basin,date,raw_training_q_token,quality_flag
```

531个逐流域训练记录摘要再按冻结流域顺序组成摘要树。最终封存只保存：

- 训练记录摘要树；
- 训练流量字段解析数1,745,928；
- 正式评估期流量字段解析数0；
- 其他非训练期流量字段解析数0；
- 候选原始流量文件打开数0；
- 输出目标包SHA-256。

它能追溯训练监督来源，但不产生正式评估答案的文件级摘要。

## 可验证测试

正式实现必须至少包含以下反驳测试：

1. 在正式评估日期分别放置不可转换字符串`DO_NOT_PARSE`、额外字段和缺失尾字段，
   训练期放置数值；解析器必须成功并只返回训练期值。
2. 在训练期放置不可转换字符串，解析器必须失败。
3. 缺失、重复、乱序或多出训练日期必须失败。
4. 流量非有限、负值、面积非正或流域编号漂移必须失败。
5. 可信模块源码中不得出现`load_camels_us_discharge`、`pd.read_csv`或
   `pandas.read_csv`。
6. 候选输入、训练和预测模块不得出现原始流量目录标记或可信模块导入。
7. 清单中的正式评估期流量解析数必须为0。

合成测试证明代码分支和接口边界；正式输入独立审核还必须验证真实产物只有训练日期、完整覆盖且哈希闭合。

## 事实、推断与未知

事实：

- 现有核心加载器会解析整份原始流量文件；
- 旧计划直接调用该加载器；
- 这不足以证明正式评估期流量未解析；
- 正式输入尚未获授权，也没有任何原始流量读取发生。

推断：

- 日期先行、训练期专用流式解析加合成哨兵测试，可以把候选可见信息严格限制到训练监督。

未知：

- 531个流域训练期目标是否全部连续、非负和有限；
- 训练行来源摘要树和最终目标包SHA-256；
- 真实可信导出是否通过独立审核。

这些未知只能在用户批准正式输入阶段后验证，不能用既有经典模型成功训练来替代。

## 停止条件

以下任一情况成立时，正式输入必须停止：

- 实现仍调用完整流量加载器或pandas读取原始流量；
- 非训练日期分支分离或转换流量字段，或要求其流量尾字段存在、可转换或具有固定数量；
- 任一流域不是3,288个完整训练日期；
- 任一训练流量非有限或为负；
- 可信模块被候选训练或预测导入；
- 正式评估期流量解析计数不为0；
- 正式评估期或其他非训练期流量派生量进入清单、日志或摘要；
- 用户未批准输入阶段，或授权消费、内存、哈希、工作区和输出不存在门未通过。

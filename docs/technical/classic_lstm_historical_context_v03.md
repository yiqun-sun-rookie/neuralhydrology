# 经典长短期记忆网络叠加分段历史信息：版本 03 内部结果

**日期：** 2026-07-26  
**状态：** `no_go_stage1`  
**结论：** 本轮不追加随机种子，也不进入 531 流域正式实验。单输出头拼接出现弱正信号，但没有达到事先冻结的最小效应；初始记忆状态注入没有超过对应的容量控制。

## 1. 回答的问题

本轮检验：在经典水文长短期记忆网络完整保留近 270 天主干和单一流量输出的条件下，显式加入互不重叠的中期、远期气象历史，能否获得超过参数增加本身的验证期收益。

三个输入区间为：

- 近期：滞后 0–269 天，270 个逐日时间步；
- 中期：滞后 270–1824 天，聚合为 60 个等宽平均时间块；
- 远期：滞后 1825–3649 天，聚合为 60 个等宽平均时间块。

两个候选都只有一个流量输出：

- 单输出头拼接：拼接 256 维近期状态、24 维中期状态和 24 维远期状态，再由一个线性头输出流量；
- 初始记忆状态注入：中期和远期状态生成近期 256 单元长短期记忆网络的初始记忆状态，仍由经典单一线性头输出流量。

本轮没有多个专家分别预测流量，也没有动态门控或多个流量的加权平均。

## 2. 对比协议

- 数据：美国大样本流域属性与气象数据集，Maurer 五项气象强迫和 27 项静态属性；
- 流域：冻结的 60 个流域；
- 训练目标期：1999-10-01 至 2006-09-30；
- 内部验证目标期：2006-10-01 至 2008-09-30；
- 随机种子：第一阶段固定为 100；
- 训练：30 轮、批量大小 256、Adam、梯度范数上限 1；
- 学习率：第 1–11 轮为 0.001，第 12–21 轮为 0.0005，第 22–30 轮为 0.0001；
- 损失：按流域训练期流量标准差加权的平方误差，与经典纳什－萨特克利夫损失实现一致；
- 每个运行：153,420 个训练目标样本、每轮 600 次优化、总计 18,000 次优化；
- 每个运行：60 个流域、43,860 条完整逐日验证预测。

五个模型的实际可训练参数量为：

| 模型 | 参数量 | 作用 |
|---|---:|---|
| 经典长短期记忆网络，256 单元 | 297,217 | 精确经典对照 |
| 加宽经典长短期记忆网络，261 单元 | 308,242 | 单输出头拼接的容量控制 |
| 加宽经典长短期记忆网络，266 单元 | 319,467 | 初始记忆状态注入的容量控制 |
| 单输出头拼接 | 308,401 | 候选一 |
| 初始记忆状态注入 | 320,897 | 候选二 |

单输出头拼接与对应容量控制相差 159 个参数，即候选参数量的 0.052%；初始记忆状态注入与对应容量控制相差 1,430 个参数，即候选参数量的 0.446%。

## 3. 第一阶段结果

### 3.1 绝对指标

| 模型 | 60 流域纳什－萨特克利夫效率系数中位数 |
|---|---:|
| 经典长短期记忆网络，256 单元 | 0.663391 |
| 加宽经典长短期记忆网络，261 单元 | 0.673329 |
| 加宽经典长短期记忆网络，266 单元 | 0.693332 |
| 单输出头拼接 | 0.695812 |
| 初始记忆状态注入 | 0.735654 |

绝对中位数之间不能直接相减代替逐流域配对中位差，因为不同模型的中位流域可以不同。继续判据只使用下面的逐流域配对差。

### 3.2 冻结配对判据

| 候选 | 相对精确经典模型的逐流域中位差 | 相对精确经典模型的流域胜率 | 相对容量控制的逐流域中位差 | 第一阶段 |
|---|---:|---:|---:|---|
| 单输出头拼接 | +0.009156 | 61.67% | +0.003833 | 不通过 |
| 初始记忆状态注入 | +0.006626 | 58.33% | -0.007309 | 不通过 |

第一阶段要求同时满足：

1. 相对精确经典模型的逐流域中位差不小于 0.01；
2. 相对容量控制的逐流域中位差大于 0；
3. 相对精确经典模型的流域胜率不小于 55%。

单输出头拼接满足第二、三项，但第一项差 0.000844。初始记忆状态注入只满足第三项。

作为不参与门槛的稳定性描述，随机种子 100 的流域配对自助抽样 95% 区间为：

- 单输出头拼接相对精确经典模型：[-0.000525, 0.020513]；
- 初始记忆状态注入相对精确经典模型：[-0.003753, 0.029770]。

两个区间都包含 0。因此，单个随机种子不足以把弱正信号写成稳定增益。

## 4. 决策

按冻结协议，两个候选均为 `no_go_stage1`：

- 不运行随机种子 200 和 300；
- 不触碰 1989-10-01 至 1999-09-30 的封存正式评估流量；
- 不进入 531 流域正式比较；
- 不把本轮结果解释为新水、旧水或水龄机制证据。

这个结论只否定本轮固定区间、等宽平均压缩和两个叠加位置在冻结门槛下的继续资格。它不否定所有显式分段历史信息方法。

单输出头拼接仍是两个候选中更值得保留的方向，因为它同时超过精确经典模型和几乎等参数的容量控制，并在 61.67% 的流域上获胜；但其预注册效应不足且单种子不确定区间跨 0，当前证据不能支持扩大实验。

# 历史分段专家严格屏蔽与嵌套复现

**日期：** 2026-07-27  
**状态：** 前置诊断通过，允许进入候选迭代 1

## 1. 结论

版本 05 的负结果不是因为“新增模块只要存在就会破坏经典模型”。一个包含但完全停用中期和远期模块的嵌套控制，在 30 轮、18,000 次优化更新中逐元素复现了经典 256 单元长短期记忆网络；最终 43,860 条内部验证预测也与版本 03 冻结经典结果逐元素相同。

因此，代码和训练框架具备严格嵌套能力。版本 05 的下降来自历史分支参与共同训练后的优化轨迹和表示共同适应，而不是理论嵌套本身失效。

## 2. 已训练模型的七种屏蔽

屏蔽发生在编码器输出之后、冻结线性输出层之前。模型处于评估模式，被屏蔽表示置零，输出偏置保留一次。

完整组合逐元素复现版本 05 已保存的 43,860 条预测。四个结果文件的清单哈希全部通过，逐流域指标从保存预测重新计算后逐元素一致。

### 事实

- 共同训练后的近期路径单独使用时，中位效率只有 0.444846，明显低于经典模型的 0.663391。
- 加入远期分支后中位效率恢复到 0.606065，与完整模型只差 0.000499 的逐流域中位差。
- 中期分支单独预测无效；在近期和远期已经活跃时，中期只带来很小的净改善。

### 推断

远期分支主要在补偿共同训练后近期路径的漂移。该结果不能证明远期信息具有独立、可泛化的预测价值，因为所有分支已经共同适应。

## 3. 随机丢弃根因

版本 05 模型构建后的中央处理器随机数状态不同，但完整训练使用图形处理器。图形处理器构建后随机数状态实际上相同。

真正的可复现实验差异是：在相同图形处理器随机数状态下，对 256 维近期表示和 448 维拼接表示执行随机丢弃，近期 256 维中的 1,024 个测试位置有 386 个掩码不同。初始中期和远期输出权重为零时，训练模式输出最大绝对差仍达到 0.333648。

因此，仅重置随机种子不足以建立严格嵌套。

## 4. 严格嵌套控制

嵌套控制具有中期和远期模块，但这些模块：

- 不执行前向；
- 不读取中期或远期输入；
- 全部冻结；
- 不进入优化器。

活跃近期路径与经典模型均为 297,217 个参数。参数名称、顺序、形状和初值完全相同。每个批次在两个前向之间保存并恢复中央处理器和图形处理器随机数状态，然后逐项比较预测、损失、梯度、裁剪结果、Adam 状态和更新后参数。

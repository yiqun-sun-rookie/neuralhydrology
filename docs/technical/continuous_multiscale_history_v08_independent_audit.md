## 3. 数据边界、实际输入和标准化

### 模型实际读取的信息

执行路径只把下列内容传入模型：

1. Maurer 数据产品的五个命名气象列：
   `PRCP(mm/day)`、`Tmin(C)`、`Tmax(C)`、`SRAD(W/m2)`、`Vp(Pa)`；
2. 27 项气候、地形、植被、土壤和地质静态属性；
3. 历史时间块宽度和中心滞后的两个确定性坐标。

两个时间坐标完全由冻结滞后索引计算，不读取外部观测、预测或答案。流量只在损失函数中作为
监督目标，没有进入近期序列、历史序列、静态属性或时间坐标。

当前 60 个流域、`1989-10-04` 至 `2008-09-30` 的 Maurer 文件中，
`Tmin(C)` 与 `Tmax(C)` 在全部 `60 × 6,937 = 416,220` 个流域—日期位置上逐元素相同。
所以模型有五个命名气象列，但只有四个独立气象通道。三个比较模型使用完全相同的数据，
这不破坏当前公平比较；报告若写“五码独立气象信息”则不准确。

### 独立输入核验

## 4. 120 个历史时间块和因果顺序

本审核没有调用版本 08 的时间块函数，直接按冻结公式重新生成：

```python
edges = round(exp(linspace(log(270), log(3650), 121)))
edges[0] = 270
edges[-1] = 3650
```

独立结果为：

- 121 个边界、120 个时间块；
- 紧凑 JSON 边界 SHA-256：
  `bae1f744feca9160181365545a07b445eab269d6afa8817a2e7c99e19f200d73`；
- 120 个宽度全部为正，最小 6 天、最大 78 天，合计 3,380 天；
- 展开后恰好等于每个滞后 `270, 271, …, 3649` 一次；
- 重叠 0、空缺 0、未来索引 0；
- 近期滞后 `0–269` 与历史滞后 `270–3649` 的并集恰好是 3,650 个位置；
- 模型读取顺序为最老到最近：第一个时间块是滞后 `3572–3649`，最后一个是
  `270–275`；
- 由于整数取整，宽度相邻下降 1 天的地方有 7 处；没有更大下降。这与设计所说的局部一日
  取整波动一致。

对首个训练目标 `1999-10-01`：

| 区段 | 实际日期 |
|---|---|
| 最早历史气象 | `1989-10-04` |
| 历史区段最后一天 | `1999-01-04` |
| 近期区段第一天 | `1999-01-05` |
| 近期区段最后一天 | `1999-10-01` |

因此没有历史—近期重叠或空缺，也没有读取目标日之后的气象。

## 5. 模型图、参数量和公平性

### 实际模型图

连续历史候选是：

1. 一个输入宽度 34、隐藏宽度 256、单层的历史长短期记忆网络；
2. 历史网络的最终隐藏状态和记忆状态分别乘以一个 256 维可学习门；
3. 两个门的原始参数精确初始化为零，并经双曲正切函数限制；
4. 门控后的两个历史状态初始化输入宽度 32、隐藏宽度 256、单层的近期长短期记忆网络；
5. 一个形状为 `1 × 256`、带一个偏置的线性输出层；
6. 唯一输出形状为每个样本一个流量。

九个检查点的参数键、形状、元素数和有限性均独立检查。没有第二个输出头、流量输入头或
未报告的预测分支。

| 模型 | 独立公式和检查点参数量 |
|---|---:|
| 经典近期模型，隐藏宽度 256 | 297,217 |
| 近期参数量控制，隐藏宽度 369 | 595,198 |
| 连续多尺度历史候选 | 596,737 |

候选比参数量控制多 1,539 个参数，即候选参数量的
`1,539 / 596,737 = 0.2579026%`，低于冻结的 1% 上限。

候选在初始化时的近期网络和输出层与同训练随机数的经典 256 单元模型逐元素相同。两个历史
门为零，因此训练开始前候选输出与经典模型逐元素相同。三个候选运行的历史编码器第一次出现
非零梯度都在第 2 次优化更新，符合“第一步更新门、随后历史编码器获得梯度”的结构。

### 训练公平性

- 三个模型使用相同的 109,620 个训练坐标、每批 256 个目标和每轮相同的随机排列；
- 每个模型都是 30 轮、每轮 429 次更新、共 12,870 次更新；
- 学习率、流量损失权重、梯度裁剪、最终轮检查点和确认批次规则一致；
- 候选与经典 256 单元模型的近期随机丢弃掩码由相同的
  `训练随机数—轮次—批次—分支`
  生成；
- 九个检查点保存的标准化统计逐元素相同；
- 检查点内所有参数均为有限值。

运行清单只保存设备为 `cuda`，没有保存 Python、PyTorch、CUDA、驱动和图形处理器型号。
当前审核环境是 Python 3.11.5、PyTorch 2.2.2、CUDA 12.1 和
NVIDIA GeForce RTX 4070 Ti；这些是当前环境，不一定等于历史训练环境。因此当前结果可审核，
但不能保证在另一台机器逐位重跑。

## 12. 新确认期的独立性边界

长期存在，旧模型曾用这些观测优化参数。现有系统没有把该窗口作为研究者不可见的密封目标。

- “版本 08 没有用确认期训练或选择”得到代码和检查点支持；

# 历史专家初始化冻结近期状态：候选迭代 3

## 结论

候选迭代 3 未通过单训练随机数筛选，停止运行训练随机数 200 和 300。历史专家初始化近期
隐藏状态与记忆状态只带来很小的逐流域改进，弱于候选迭代 2 的输出残差。

本轮只使用 60 个固定流域、Maurer 气象驱动、27 个静态属性、1999-10-01 至
2006-09-30 训练期和 2006-10-01 至 2008-09-30 验证期。未读取正式评估期。

## 完整结果

历史参数使用训练随机数 100 训练 30 轮、18,000 次更新。候选总参数量为 892,161，
其中 594,944 个历史编码器和门控参数可训练。初始预测与冻结经典近期模型逐位相同；近期
编码器和唯一输出层在训练前后的状态散列均为
`9e1d987d4823120fa7c2ce4b201a0075ef7730ab18bcbafe1f81aae6a7d24138`。

候选验证期纳什—萨特克利夫效率中位数为 0.683403897768。候选相对近期经典模型的逐流域
效率差中位数为 +0.000207504319，相对参数量匹配经典模型为 -0.001299587455，相对冻结
旧版历史拼接模型为 -0.007054502734。60 个流域中有 34 个优于近期经典模型，胜率为
0.566666666667。

只有流域胜率门槛通过，其余三项门槛失败。

## 训练与产物核验

第 11 轮训练损失从约 0.00762 短暂升至 0.01714；第 12 轮按预注册计划降低学习率后恢复
至 0.00777，此后没有非有限值。最终训练损失为 0.007488182786。

检查点、配置、43,860 条逐日预测和逐流域指标的散列均与清单一致。候选预测的 SHA-256 为
`b28d1d9d820199fe4925d4cd4e96eaa1d509a20dce911ca991ad6e96f056ea68`。

推断：把历史状态注入冻结近期网络能够改善部分流域，但信息强度不足；继续调整状态门控或
输出残差缩放没有证据能达到 +0.01 门槛。

## 3. 内存安全审核

### 3.1 门槛

本机31.70 GiB物理内存对应：

- 长任务启动可用内存：至少12.68 GiB；
- 运行中保留：至少8 GiB；
- 当前进程驻留内存：不超过6 GiB；
- 单次计划分配：不超过512 MiB；
- 单批量：不超过256个样本。

全量展开 `1,745,928 × 3,562 × 5` 个float32值需要124,379,910,720字节，即115.84 GiB。代码会在分配前拒绝。一个256样本批量为17.39 MiB；按窗口、前缀和中间张量共四份估计为69.57 MiB，低于单次门槛。

### 3.2 实际启动检查

审核快照：

- 总物理内存：31.70 GiB；
- 可用物理内存：11.47 GiB；
- 合成测试：允许；
- 训练协议授权：拒绝；
- 假设已有训练授权，内存门仍拒绝，因为11.47 GiB小于12.68 GiB。

这说明当前不是“文档提醒”，而是双重失败关闭：没有授权时先拒绝；有授权但内存不足时仍拒绝。

限制：用户态门槛不能绝对防止其他进程突然占满内存或操作系统故障。当前任务通过禁止全量展开、限制批量、逐块检查和保留8 GiB，把自身导致物理内存耗尽的风险控制在明确边界内。

# 冻结近期专家的历史残差：候选迭代 2

## 结论

候选迭代 2 未通过单训练随机数筛选，停止运行训练随机数 200 和 300。冻结近期专家消除了首轮
的近期分支退化，历史残差使 36/60 个流域优于近期经典模型，但改进幅度不足，且仍低于旧版
历史拼接模型。

本轮只使用 60 个固定流域、Maurer 气象驱动、27 个静态属性、1999-10-01 至
2006-09-30 训练期和 2006-10-01 至 2008-09-30 验证期。未读取
1989-10-01 至 1999-09-30 的正式评估期。

## 完整结果

历史参数使用训练随机数 100 训练 30 轮、18,000 次更新。候选总参数量为 891,649，
其中 594,432 个历史参数可训练。候选保存 43,860 条验证预测。

| 模型 | 验证期纳什—萨特克利夫效率中位数 |
|---|---:|
| 冻结近期经典模型 | 0.682708709251 |
| 参数量匹配经典模型 | 0.708129838031 |
| 冻结旧版历史拼接模型 | 0.695811909868 |
| 冻结近期模型加两个历史残差 | 0.691590855786 |

候选相对近期经典模型的逐流域效率差中位数为 +0.000627956001，相对参数量匹配经典模型为
+0.002936882180，相对冻结旧版历史拼接模型为 -0.007233555212。60 个流域中有 36 个
优于近期经典模型，胜率为 0.60。

“相对参数量匹配模型”和“流域胜率”两项门槛通过；“相对近期经典模型至少 +0.01”和
“高于旧版历史拼接模型”两项失败。因此本轮总体判定为不通过。

## 分支与缩放诊断

| 保留输出 | 验证期效率中位数 | 相对近期经典模型的逐流域差中位数 | 胜出流域 |
|---|---:|---:|---:|
| 近期 | 0.682708713670 | 0 | 0 |
| 近期和中期 | 0.691454916677 | +0.000130898692 | 34/60 |
| 近期和久远 | 0.683465477012 | -0.000059104258 | 29/60 |
| 近期、中期和久远 | 0.691590853922 | +0.000627961402 | 36/60 |

中期分支贡献主要的效率中位数提升；久远分支单独使用没有稳定优势，但与中期分支组合后改善
逐流域差中位数和胜率。

仅作为诊断，在验证期把已训练历史残差乘以 0 至 2 的 21 个固定系数。最佳逐流域差中位数
为 +0.000787502868，仍远低于 +0.01，且仍低于旧版历史拼接模型。该诊断没有被当作候选
结果，也没有用于追加训练随机数。

推断：简单的输出层残差幅度调整无法解决问题。下一轮应保持近期参数冻结，把两个历史专家
用于构造近期长短期记忆网络的初始隐藏状态和记忆状态，使历史信息在近期序列内部参与状态
演化，而不是只在输出端相加。

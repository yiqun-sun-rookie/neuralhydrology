# 三个等宽历史专家：候选迭代 1

## 结论

候选迭代 1 未通过单训练随机数筛选，停止运行训练随机数 200 和 300。三个专家联合训练后，
近期专家本身明显退化；中期和久远专家主要用于修复该退化，最终仍未恢复到独立经典近期模型。

本轮只使用 60 个固定流域、Maurer 气象驱动、27 个静态属性、1999-10-01 至
2006-09-30 训练期和 2006-10-01 至 2008-09-30 验证期。未读取
1989-10-01 至 1999-09-30 的正式评估期。

## 完整训练结果

四个模型均使用训练随机数 100、30 轮、18,000 次参数更新。每组保存 43,860 条验证预测。

| 模型 | 参数量 | 验证期纳什—萨特克利夫效率中位数 |
|---|---:|---:|
| 近期经典长短期记忆网络，隐藏宽度 256 | 297,217 | 0.682708709251 |
| 近期经典长短期记忆网络，隐藏宽度 455 | 890,436 | 0.708129838031 |
| 近期模型加两个较窄历史编码器 | 308,401 | 0.693457454154 |
| 三个隐藏宽度均为 256 的分段专家 | 891,649 | 0.676727773145 |

三个等宽专家相对近期经典模型的逐流域效率差中位数为 -0.004164780708，
相对参数量匹配经典模型为 -0.006303311722，相对冻结旧版历史拼接模型为
-0.011426914455。60 个流域中有 29 个优于近期经典模型，胜率为 0.483333333333。
四项预注册门槛全部失败。

## 输出分支屏蔽诊断

对已训练的三个等宽专家检查全部七个非空输出分支组合：

| 保留分支 | 验证期效率中位数 |
|---|---:|
| 近期 | 0.616532752698 |
| 中期 | -0.118735543862 |
| 久远 | -0.134036409435 |
| 近期和中期 | 0.658892211246 |
| 近期和久远 | 0.651426682131 |
| 中期和久远 | -0.097452308477 |
| 全部 | 0.676727780607 |

事实：联合训练后的近期分支比独立近期经典模型低 0.066175956553。
事实：两个历史分支都能修复一部分联合训练造成的下降，但完整模型仍比独立近期模型低
0.005980928644（两者各自效率中位数之差）。

推断：首轮失败的主要机制是共同优化改变了近期专家的有效训练轨迹，而不是“历史分支没有产生
任何信息”。下一轮应冻结已经完整训练的近期专家，只允许历史专家学习剩余误差。

## 独立核验

独立脚本从五组逐日预测重新计算 60 个流域指标；其逐流域差中位数与正式汇总差异小于
4e-13。五组预测的流域、日期和观测值逐行一致。四个新训练目录中的全部文件散列均与各自
清单一致；冻结旧版历史拼接预测的 SHA-256 为
`dc67277dd9302e7fe5985728a87d82178de1029a9f2bab123a3cbe72d5807941`。

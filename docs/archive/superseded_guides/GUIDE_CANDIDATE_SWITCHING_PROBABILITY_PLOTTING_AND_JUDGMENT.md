# 候选切换概率绘图与判断指南

## 一、用途和边界

本指南用于回答一个独立问题：

> 当已知真值因素按阶段发生切换时，多个候选的后验概率是否朝新的真实候选响应，以及是否达到预先规定的识别标准？

它适用于参数候选、过程噪声候选、参数与过程噪声的联合候选，以及其他离散候选集合。它不绑定具体水文模型、状态个数、候选个数、阶段个数或固定概率门槛。

候选概率只能支持候选辨认或切换响应结论，不能单独证明：

- 更新后的状态更准确；
- 未来流量预报更准确；
- 状态与协方差交互有效；
- 真实流域中的参数或噪声已被识别；
- 连续真值一定等于候选库中的某一个离散候选。

这些问题必须分别设计实验和提供证据。

## 二、先区分五种不同结论

以下说法强度不同，不能互相替代。

| 结论层级 | 可验证含义 | 不能自动推出 |
|---|---|---|
| 概率响应 | 切换后，真实候选或真实候选组的概率按预期方向上升 | 真实候选已成为第一 |
| 暂时主导 | 真实候选在某些时刻具有最高概率 | 主导稳定、可重复 |
| 稳定主导 | 真实候选满足预先规定的连续时长或阶段占比规则 | 其他真值因素也被识别 |
| 边缘识别 | 某一类因素的概率求和后，真实参数组或真实噪声组稳定主导 | 唯一的参数—噪声组合正确 |
| 联合识别 | 真实的唯一联合候选稳定主导，并通过预先规定的重复性判断 | 状态或预报因此更优 |

“真实候选概率上升”应写为响应；只有满足事先冻结的主导、持续性和重复性规则，才能写为识别。

## 三、开始前必须冻结的科学合同

### 1. 真值阶段和候选映射

开始前记录：

- 每一阶段的起止时间；
- 每个切换时刻；
- 每一阶段的真实候选或真实候选组；
- 候选完整名称、顺序和物理含义；
- 真值是否精确包含在候选库中；
- 哪些候选在当前观测下预先被视为不可区分。

如果真值不在候选库中，不能使用“正确候选识别率”。应改为评价预先定义的相容候选组、距离真值最近的候选，或候选覆盖不足。

如果多个候选在登记的强迫和观测下不可区分，可以把它们组成“相容候选组”，并评价该组的总概率。该分组必须在看结果前确定，不能为解释失败而事后合并。

### 2. 概率递推合同

开始前冻结：

- 初始候选概率；
- 候选转移规则；
- 观测似然定义；
- 概率归一化方法；
- 缺测时的处理；
- 使用观测的时间边界；
- 随机种子、样本区块和重复次数；
- 主要指标、判断规则和不确定性计算方法。

不得使用切换后的未来观测来修改切换前的概率。不得根据结果曲线再调高停留概率、平滑强度或成功门槛，然后把同一批样本当作正式验证。

### 3. 数值完整性

每个有效时刻都应核对：

- 所有候选概率为有限数；
- 每个概率不小于零；
- 概率和在允许误差内等于一；
- 候选顺序与候选登记表完全一致；
- 每个真值阶段都有对应的概率读出；
- 边缘概率由联合概率按登记的候选映射正确求和。

至少用独立程序重新计算概率和、最高概率候选、真实候选概率、真实候选排名和边缘概率。独立核验失败时停止，不给识别结论。

## 四、推荐的基本读出

不要求所有实验使用完全相同的指标。以下读出覆盖了最常见的判断。

### 1. 真实候选概率

在时刻 `t`，记真实候选或真实候选组的总概率为 `p_true(t)`。它回答“证据给真实候选分配了多少概率”，但不单独表示真实候选是否主导。

### 2. 真实候选排名

报告真实候选的每日排名，以及它成为最高概率候选的日比例。若评价候选组，应先求组概率再排名，不能用组内单个候选替代。

### 3. 主导差值

推荐同时报告：

```text
真实候选概率 - 最高错误候选概率
```

差值大于零表示真实候选当日主导；接近零表示近似并列。只报告“第一名”会掩盖几乎相等的候选。

### 4. 概率评分

需要评价完整概率分布时，可使用对数损失或布赖尔分数。评分定义、数值截断规则和平均单位必须提前冻结。

概率评分比“是否第一名”使用了更多信息，但仍不等于状态误差或预报误差。

### 5. 切换响应时间

响应时间从登记的真实切换边界开始计算。推荐定义为：

> 真实候选首次满足预先规定的稳定主导规则的时刻。

稳定主导可以由连续时长、阶段占比或其他与时间分辨率相符的规则定义。不存在适用于所有实验的固定天数或固定占比。

若在观察窗内从未满足规则，应记为未响应或右删失，不能把窗口终点当作响应日。

## 五、最小充分绘图

图的数量由问题决定，不设置固定张数。主结果通常只需一张阶段对齐概率图；候选较多或联合候选难以阅读时，再增加热图或摘要图。

### 1. 阶段对齐概率图

主图应让读者不查内部编号也能看懂：

- 横轴为日期或相对切换时间；
- 每个真实切换点有明确竖线；
- 背景色带或顶部条带写出每一阶段的真实候选；
- 当前真实候选曲线加粗，其他曲线减弱；
- 候选使用完整、通俗的名称；
- 纵轴明确为后验概率，范围一致；
- 面板内写出样本数、判断规则、成功数和响应时间摘要。

当候选数量较少时，可以画全部候选。候选数量较多时，优先画真实候选、最强竞争候选和其余候选总概率，完整候选分布改用热图。

不得只靠“绿色代表正确”传递真值。颜色、线宽、背景标注和文字应共同表达信息，灰度查看时也应能区分主要曲线。

### 2. 候选概率热图

候选较多时，热图通常比大量折线更清楚：

- 横轴为时间；
- 纵轴为固定顺序的候选；
- 色标固定为零到一；
- 每个阶段直接标记真实候选所在行；
- 参数、噪声或其他候选属性按预先登记的顺序分组；
- 切换线与主图使用相同时间位置。

热图不能只显示获胜候选，因为这会丢失近似并列和概率扩散信息。

### 3. 多次重复的汇总图

有多个区块或随机种子时，主图可画真实候选概率的中位数和预先指定的分位区间，并在补充图保留单次事件细线。

图注必须明确阴影表示分位区间、重采样区间还是参数估计区间。不要用平均曲线掩盖两类相反结果。

### 4. 参数与噪声联合候选

联合候选实验优先使用对齐的三个读出：

- 参数边缘概率；
- 过程噪声边缘概率；
- 唯一参数—噪声联合候选概率。

边缘概率由所有具有同一参数或同一噪声属性的联合候选概率求和得到。两个边缘方向都正确，仍不保证真实联合组合具有最高概率。

联合候选很多时，不应把全部联合曲线挤在一张折线图中。可使用两个边缘概率面板，加一个联合概率热图或真实联合候选概率轨迹。

## 六、判断规则

### 1. 不使用任意的绝对概率门槛

后验概率不必达到 `0.9` 才能称为主导，也不能因为达到 `0.9` 就自动称为正确识别。绝对门槛只有在实验登记中提前规定并有科学理由时才使用。

默认判断应同时考虑：

- 真实候选是否最高；
- 与最强错误候选的差值；
- 主导是否持续；
- 多次重复是否一致；
- 切换方向之间是否一致；
- 不确定性区间是否支持声明。

### 2. 推荐判断用语

| 观察结果 | 合适判断 |
|---|---|
| 真实候选概率上升，但未成为第一 | 朝真实方向响应；识别未得到支持 |
| 真实候选短暂第一，但近似并列或反复切换 | 出现暂时主导；稳定识别未得到支持 |
| 真实候选满足预先规定的持续规则 | 该阶段的稳定主导得到支持 |
| 只有真实参数边缘稳定主导 | 参数边缘识别得到支持；噪声和联合识别未确定 |
| 只有真实噪声边缘稳定主导 | 噪声边缘识别得到支持；参数和联合识别未确定 |
| 两个边缘都正确，但真实联合候选不稳定 | 两类边缘响应得到支持；唯一联合组合识别未得到支持 |
| 唯一真实联合候选稳定主导，并在独立重复中通过冻结规则 | 登记的合成条件下，联合候选识别得到支持 |
| 不同切换方向结论不同 | 分方向报告；总体能力无法确定 |
| 点估计有利，但区间跨过登记的无差异界限 | 方向性结果；正式结论无法确定 |

单条合成轨迹只能作为案例描述。要声称方法具有可重复的切换能力，需要多个独立区块、随机种子或事件，并保留时间配对结构计算区间。

### 3. 切换延迟不等于时间错位

真值因素在切换时刻改变，不代表观测和候选概率必须同日突变。动态系统可能需要一段时间才把变化传到可观测输出，旧状态和汇流记忆也可能继续影响观测。

因此应分别标出：

- 真值切换时刻；
- 观测开始具有区分信息的时刻；
- 概率开始响应的时刻；
- 稳定主导开始的时刻。

若延迟异常，应检查观测似然优势、时间索引、强迫对齐和状态边界处理。不能先把切换后的困难日期删除，再称为即时识别。

## 七、概率曲线异常时的条件诊断

以下图只在主图不能解释结果时加入，不是每次都必须生成。

### 1. 观测似然优势

画出真实候选与最强错误候选的每日对数似然差和累计对数似然差。它回答当前观测是否真正支持真实候选。

如果真实候选在似然上没有稳定优势，提高候选停留概率或增加平滑只能改变曲线外观，不能创造辨认信息。

### 2. 转移先验与观测更新分解

分别保存观测到来前的候选预测概率和观测更新后的候选后验概率。这样可以区分：

- 高停留概率造成的旧候选惯性；
- 当前观测似然造成的真实证据；
- 数值归一化或时间索引错误。

### 3. 失败事件检查

对失败方向或失败事件，检查：

- 候选之间是否过于接近；
- 强迫是否缺乏激发；
- 观测是否对被切换因素不敏感；
- 阶段是否短于系统响应时间；
- 真值生成是否发生未登记的裁剪或投影；
- 真值噪声定义与候选噪声定义是否一致；
- 候选转移矩阵是否压制了允许的切换。

诊断用于解释失败，不得把失败样本静默排除出主要判断。

## 八、证据保存和独立核验

不规定固定文件名，但以下证据角色必须可追溯：

- 真值阶段表；
- 候选登记表和候选属性映射；
- 配置、随机种子和输入散列值；
- 每日预测概率、后验概率和观测似然；
- 参数边缘、噪声边缘和联合概率；
- 主要指标和分方向判断；
- 独立复算结果；
- 绘图数据和图形生成记录；
- 环境、测试、日志和文件散列值。

证据链应满足：

```text
结论和图
→ 冻结的指标与绘图数据
→ 原始概率和似然证据
→ 真值阶段、候选映射和配置
→ 输入数据与源代码快照
```

绘图程序只能读取封存判断，不得在画图时重新定义成功规则。结果目录已存在、散列值不符、测试失败、概率核验失败或候选映射不一致时，应停止并保留失败记录。

## 九、允许和不允许的结论

### 允许

> 在已登记的分阶段合成条件下，真实参数候选在切换后满足稳定主导规则；该结论仅涉及参数候选概率响应。

> 真实参数边缘概率和真实噪声边缘概率均有响应，但真实联合候选未稳定主导，因此唯一参数—噪声组合识别未得到支持。

> 某一切换方向通过，而另一方向未通过，因此切换能力具有方向依赖性，不能概括为所有切换均成功。

### 不允许

- “概率跟过去了，所以状态一定更准。”
- “参数边缘和噪声边缘都对，所以唯一联合滤波器一定找对了。”
- “真实候选有几天第一，所以方法已经能够稳定切换。”
- “曲线超过 0.9，所以识别成功。”
- “合成实验成功，所以真实流域参数变化已被识别。”
- “删除切换后的困难日期后表现很好，所以响应没有延迟。”

## 十、最简执行清单

开始前：

- 冻结真值阶段、候选映射、概率递推和判断规则；
- 说明真值是否在候选库内，以及是否存在预先定义的相容候选组；
- 核对输入散列值、结果目录、工作树和时间边界。

运行后：

- 核对概率有限、非负、归一化和候选顺序；
- 独立复算真实候选概率、排名、主导差值和边缘概率；
- 按切换方向和阶段分别报告，不用总体平均掩盖失败方向；
- 先画带真值阶段标注的最小概率图，再按需要增加热图或似然诊断；
- 分开写概率响应、稳定主导、边缘识别和联合识别；
- 明确说明这不是状态精度或预报价值证据。

## ✨ 新增功能

### 1. 断点续训核心功能
- **自动检测**: 智能扫描 `runs/` 目录，识别可恢复的训练运行
- **交互式选择**: 用户友好的选择界面，显示训练进度和模型文件数量
- **灵活恢复**: 支持从指定运行目录和特定epoch恢复训练
- **智能检测**: 自动检测GPU/CPU可用性，确保环境一致性
- **错误处理**: 完善的错误处理和用户提示机制

### 2. 命令行参数扩展
```bash
# 新增参数
--resume              # 启用断点续训模式
--run-dir <path>      # 指定要恢复的训练运行目录
--epoch <num>         # 指定从哪个epoch开始恢复
--clean               # 清理不完整的运行目录
```

### 3. 使用场景支持
- ✅ 训练意外中断恢复
- ✅ 系统崩溃后恢复
- ✅ 调整训练参数后继续
- ✅ 清理存储空间

# NeuralHydrology HPC 部署规划总结

## 🎯 项目概述

基于您当前的NeuralHydrology项目，我已经为您制定了完整的HPC部署方案，用于在河海大学高性能计算平台上运行531个流域的大规模训练。

## 📊 当前项目状态分析

### 现有配置
- **数据集**: CAMELS_US (531个流域)
- **模型**: CudaLSTM (隐藏层128)
- **训练配置**: 50个epoch，批次大小256
- **数据分割**: 训练集(1980-1999) + 验证集(2000-2007) + 测试集(2008-2014)
- **环境**: Windows本地开发环境

### HPC优化目标
- **模型容量**: 隐藏层从128扩展到512
- **训练规模**: 从50个epoch扩展到200个epoch
- **批次大小**: 从256提升到512
- **并行处理**: 启用16个数据加载工作进程
- **多GPU支持**: 2个GPU并行训练

## 🚀 部署流程

### 阶段1: 环境准备 (1-2天)
1. **上传项目文件到HPC**
   ```bash
   # 将以下目录上传到 /data/neuralhydrology/
   - neuralhydrology/          # 核心代码
   - src/full_531_basins/configs/camels_us/hpc/             # HPC配置文件
   - src/full_531_basins/hpc/  # SLURM作业脚本
   - scripts/                 # 工具脚本
   ```

2. **设置HPC环境**
   ```bash
   # 运行环境设置脚本
   bash scripts/hpc_deploy.sh setup
   ```

### 阶段2: 快速测试 (1天)
1. **提交快速测试作业**
   ```bash
   bash scripts/hpc_deploy.sh test
   ```

2. **验证环境配置**
   - 检查GPU可用性
   - 验证数据访问
   - 确认依赖包安装

### 阶段3: 完整训练 (3-7天)
1. **提交完整训练作业**
   ```bash
   bash scripts/hpc_deploy.sh train
   ```

2. **监控训练进度**
   ```bash
   bash scripts/hpc_deploy.sh monitor
   ```

## ⚙️ 关键配置优化

### 1. 模型配置优化
```yaml
# 从原始配置优化到HPC配置
hidden_size: 128 → 512          # 模型容量提升4倍
batch_size: 256 → 512           # 批次大小翻倍
epochs: 50 → 200                # 训练轮数提升4倍
num_workers: 0 → 16             # 启用多进程数据加载
```

### 2. 性能优化配置
```yaml
# HPC特定优化
use_mixed_precision: true       # 混合精度训练
pin_memory: true               # 固定内存
persistent_workers: true       # 持久化workers
prefetch_factor: 4             # 数据预取
use_data_parallel: true        # 多GPU并行
```

### 3. 资源申请配置
```bash
# 完整训练资源
--time=72:00:00                # 72小时训练时间
--gres=gpu:2                   # 2个GPU
--mem=64G                      # 64GB内存
--cpus-per-task=16             # 16个CPU核心
```
